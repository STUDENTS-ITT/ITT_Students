# Оценивание: error-state фильтр Калмана (15 состояний)

Теория фильтра, который комплексирует БИНС и СНС. Реализация —
`src/core/ins/ins_filter.h`, вызов — `src/core/navigation/trajectory.h`
(`nav::step`), `src/core/navigation/maneuver_tilt.h` (tilt-контур).

Подход — **ESKF** (Error-State Kalman Filter): фильтр оценивает не полное
состояние, а **ошибку** номинального решения БИНС. Номинал интегрируется
нелинейными уравнениями счисления, а фильтр — линейный и работает с малой
ошибкой.

---

## 1. Вектор состояния (15 компонент)

`x` (тип `Vector`, размер `KF_STATE = 15`) — вектор ошибок:

| Индексы | Компонента | Смысл |
|---|---|---|
| `0..2` | `δφ, δλ, δh` | ошибки координат (широта, долгота — рад; высота — м) |
| `3..5` | `δVn, δVh, δVe` | ошибки скорости, м/с |
| `6..8` | `δψ, δθ, δφ` | ошибки углов (курс, тангаж, крен), рад |
| `9..11` | `δba` | ошибки смещения акселерометра, м/с² |
| `12..14` | `δbg` | ошибки смещения гироскопа, рад/с |

Ковариация `P` — матрица 15×15 (`NavState::P`).

Ошибка вычитается из номинала при выводе (`makeResult` в `trajectory.h`):
`lat = lat − x[0]`, `V = V − x[3..5]`, `heading = heading − x[6]` и т. д.

---

## 2. Вектор измерений (9 компонент)

`KF_MEAS = 9`. Измерение — разность «БИНС − СНС»:

| Индексы | Разность |
|---|---|
| `0..2` | координаты (широта, долгота, высота) |
| `3..5` | скорости |
| `6..8` | углы (курс, тангаж, крен) |

Особенности формирования (`nav::step`, пункт 16):

- если `angle.dat` **нет** (`has_heading_ref == false`), в измерении курса
  подставляется **номинальный** курс БИНС — инновация курса нулевая, фильтр
  не тянет курс к нулю;
- тангаж/крен в измерение подставляются из **акселя** (tilt-контур), а не из
  СНС;
- инновация по углам нормализуется `normalize_angle` — корректно на стыке ±π.

Матрица наблюдения `H` (`H_matrix`) — «выборка» первых 9 компонент: `H = [I₉ | 0₉ₓ₆]`.

---

## 3. Шумы и матрицы

### 3.1. `Q` — шум процесса (`Qj_matrix`)

Диагональная матрица, построенная по моделям дрейфа:

| Блок | Значение | Смысл |
|---|---|---|
| координаты `0..2` | `0` | координаты меняются только через скорость |
| скорости `3..5` | `sig_a² · T` | шум акселерометра |
| углы `6..8` | `sig_g² · T` | шум гироскопа |
| смещение акселя `9..11` | `sig_ba² · T` | случайное блуждание `ba` |
| смещение гиро `12..14` | `sig_bg² · T` | случайное блуждание `bg` |

Значения `σ` (`KalmanConfig`, по умолчанию): `sig_g = 2.12428e-02`,
`sig_a = 1.5276`, `sig_bg = 1.05526e-05`, `sig_ba = 1.10162e-05`. `T` — шаг
времени.

Модель `Q` — «белый шум, проинтегрированный по шагу»: дисперсия ошибки растёт
линейно по `dt` для скорости/углов и как блуждание для смещений.

### 3.2. `R` — шум измерений (`Rj_matrix`)

Диагональная матрица 9×9:

| Блок | Значение |
|---|---|
| широта, долгота `0,1` | `sig_pos²` (`2.64401e-08` рад²; `sig_pos·R_EARTH ≈ 0.17` м) |
| высота `2` | `sig_h²` (`5.0` м) |
| скорости `3..5` | `sig_v²` (`4.81061e-02` м/с) |
| курс `6` | `sig_hdg²` (`1.23106e-03` рад) |
| тангаж `7` | `sig_pitch²` (из акселя, динамическая) |
| крен `8` | `sig_roll²` (из акселя, динамическая) |

`sig_pitch`/`sig_roll` не глобальны: их вычисляет tilt-контур на каждом такте
по доверию к акселю (`navigation_tilt.md`).

### 3.3. `F` — матрица перехода (`Fj_matrix`)

15×15, линеаризация ошибок на шаге `T`. Единичная диагональ плюс связи:

| Связь | Элемент | Формула (умножается на `T`) |
|---|---|---|
| `δφ ← δVn` | `(0,3)` | `1/R` |
| `δλ ← δVe` | `(1,5)` | `1/(R·cos φ)` |
| `δh ← δVh` | `(2,4)` | `1` |
| `δVh ← δh` | `(4,2)` | `2g/R` (градиент тяжести) |
| `δVn ← δVe` | `(3,5)` | `−2Ω·sin φ` |
| `δVh ← δVe` | `(4,5)` | `+2Ω·cos φ` |
| `δVe ← δVn` | `(5,3)` | `+2Ω·sin φ` |
| `δV ← δψ,θ,φ` | `(3..5, 6..8)` | `(n̂ × f_н)` |
| `δV ← δba` | `(3..5, 9..11)` | `C` |
| `δψ,θ,φ ← δbg` | `(6..8, 12..14)` | `e_rate` |

Пояснения:
- **Кориолисовы связи скоростей** `2Ω×δV` — малые, но присутствуют для полноты.
- **Ошибки ориентации → ошибки скорости**: через крестовое произведение
  `n̂ × f_н`, где оси поворота `n̂` соответствуют элементарным поворотам:
  `n_psi = {0, −1, 0}` (курс по часовой → ось вниз),
  `n_theta = {−sin ψ, 0, cos ψ}`,
  `n_gamma` — первый столбец `C`.
- **Смещение акселя → скорость**: через `C` (ошибка акселя переводится в nav).
- **Смещение гиро → ошибки углов**: через связывающую матрицу Эйлера `e_rate`
  (те же коэффициенты, что в `eulerRates`).

## 4. Предсказание (time update)

`ins::predict(T, lat, alt, C, f_nav, att, x, P)`:

```
F = Fj_matrix(T, lat, alt, C, f_nav, att)
x = F · x
P = F · P · Fᵀ + Q(T)
```

Вызывается один раз на такт ИМУ **после** обновления номинала (новые `lat`,
`att`, `C`).

---

## 5. Коррекция (measurement update)

`ins::correct(bins, sns, x, P, sig_hdg, sig_pitch, sig_roll, stats)`:

1. **Инновация** `z = y_БИНС − y_СНС`, углы нормализуются.
2. **Ковариация инновации** `S = H·P·Hᵀ + R`.
3. **Усиление** `K = P·Hᵀ·S⁻¹` (обращение `S` — Гаусс–Жордан с выбором
   ведущего элемента, `return_matrix`).
4. **Оценка** `x = x + K·(z − H·x)`; невязка по углам нормализуется.
5. **Ковариация — Joseph-форма**:
   ```
   P = (I − K·H)·P·(I − K·H)ᵀ + K·R·Kᵀ
   ```
   Вместо упрощённой `(I − K·H)·P`: Joseph-форма симметрична по построению и
   сохраняет положительную полуопределённость (упрощённая форма теряет
   симметрию и даёт отрицательные дисперсии).

После коррекции номинал обновляется инъекцией ошибок (`applyKalmanCorrections`,
`trajectory.h`): вычитаются `x[0..8]`, прибавляются `ba += x[9..11]`,
`bg += x[12..14]`, `x` обнуляется, `P` согласуется (`apply_reset_covariance`).

---

## 6. Диагностика согласованности: NIS/NEES

При коррекции (если передан `stats`, GUI-режим) считается
`CorrectionStats { nis, nees, dof = 9, valid }`:

```
NIS  = innovᵀ · S⁻¹ · innov            (S = H·P·Hᵀ + R)
NEES = innovᵀ · P_meas⁻¹ · innov       (P_meas — верхний блок P 9×9)
```

- Обе величины — хи-квадрат с 9 степенями свободы. У согласованного фильтра
  их среднее ≈ `dof = 9`, а отношение `NIS/NEES` ≈ 1 (NIS больше NEES, т. к.
  `S` включает `R`).
- `NEES` нормирует ту же невязку только по ковариации состояния (без шума
  измерения); сравнение `NIS` и `NEES` показывает, не «съеден» ли сигнал
  невязки моделью шума.
- Считаются **до** обновления `x` и `P` — на предсказанных значениях.
- В консольном прогоне `stats == nullptr`, поэтому вычислительный путь и файлы
  не меняются.

## 7. Tilt-контур (коррекция только тангажа/крена)

Помимо основной коррекции по СНС, на **каждом** такте ИМУ работает отдельная
коррекция по акселерометру, когда аппарат «успокоился»
(`ins::correctTilt`, `KF_TILT_MEAS = 2`):

- `H_tilt` выбирает `x[7]`, `x[8]`; `R_tilt = diag(sig_pitch², sig_roll²)`;
- `z = {pitch_б − pitch_аксель, roll_б − roll_аксель}` (нормализованные).

**Развязка от координат/скорости/курса:** строки `K` для `x[0..6]` обнуляются,
чтобы корреляционные члены `P·Hᵀ` не «протекали» в непогашенные ошибки
позиции/скорости/курса, которые живут между кадрами СНС. Tilt-коррекция трогает
только углы и смещения датчиков (`x[7..14]`).

Ковариация — тоже в Joseph-форме. После tilt-коррекции обнуляются только
`x[7], x[8]` (`applyTiltKalmanCorrections`), а если коррекция не применялась —
`x[7], x[8]` гасятся `clearTiltKalmanErrors`.

---

## 8. Согласование ковариации (reset)

`ins::apply_reset_covariance(P)` вызывается после каждой инъекции ошибок:

1. **Симметризация** `P ← (P + Pᵀ)/2` — после `predict`/`correct` симметрия
   нарушается на уровне `~1e-15`.
2. **Страховка диагонали:** отрицательные дисперсии заменяются на `1e-15`
   (источник — хвостовые вычитания в `(I−KH)·P` при малых `σ`).

В каноническом ESKF после reset нужно `P ← G·P·Gᵀ` с якобианом `G`. Для
аддитивных групп (координаты, скорости, смещения) `G = I`; для угловых Эйлеровых
компонент при корректной выставке (рассинхронизация < π/2) тоже `G ≈ I`.
Практический эффект функции — численное согласование `P`.

## 9. Размеры и константы

| Константа | Значение | Смысл |
|---|---|---|
| `KF_STATE` | 15 | размер вектора состояния |
| `KF_MEAS` | 9 | размер вектора измерений |
| `KF_TILT_MEAS` | 2 | размер измерения tilt-контура |

Коррекция по СНС выполняется не каждый такт, а **один раз на кадр СНС**
(`hold_ref.time != prev_gps_time`, см. `navigation.md`); предсказание и
tilt-коррекция — каждый такт ИМУ (200 Гц).
