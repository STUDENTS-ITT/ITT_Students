# Начальная выставка

Определение начальной ориентации и смещения акселерометра до запуска
счисления. Реализация — `src/core/navigation/aligner.hpp`,
`src/core/navigation/Aligner.cpp`.

Идея: пока аппарат стоит неподвижно, акселерометр измеряет **только силу
тяжести**, а гироскоп — **только вращение Земли**. По этим двум источникам можно
найти ориентацию без внешних данных (автономная выставка).

Контракт функции (`aligner.hpp`):

```cpp
void alignFromImuProvider(const AlignImuProvider &next,
                          double *Yaw, double *Pitch, double *Roll,
                          double *ba_x, double *ba_y, double *ba_z,
                          double lat_deg, double h, double iter,
                          bool write_dump = true);
```

где `next` — поставщик строк ИМУ (`time_s, wx, wy, wz, ax, ay, az`), `iter` —
время окончания выставки (с), `lat_deg`/`h` — широта и высота места.

Входные величины на выходе — **в радианах** (`Yaw`, `Pitch`, `Roll`), `ba` — в
м/с².

---

## 1. Тангаж и крен по акселерометру

В покое акселерометр измеряет реакцию на гравитацию: в связанной СК вектор
силы тяжести равен `g_nav = {0, g, 0}`, спроецированный обратно в тело:

```
f_б = (C_б^н)ᵀ · {0, g, 0}
```

Из этого:

```
pitch = asin(ax / g)
roll  = atan2(−az, ay)
```

(`pitch_smooth`, `roll_smooth` в `Aligner.cpp`). Аргумент `asin` защищён
ограничением `[−1, 1]` (`ax_norm_sm`), чтобы шум не дал NaN.

Знак `roll = atan2(−az, ay)` согласован с выбранной СК (Y — вверх, Z — правый
борт).

Ускорение `g` берётся по формуле Клеро с учётом широты и высоты:
`g = calculate_g(lat_deg·DEG_TO_RAD, h)` (численно то же, что
`utils::normalGravity`).

---

## 2. Курс по вращению Земли

Курс определяется по проекции вектора угловой скорости Земли на
горизонтальную плоскость. В навигационной СК:

```
ω_Земля = {U_EARTH·cos(lat), U_EARTH·sin(lat), 0}
```

Разворачиваем в связанную СК через известные `pitch` и `roll` и берём
географические компоненты «север» и «восток»:

```
Wn = Wx·cos θ − Wy·sin θ·cos φ + Wz·sin θ·sin φ      (север)
We = Wy·sin φ + Wz·cos φ                             (восток)
yaw = atan2(−We, Wn)
```

(`Wn_sm`, `We_sm`, `yaw_smooth`). Знак минус — из соглашения о курсе по часовой
стрелке.

Физический смысл: меридиональная составляющая вращения Земли «направлена» на
север, а её проекция на оси аппарата зависит от курса. При точном знании
`pitch`/`roll` угол курса восстанавливается однозначно. Точность курса
ограничена шумом гироскопа и **неснимаемым** смещением `bg` — поэтому начальная
ковариация курса масштабируется как `sig_bg / (cos(lat)·U_EARTH)` (см.
`estimation.md`).

Побочная реализация той же идеи есть в `ins::headingFromEarthRate(wx, wz) =
atan2(−wz, wx)` — вспомогательная оценка без учёта крена/тангажа; основная
выставка использует полные формулы выше.

## 3. Фильтрация показаний

Показания датчиков в покое всё равно шумят, а в начале записи возможны выбросы.
Последовательная обработка (`Aligner.cpp`):

1. **Медианный фильтр** `FastMedian` (окно 5, `aligner.hpp`) — подавление
   одиночных выбросов. Крайние два элемента копируются без фильтрации, в центре
   берётся медиана из 5 точек (пузырьковая сортировка).
2. **EMA-фильтр** `EMA_Filter` с коэффициентом
   `alpha = calculate_alpha(cutoff_freq, sample_rate)`:
   ```
   dt  = 1/sample_rate
   RC  = 1/(2π·cutoff_freq)
   alpha = dt/(RC + dt)
   ```
   Параметры в коде: `SAMPLE_RATE = 200` Гц, `CUTOFF_FREQ = 1` Гц.
   Фильтр работает **блоками** по `BUF_rot = 3000` отсчётов, сохраняя последнее
   значение между блоками (`last_Ax…last_Wz`) — сшивки на границах блоков нет.

Обратите внимание: финальные углы считаются **не** по сглаженным блокам
напрямую, а по **глобальным средним** (`Ax_sm / total_samples` и т. д.) — блоки
нужны для отладочного дампа `Aligner.dat` и промежуточных графиков, а среднее
накапливается по всем отсчётам до `iter`. Сырые углы (`raw_*`) считаются по
нефильтрованным данным — тоже только для дампа.

## 4. Рекурсивное среднее углов

Итоговые углы — среднее по времени мгновенных оценок
(`update_recursive_mean`):

```
n = 1:  mean = value
n > 1:  mean += (value − mean) / n
```

Это численно устойчивое среднее без хранения всех значений (сравните с
накоплением сумм для акселя/гироскопа — там суммы, потому что нужны ещё и
глобальные средние компонент).

---

## 5. Смещение акселерометра `ba`

После определения углов смещение находится как разность фактического среднего
показания и ожидаемого при данных углах:

```
C = bodyToNavMatrix(Yaw, Pitch, Roll)
f_expected = (C)ᵀ · {0, g, 0}
ba = f_mean − f_expected
```

(`f_mean = (Ax_sm, Ay_sm, Az_sm)/total_samples`). Это позволяет «обнулить»
постоянное смещение акселя ещё до фильтра (фильтр потом его уточняет через
`x[9..11]`).

---

## 6. Обработка форматов и потока

- Поставщик `AlignImuProvider` развязывает выставку от источника: файл
  (`get_angle_start`) или память (в `runSimulation` — обёртка над
  `IDataSource::nextImu`).
- Разбор строки `parseAlignImuRow` (`Aligner.cpp`) поддерживает оба формата:
  новый (`ЧЧ:ММ:СС.дробь wx wy wz ax ay az`, определяется по `':'`) и старый
  (`time_s timestamp_ns wx …`, через `sscanf` с пропуском второго столбца).
- `get_angle_start` открывает файл в **бинарном** режиме: байт `0x1A` в
  повреждённых наборах в текстовом режиме обрезал бы чтение.
- Выставка идёт до времени `iter`, после чего обрабатывается «хвост» буфера.
- Отладочный дамп `../data/processed/Aligner.dat` пишется **по возможности**
  (`write_dump`): если путь недоступен — пробует `data/processed/Aligner.dat`,
  если и он нет — молча продолжает без дампа (выставка не прерывается).

---

## 7. Порядок вызова в прогоне

В `runSimulation` (`simulation.cpp`) выставка выполняется **до** основного
цикла:

1. из `StartupNav.ini` (или первого отсчёта СНС) берутся координаты и время
   выставки;
2. `src->open()` — перемотка на начало;
3. `alignFromImuProvider(...)` над `nextImu` → `Yaw/Pitch/Roll/ba`;
4. `initialAlignment(lat, lon, alt, yaw, pitch, roll, ba)` формирует начальное
   состояние (`aligner.h`);
5. `observer->onAlignment(summary)` (для GUI), затем `src->open()` ещё раз —
   основной цикл.

Если `StartupNav.ini` нет, координаты берутся из первого отсчёта СНС, а время
выставки — `align_fallback_s` (по умолчанию 120 с) либо
`align_time_override_s` из настроек.

---

## 8. Ограничения

- Выставка предполагает **покой**: любое движение во время неё искажает и
  тангаж/крен (аксель), и курс (проекция вращения Земли).
- Курс определяется по очень малой величине `U_EARTH ≈ 7.29e-5` рад/с —
  сравнимой с шумом гироскопа; отсюда большая начальная неопределённость курса.
- Точность тангажа/крена ограничена смещением акселя и наклоном площадки.
- В коде нет обнаружения движения и автоматического продления выставки.
