# Теоретическая справка

Теория, на которую опирается код `esfcore`: системы координат и углы, уравнения
БИНС, выставка, оценивание (error-state фильтр Калмана) и комплексирование с СНС.

Документы написаны **по текущему коду**: каждая формула — та, что реально
считается в `src/core/`, с указанием файла. Исторические материалы
(`SINS/`, `Smoothing/`, `Documentation/`) полезны для вывода формул, но в ряде
мест расходятся с текущей реализацией (другие соглашения о знаках, другой блок
вертикального канала) — код важнее.

## Документы

| Документ | О чём |
|---|---|
| [`coordinate_frames.md`](coordinate_frames.md) | связанная и навигационная СК, углы Эйлера–Крылова, матрица `C_б^н`, кинематика углов |
| [`ins_equations.md`](ins_equations.md) | уравнения счисления: вредные ускорения, Кориолис, гравитация, интегрирование, модель Земли |
| [`alignment.md`](alignment.md) | выставка: определение тангажа/крена по акселю и курса по вращению Земли, фильтрация |
| [`estimation.md`](estimation.md) | ESKF 15 состояний: модель ошибок, матрицы `F`, `Q`, `R`, коррекция, NIS/NEES, reset |
| [`gnss.md`](gnss.md) | модель измерений СНС, отсев аномальных кадров (защита) |

Связь «теория ↔ код»: практическое описание модулей — в
[`../algorithm/README.md`](../algorithm/README.md).

## Обозначения

| Символ | Смысл |
|---|---|
| `ψ`, `θ`, `φ` | курс (heading), тангаж (pitch), крен (roll) |
| `C` или `C_б^н` | матрица перехода «связная → навигационная» |
| `Cᵀ` | матрица перехода «навигационная → связная» |
| `f_б`, `f_н` | кажущееся ускорение (удельная сила) в связной / навигационной СК |
| `ω` | угловая скорость |
| `Ω` (`U_EARTH`) | угловая скорость вращения Земли, `7.292115e-5` рад/с |
| `R` (`R_EARTH`) | средний радиус Земли, `6371e3` м |
| `φ_г` (`lat`) | широта места |
| `V_n, V_h, V_e` | скорости: Север, Вверх, Восток |
