# Навигация по интерфейсу imitator_gui

Подробная «карта» графического интерфейса `imitator_gui`: что где находится, какой
элемент за что отвечает и что нужно нажать, чтобы выполнить типовые действия.

Документ дополняет `USER_GUIDE.md`: там описан общий порядок работы, здесь —
детальная привязка к конкретным кнопкам, вкладкам и пунктам меню.

> Обозначения: пути и подписи элементов приведены в кавычках ровно так, как они
> видны в интерфейсе. Горячие клавиши выделены как `F5`, `Shift+F5`.

---

## 1. Запуск приложения

Способы запуска:

1. **Портативно** — двойной щелчок по `dist\imitator_gui.exe` (рекомендуется: все
   библиотеки Qt и runtime MinGW лежат рядом).
2. **Из сборки** — `imitator_gui.exe` из каталога сборки (`build\`).
3. **Из командной строки** — с опциями (см. ниже).

### 1.1. Ключи командной строки

| Ключ | Значение |
|------|----------|
| `-d, --data <dir>` | каталог с `imu.dat` / `gps.dat` / `angle.dat` / `StartupNav.ini` |
| `-o, --output <dir>` | каталог для `result.txt` / `reference.txt` / `errors.txt` |
| `-s, --settings <file>` | файл параметров фильтра (`settings.ini`) |
| `-t, --dark` | тёмная тема оформления |
| `--autostart` | сразу запустить расчёт при открытии окна |
| `--self-test` | без окна: выполнить расчёт и выйти (код 0 — успех, 1 — ошибка); для CI |
| `--self-test-timeout <sec>` | предельное время ожидания в режиме `--self-test` (по умолчанию 600 с) |
| `--self-test-report <file>` | файл отчёта о прогоне в режиме `--self-test` (с логом) |
| `--self-test-generate <dir>` | сгенерировать тестовый набор данных и выйти; для CI |
| `--export-matrices <dir>` | без окна: выгрузить статические матрицы фильтра (Q/R/P0/H) в каталог (csv/md/json) и выйти; для CI |
| `--tuning-report <config.json>` | без окна: собрать PDF-отчёт о подборе по конфигу тюнера (`tuner_config*.json`) из его `work_root` (`best_params.txt`, `eval.json`) и выйти |
| `--tuning-report-out <file.pdf>` | куда сохранить отчёт о подборе (по умолчанию — `reports/<набор>/tuning_<набор>.pdf`) |
| `-h, --help`, `-v, --version` | справка и версия |

При `--self-test` дополнительно проверяются чтение прогона из истории (SQLite),
сравнение прогонов, сборка сводного PDF-отчёта и экспорт статических матриц
фильтра (Q/R/P0/H) в csv/md/json.

### 1.2. Что происходит при старте

- Выполняется самопроверка: строится временный PDF и проверяется его сигнатура
  `%PDF`. При ошибке сведения попадают в «Лог».
- Читаются пользовательские настройки (`QSettings`): размеры/позиция окна, пути,
  флажки, тёмная тема, размеры экспорта.
- Восстанавливается геометрия окна; открывается окно 1400×860 (если в настройках
  нет сохранённой геометрии).
- В «Лог» пишутся: версия Qt, каталог данных, путь к `settings.ini`.

## 2. Общий вид окна

```
+---------------------------------------------------------------------------------------+
|  Прогон  Сравнение  Вид  Экспорт  Справка                  (строка меню)                |
+---------------------------------+-------------------------------------------------------+
|  ЛЕВАЯ КОЛОНКА                  |  ПРАВАЯ ЧАСТЬ (вкладки)                                |
|  ------------------------------ |  +--------------------------------------------------+  |
|  Панель управления:             |  | Графики | Данные | Параметры | Подбор | Лог     |  |
|    Каталог данных      [ ... ]  |  +--------------------------------------------------+  |
|    Каталог результатов [ ... ]  |  |                                                  |  |
|    settings.ini        [ ... ]  |  |   (содержимое выбранной вкладки)                 |  |
|    [x] Писать файлы             |  |                                                  |  |
|    [x] Телеметрия               |  |                                                  |  |
|    [x] В историю (SQLite)       |  |                                                  |  |
|    [Запустить][Пауза][Стоп]     |  |                                                  |  |
|    Темп [------o] максимум      |  |                                                  |  |
|    [============прогресс======] |  |                                                  |  |
|    Готово                       |  |                                                  |  |
|  ------------------------------ |  |                                                  |  |
|  Панель состояния:              |  |                                                  |  |
|    t = ...   такт ...   ожидание|  |                                                  |  |
|    Навигационные параметры      |  |                                                  |  |
|    Смещения датчиков            |  |                                                  |  |
|    СКО (из P): ...              |  |                                                  |  |
+---------------------------------+-------------------------------------------------------+
|  Строка состояния: текущий прогресс/сообщения           |   кэш вкл: 0/0 (0%)          |
+---------------------------------------------------------------------------------------+
```

- Окно разделено **сплиттером** на две части: слева — управление и состояние,
  справа — вкладки. Границу можно перетаскивать мышью (начальная ширина ~340 px
  слева и ~1000 px справа).
- Вся работа идёт через **строку меню** и **панели**; отдельной панели инструментов
  (toolbar) нет.
- Внизу — **строка состояния** (прогресс и сообщения) и постоянная **метка кэша**.

## 3. Строка меню

Меню открываются щелчком или с клавиатуры по мнемонике (`Alt` + подчёркнутая
буква): **П**рогон, **С**равнение, **В**ид, **Э**кспорт, **С**правка.

### 3.1. Меню «Прогон»

| Пункт | Действие |
|-------|----------|
| **Запустить** `F5` | начать расчёт по текущим настройкам (см. §12.1) |
| **Остановить** `Shift+F5` | запросить досрочную остановку расчёта (результаты до момента остановки сохраняются) |
| — разделитель — | |
| **Загрузить settings.ini…** | выбрать INI-файл и загрузить параметры фильтра в таблицу вкладки «Параметры»; сразу применяет их к ядру и сохраняет как текущий файл настроек |
| **Сохранить settings.ini** | сохранить параметры в текущий файл (если файл не задан — открывается диалог «Сохранить как») |
| **Сохранить settings.ini как…** | выбрать путь и сохранить параметры в новый INI-файл |
| — разделитель — | |
| **Сбросить параметры к умолчаниям** | сбросить таблицу параметров к значениям по умолчанию (с подтверждением) |
| **Применить параметры к фильтру** | применить правки таблицы к ядру (то же, что двойной щелчок по значению в таблице параметров) |
| — разделитель — | |
| **Сгенерировать тестовые данные...** | открыть диалог генерации набора данных (см. §12.2) |

### 3.2. Меню «Сравнение»

| Пункт | Действие |
|-------|----------|
| **Второй прогон из истории…** | выбрать из списка сохранённых прогонов второй (для наложения и разности) |
| **[ ] Показывать разность (текущий − второй)** | флажок; включает построение рядов разности. Недоступен, пока второй прогон не выбран |
| **Убрать сравнение** | сбросить выбранный второй прогон и режим разности. Недоступен, пока сравнение не задано |

Второй прогон добавляется на графики **пунктирными** линиями с суффиксом
`[прогон <id>]`. В режиме разности дополнительно строятся ряды `Δ …`.

### 3.3. Меню «Вид»

| Пункт | Действие |
|-------|----------|
| **Сбросить масштаб графика** | вернуть текущей вкладке-графику автоматический масштаб (для траектории — исходный вид) |
| **[ ] Тёмная тема** | переключить тёмное оформление (палитра + цвета графиков) |
| **[ ] Кэш кадров графиков** | включить/выключить кэширование отрисовки (по умолчанию включено) |

### 3.4. Меню «Экспорт»

| Пункт | Что сохраняет |
|-------|----------------|
| **График в изображение (PNG/JPG)…** | текущий график в `.png/.jpg/.bmp` |
| **График в SVG…** | текущий график в `.svg` (вектор) |
| **График в PDF…** | текущий график в `.pdf` |
| **Таблица результатов в CSV…** | сводную таблицу результатов прогона в `.csv` |
| **Данные активного графика в CSV…** | числовые данные рядов активного графика в `.csv` |
| **Матрицы фильтра (Q/R/P0/H)…** | статические матрицы фильтра ESKF для текущего датасета сразу в `.csv`, `.md`, `.json` |
| **Все графики…** | пакетный экспорт всех вкладок в выбранный каталог |
| **Анимация…** | GIF или последовательность PNG-кадров активного графика |
| **Лог в файл…** | содержимое вкладки «Лог» в текстовый файл |
| — разделитель — | |
| **Сводный отчёт в PDF…** | многоблочный отчёт (титул, метрики, графики) |

Все действия меню «Экспорт», кроме «Матрицы фильтра…», применяются к **текущей
активной вкладке** внутри «Графиков». Каталог и имя по умолчанию подставляются из
«Каталог результатов». Экспорт матриц относится к **текущему датасету** и не
зависит от активной вкладки.

> Контекстных меню по правому клику на графиках **нет** — экспорт доступен только
> через меню «Экспорт» и (для лога) кнопку «Сохранить…» на вкладке «Лог».

### 3.5. Меню «Справка»

| Пункт | Действие |
|-------|----------|
| **О программе** | окно с версией и кратким описанием |

## 4. Левая колонка — панель управления

Порядок элементов сверху вниз.

### 4.1. Пути

Каждое поле — строка ввода с кнопкой «**…**» справа:

| Поле | Что задаёт | Диалог кнопки «…» |
|------|------------|--------------------|
| **Каталог данных** | папку с `imu.dat`, `gps.dat`, `angle.dat`, `StartupNav.ini` | выбор существующего каталога |
| **Каталог результатов** | папку для `result.txt`, `reference.txt`, `errors.txt` | выбор существующего каталога |
| **settings.ini** | файл параметров фильтра | выбор файла `*.ini` |

- Изменение любого поля или флажка сразу сохраняется в пользовательские настройки
  (`QSettings`) и передаётся вкладке «Подбор» и вкладке «Данные».
- Пока идёт расчёт, поля путей заблокированы.

### 4.2. Флажки опций прогона

| Флажок | По умолчанию | Значение |
|--------|--------------|----------|
| **Писать файлы** | вкл | записывать `result.txt` / `reference.txt` / `errors.txt` в «Каталог результатов» (каталог создаётся при необходимости) |
| **Телеметрия** | вкл | передавать данные для графиков, таблицы результатов и панели состояния. Если снять — графики/таблица/состояние во время прогона не наполняются |
| **В историю (SQLite)** | вкл | сохранять прогон в базу истории для последующего открытия и сравнения |

### 4.3. Кнопки управления прогоном

| Кнопка | Когда активна | Действие |
|--------|---------------|----------|
| **Запустить** | пока расчёт не идёт | начать прогон |
| **Пауза** / **Продолжить** | во время расчёта | пауза/возобновление (переключатель; подпись меняется) |
| **Стоп** | во время расчёта | досрочная остановка |

> Кнопка панели называется «**Стоп**», а пункт меню — «**Остановить**» (`Shift+F5`);
> это одно и то же действие.

### 4.4. Регулятор темпа воспроизведения

Горизонтальный ползунок (позиции 0…6) и подпись справа. Значения темпа:

| Позиция | Подпись |
|---------|---------|
| 0 | «максимум» (расчёт быстрее реального времени; **по умолчанию**) |
| 1 | «1/32 от реального времени» |
| 2 | «1/16 от реального времени» |
| 3 | «1/8 от реального времени» |
| 4 | «1/4 от реального времени» |
| 5 | «1/2 от реального времени» |
| 6 | «1/1 от реального времени» |

Темп можно менять **во время** прогона — он применяется сразу. На паузе время темпа
не «накапливается».

### 4.5. Прогресс

- Прогресс-бар: процент выполнения; если общее число отсчётов неизвестно, полоса
  работает в неопределённом режиме.
- Текст слева: «Готов» до старта; во время прогона — «Прогон…», затем «`N%, t = X с`»
  (или «`t = X с`» без процента).

## 5. Левая колонка — панель состояния

Отображает последние данные (обновляется с частотой ~10 Гц во время прогона).

### 5.1. Заголовок

| Элемент | Содержимое |
|---------|------------|
| `t = …` | текущее модельное время, с |
| `такт …` | номер такта ИМУ |
| статус | «ожидание» → «счисление» → «коррекция СНС» (в момент коррекции) |

### 5.2. Таблица «Навигационные параметры»

Колонки: «Параметр», «Значение», «Ед.». Строки:

| Параметр | Ед. | Разряды |
|----------|-----|---------|
| Широта | ° | 9 |
| Долгота | ° | 9 |
| Высота | м | 3 |
| Курс | ° | 4 |
| Тангаж | ° | 4 |
| Крен | ° | 4 |
| Vn | м/с | 4 |
| Vh | м/с | 4 |
| Ve | м/с | 4 |

### 5.3. Таблица «Смещения датчиков (после коррекции)»

Колонки: «Датчик», «Компонента», «Оценка». Шесть строк: акселерометр X/Y/Z
(`м/с²`) и гироскоп X/Y/Z (`рад/с`), по 6 знаков.

### 5.4. Строка точности

«СКО (из P): горизонт … м, высота … м; курс …°, тангаж …°, крен …°» — оценка
точности по диагоналям ковариации `P`.

До первого прогона панель показывает «ожидание», «Точность: —».

## 6. Правая часть — вкладка «Графики»

Вкладка «Графики» — контейнер с восемью вложенными вкладками:

`Траектория` · `Координаты` · `Углы` · `Скорости` · `Ошибки x` · `Инновации СНС` ·
`Ковариация P` · `Согласованность`

Активна всегда ровно одна; перерисовывается только она (поэтому переключение вкладок
дёшево). Данные пересобираются при переключении и при поступлении новой телеметрии.

### 6.1. Навигация по любому графику (мышь)

| Действие | Результат |
|----------|-----------|
| **Колесо мыши** над областью графика | зум к точке под курсором |
| **Колесо + Ctrl** | зум только по оси X (время) |
| **Колесо + Shift** | зум только по оси Y (величина) |
| **Левый драг** внутри области | панорамирование (курсор «закрытая рука») |
| **Двойной щелчок** | сброс к автоматическому масштабу |
| **Наведение мыши** | перекрестие с подсказкой значений в ближайшей точке |
| **Меню «Вид → Сбросить масштаб графика»** | то же, что двойной щелчок |

Пошаговое масштабирование — на «щелчок» колеса (множитель 0.8). После любого
зума/панорамирования автоматический масштаб по соответствующей оси выключается;
двойной щелчок возвращает авто-режим.

### 6.2. Кэш кадров

- При включённом кэше содержимое графика рисуется один раз и переиспользуется, пока
  не изменятся данные, диапазоны осей, состав рядов или размер виджета.
- Перекрестие рисуется **поверх** кэша и на содержимое кэша не влияет.
- Переключение — «Вид → Кэш кадров графиков».
- Счётчики — справа в строке состояния: «кэш вкл/выкл: попаданий/промахов (проценты)».

### 6.3. Вложенная вкладка «Траектория»

- Горизонтальная ось — восток (м), вертикальная — север (м), от точки старта
  (топографическая проекция).
- Траектория БИНС — сплошная линия; точки СНС — маркеры; эталон (при наличии) —
  отдельные точки.
- Кнопки «Сбросить масштаб»/двойной щелчок возвращают исходный вид.

### 6.4. Вложенная вкладка «Координаты» (заголовок «Координаты и высота»)

- Оси: «Время, с» / «°, м».
- Если известна точка старта: ряды «Север, м», «Восток, м» (в метрах от старта),
  иначе — «Широта, °», «Долгота, °». Плюс «Высота, м».

### 6.5. Вложенная вкладка «Углы» (заголовок «Углы ориентации»)

- Оси: «Время, с» / «°».
- Ряды: «Курс, °», «Тангаж, °», «Крен, °».

### 6.6. Вложенная вкладка «Скорости» (заголовок «Скорости»)

- Оси: «Время, с» / «м/с».
- Ряды: «Vn, м/с», «Vh, м/с», «Ve, м/с».

### 6.7. Вложенная вкладка «Ошибки x»

- Заголовок: «Вектор ошибок x (кадры коррекции СНС)».
- Оси: «Время, с» / «ошибка». Легенда включена.
- 15 рядов `x0…x14` (широта, долгота, высота, скорости, углы, смещения ДУС/акселерометров),
  отмечены маркерами; вертикальные линии — моменты коррекции СНС.
- Ряды, у которых максимум |y| ниже порога 1e-18, скрываются автоматически.

### 6.8. Вложенная вкладка «Инновации СНС»

- Заголовок: «Инновации измерений СНС». Оси: «Время, с» / «измерение − прогноз».
- Ряды: `Δширота`, `Δдолгота`, `Δвысота`, `ΔVn`, `ΔVh`, `ΔVe`, `Δкурс`, `Δтангаж`,
  `Δкрен` — но **только ненулевые** (компоненты без данных не рисуются).

### 6.9. Вложенная вкладка «Ковариация P»

- Заголовок: «Диагонали ковариации P». Оси: «Время, с» / «Pᵢᵢ».
- 15 рядов `P00…P1414` (диагональ ковариации по всем тактам ИМУ).
- Порог отображения 1e-12 — нулевые компоненты не показываются.

### 6.10. Вложенная вкладка «Согласованность»

- Заголовок: «Согласованность фильтра (NIS / NEES)». Оси: «Время, с» / «статистика».
- Ряды: пунктирная опорная линия «ожидание (dof)» (dof = 9), «NIS», «NEES»;
  вертикальные линии — моменты коррекции.

> **Легенда** на графиках только отображает соответствие цветов и подписи; по ней
> **нельзя** кликать, чтобы скрыть/показать ряд.

## 7. Вкладка «Данные»

Показывает входные файлы выбранного каталога и таблицу результатов прогона.

**Слева — дерево «Входные данные»:**
`imu.dat`, `gps.dat`, `angle.dat`, `StartupNav.ini` — с размером и числом строк;
отсутствующие файлы подсвечиваются. Под деревом — сводка: каталог, число строк ИМУ
и оценка длительности, список найденных файлов.

**Справа — таблица результатов:**
- Поле **«Поиск:»** — фильтр по любой колонке (подстрока, регистр не важен).
  Плейсхолдер: «координаты, высота, курс…».
- Спинбоксы **«с»** и **«по»** — ограничение по интервалу времени (значения 0 =
  без ограничения).
- Кнопка **«Сбросить»** — очищает поиск и интервал.
- Строка под таблицей: «строк: N из M» (и пометка «фильтр применён»).
- Заголовки колонок сортируемы (щелчок по заголовку).

## 8. Вкладка «Параметры»

Содержит две вложенные вкладки и кнопку меню пресетов.

### 8.1. Вложенная вкладка «Параметры»

- Таблица параметров фильтра (группы: данные, начальные условия, параметры ESKF,
  интегрирование/выравнивание, прочие).
- **Двойной щелчок по значению** — применить параметры к фильтру (то же, что пункт
  меню «Прогон → Применить параметры к фильтру»).
- Кнопка **«Пресеты ▾»** — меню:
  - **Сохранить как пресет…** — сохранить текущие параметры в `presets/*.ini`;
  - **Загрузить пресет…** — загрузить INI-пресет (сразу применяется);
  - **Удалить пресет…** — удалить пресет из каталога;
  - ниже, после разделителя, — список сохранённых пресетов (щелчок загружает и
    применяет выбранный).

### 8.2. Вложенная вкладка «История»

- Таблица сохранённых прогонов (SQLite): `id`, имя (дата/время + каталог данных),
  дата создания, число тактов, число коррекций, время расчёта, каталог данных.
- Поле **«Фильтр по названию или каталогу…»** — фильтр по всем видимым колонкам.
- Сортировка по любому заголовку; по умолчанию — по дате создания (новые сверху).
- **Двойной щелчок по строке** — открыть прогон: результаты подгружаются на графики
  и в таблицу без пересчёта. Если для прогона сохранён снимок параметров, появляется
  предложение применить их к таблице и фильтру.
- Выбор строк — **одиночный** (наложения нескольких прогонов внутри этой таблицы нет;
  для второго прогона используйте меню «Сравнение»).

### 8.3. Подсказка под таблицами

«Двойной щелчок по значению — применить параметры к фильтру. Текущие значения
записываются в settings.ini при сохранении.»

## 9. Вкладка «Подбор»

Запускает подбор коэффициентов фильтра Калмана скриптом
`tools/kalman_tuner/tune_kalman.py` отдельным процессом.

Элементы:

| Элемент | Назначение |
|---------|------------|
| **Каталог данных** (поле + кнопка «Обзор…») | набор, по которому идёт подбор |
| **Python** | команда/путь к интерпретатору с `numpy`/`scipy` (по умолчанию `python`) |
| **Режим** (список) | «Полный подбор», «Быстрый (--quick)», «Глобальная сетка (--global-only)» |
| **Конфиг** (список) | `tuner_config*.json` рядом со скриптом (у наборов `dataset_shum` — свой конфиг, например `tuner_config.static300.json`) |
| **Запустить подбор** | запустить процесс подбора |
| **Остановить** | принудительно завершить процесс |
| **Применить пресет…** | выбрать INI-пресет и применить его к параметрам фильтра |
| **Отчёт о подборе…** | собрать PDF-отчёт по `best_params.txt` и `eval.json` выбранного конфига |
| Консоль | поток вывода тюнера |
| Подсказка внизу | пояснение про конфиг `tuner_config*.json` и пресеты `presets/tuned*.ini` |

Пошагово (см. §12.9):
1. Выберите конфиг подбора (каталог данных при этом подставляется из конфига) и
   при необходимости уточните путь к Python.
2. Выберите режим.
3. Нажмите «Запустить подбор» — кнопки и поля блокируются, идёт вывод.
4. По завершении становятся доступны «Остановить» (выкл.), «Применить пресет…»
   (если пресет найден) и «Отчёт о подборе…».
5. Нажмите «Применить пресет…» и выберите INI (по умолчанию предлагается
   `presets/tuned.ini` или путь, о котором сообщил тюнер).
6. Нажмите «Отчёт о подборе…», укажите файл — приложение соберёт PDF по итогам
   подбора. Отчёт собирайте сразу после подбора: каталоги `eval.json` при
   следующем запуске тюнера перезаписываются.

Параметры поиска берутся из выбранного конфига `tuner_config*.json` рядом со
скриптом. Полный режим может занимать десятки минут; быстрый и глобальная
сетка — существенно меньше.

## 10. Вкладка «Лог»

Журнал сообщений ядра и приложения.

| Элемент | Действие |
|---------|----------|
| **Очистить** | очистить журнал |
| **Сохранить…** | сохранить журнал в текстовый файл (`*.txt` / `*.log`) |
| **[x] Прокрутка** | авто-прокрутка к последним строкам (включена) |

Уровни сообщений подсвечиваются цветом: обычные, `[ВНИМАНИЕ]`, `[ОШИБКА]`. Шрифт —
моноширинный (Consolas). Буфер хранит до 5000 строк.

## 11. Строка состояния

- Слева — краткие сообщения: «Готово», «Прогон выполняется…», «Пауза»,

## 12. Типовые сценарии (что нажимать)

### 12.1. Первый прогон

1. «Каталог данных» → кнопка «**…**» → выберите папку с `imu.dat`, `gps.dat`,
   `angle.dat`, `StartupNav.ini`.
2. При необходимости задайте «Каталог результатов» и «settings.ini».
3. Откройте вкладку **«Параметры»** и проверьте/задайте параметры (двойной щелчок
   по значению применяет к фильтру; «Пресеты ▾ → Загрузить пресет…» — быстрый старт).
4. Нажмите **«Запустить»** (или `F5`). Следите за прогрессом и вкладкой «Лог».
5. По завершении смотрите вкладку **«Графики»** (переключайте вложенные вкладки) и
   панель состояния.

> Если заранее выбран вариант `--autostart`, расчёт стартует сразу при открытии окна.

### 12.2. Сгенерировать тестовые данные

1. Меню **«Прогон → Сгенерировать тестовые данные...»**.
2. В диалоге задайте: «Имя набора» (`square_test`), «Каталог вывода», «Частота ИМУ,
   Гц» (200), «Частота СНС, Гц» (10), «Частота углов, Гц» (10), «Выставка (покой),
   с» (120).
3. «Обзор...» — выбор каталога вывода. Если там уже есть `imu.dat`, будет запрос на
   перезапись.
4. Нажмите OK. Генерация идёт в фоне (неопределённый прогресс). По завершении
   создаются `imu.dat`, `gps.dat`, `angle.dat`, `truth.txt`, `StartupNav.ini`;
   «Каталог данных» переключается на новый набор.

### 12.3. Пауза и темп

- Во время прогона: **«Пауза»** — остановить расчёт (подпись становится
  «Продолжить»), **«Стоп»** — завершить досрочно.
- **Ползунок темпа** — замедлить/ускорить воспроизведение на ходу.
- «Продолжить» — возобновить.

### 12.4. Открыть сохранённый прогон из истории

1. Вкладка **«Параметры» → «История»**.
2. (Необязательно) отфильтруйте/отсортируйте список.
3. **Двойной щелчок** по нужной строке — результаты загрузятся на графики.
4. Если предложено применить параметры прогона — нажмите «Применить» или «Cancel».

### 12.5. Сравнить два прогона

1. Сначала откройте/выполните основной прогон (текущий).
2. Меню **«Сравнение → Второй прогон из истории…»** — выберите второй прогон.
3. На графиках появятся пунктирные ряды второго прогона.
4. По желанию включите флажок **«Показывать разность (текущий − второй)»**.
5. Для сброса — **«Убрать сравнение»**.

### 12.6. Экспорт графиков

- Один график: выберите активную вложенную вкладку → меню **«Экспорт»** →
  «График в изображение (PNG/JPG)…», «График в SVG…» или «График в PDF…».
- Все графики: **«Экспорт → Все графики…»** — выберите каталог и формат
  (PNG/JPG/SVG/PDF); показывается прогресс, экспорт можно прервать.

### 12.7. Экспорт данных и лога

- **«Экспорт → Таблица результатов в CSV…»** — таблица результатов.
- **«Экспорт → Данные активного графика в CSV…»** — ряды текущего графика.
- **«Экспорт → Матрицы фильтра (Q/R/P0/H)…»** — статические матрицы фильтра
  (Q, R, P0, H) для текущего датасета; сохраняются три файла `.csv`, `.md`,
  `.json` в выбранный каталог (σ из вкладки «Параметры», широта из
  `StartupNav.ini`, шаг T — медиана интервалов между отсчётами ИМУ).
- **«Экспорт → Лог в файл…»** или кнопка **«Сохранить…»** на вкладке «Лог».

### 12.8. Анимация и сводный отчёт

- **«Экспорт → Анимация…»**: в диалоге — «Формат» (GIF-файл / PNG-кадры), «Кадров в
  секунду», «Число кадров», «Ширина, px», «Высота, px», «Окно времени» (нарастающее
  или скользящее с шириной окна в %). Затем укажите файл GIF или каталог PNG-кадров.
- **«Экспорт → Сводный отчёт в PDF…»**: укажите путь `.pdf`. Отчёт включает титульный
  лист, сводку NIS/NEES (dof = 9), RMS/максимумы ошибок по 15 компонентам, таблицу
  NIS/NEES по времени и блоки графиков: для каждой величины — сам график и график её
  ошибки (отклонения от истины или эталона СНС).

### 12.9. Подбор коэффициентов и пресеты

1. Вкладка **«Подбор»**: выберите **конфиг** (`tuner_config*.json`), каталог данных
   и Python, при необходимости — «Режим».
2. **«Запустить подбор»** → дождитесь завершения (следите за консолью).
3. **«Отчёт о подборе…»** → укажите PDF: приложение соберёт отчёт по итогам
   подбора (метрики, подобранные σ, сходимость J, чувствительность). Собирайте
   отчёт сразу после подбора — `eval.json` перезаписываются следующим запуском.
4. **«Применить пресет…»** → выберите `presets/tuned.ini` (или другой INI).
   Параметры попадут в таблицу «Параметры» и в фильтр, а также в `settings.ini`.
5. Для повторного запуска с подобранными параметрами — «Запустить»/`F5`.

### 12.10. Оформление и производительность

- **«Вид → Тёмная тема»** — тёмная палитра и цвета графиков.
- **«Вид → Кэш кадров графиков»** — ускоряет перерисовку при больших данных.
- **«Вид → Сбросить масштаб графика»** — вернуть авто-масштаб текущей вкладки.

## 14. Замечания и ограничения

- **Контекстных меню нет.** Правый клик по графику/таблице ничего не открывает;
  экспорт — только через меню «Экспорт».
- **Легенда графиков не кликабельна** — ряды скрываются автоматически по порогу
  отображаемости, вручную — нельзя.
- **История — одиночный выбор.** Наложение нескольких прогонов задаётся меню
  «Сравнение» (второй прогон), а не выделением строк в таблице истории.
- **Телеметрия.** При снятом флажке «Телеметрия» во время прогона не наполняются
  графики, таблица результатов и панель состояния (файлы результатов при этом могут
  писаться, если включён «Писать файлы»).
- **Геометрия окна** и все настройки сохраняются автоматически в `QSettings` и
  восстанавливаются при следующем запуске.
