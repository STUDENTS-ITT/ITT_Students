# Отчёт: подбор коэффициентов фильтра Калмана (9 наборов)

Сводный отчёт по полному прогону подбора коэффициентов ESKF (этап 7 плана).
Отчёт собран из артефактов `tools/kalman_tuner/full_runs/`.

> Для знакомства с методиками 13A/13B/13C/13G (что и как подбирается, размер
> сетки, почему в 13C больше точек с отклонениями) см.
> `docs/kalman_tuning_methods.md`.

- **Дата прогона:** 2026-10-10 (все 9 наборов завершились успешно, exit=0).
- **Инструмент:** `tools/kalman_tuner/` (перенос оптимизатора `tune_kalman_v3.py`).
- **Данные:** `ITT_Students-Katya/dataset_shum/<набор>` (синтетика с эталоном `truth.txt`).
- **Исполняемый файл:** `build/src/console/imitator.exe`.

## Метод

- **Метрика:** `J = P95(pos)/5.0 + P95(vel)/0.5 + P95(hdg)/1.0 + 0.05·Mean + 0.005·u² + 0.5·P99.9(pos@200Hz)/5.0` (v3).
- **Горизонт:** `skip=130 c`, split `train=60%`, `workers=8`.
- **Оптимизация:** Sobol-разведка (65 точек, ранний стоп после 16 нейтральных
  подряд) → полировка Nelder-Mead; старт у `u=0`; фиксированный SEED
  (воспроизводимость).
- **Коэффициенты (8):** `sigma_g`, `sigma_a`, `sigma_bg`, `sigma_ba`, `sigma_pos`,
  `sigma_h`, `sigma_v`, `sigma_ang` (последний — `sig_hdg`).

## Этап 13C — робастность хвоста (окна ~5 с, выбросы, куртозис)

Реализовано **только в метрике тюнера** (`tools/kalman_tuner/tune_kalman.py`),
без изменений `core`/консоли. В `compute_error` добавлены:

* оконный квантиль `P99.9` по тактам ИМУ (200 Гц): ряд режется на окна
  `metric.window_s` (по умолчанию 5 с), в каждом берётся `P99.9`; берутся худшее
  и среднее окно отдельно для train/valid — так локальный артефакт виден
  отдельно от «фонового» хвоста;
* доля выбросов (`metric.outlier_pos_m`, по умолчанию 1 м) на 200 Гц;
* моменты распределения ошибки позиции (асимметрия, куртозис; нормальный ≈ 3);
* член J по худшему окну включается `metric.consistency_weight` (по умолчанию
  **0.0** — член выключен и J бит-в-бит совпадает с прежним; проверено: при
  весе 0 ΔJ=0, при весе 0.1 ΔJ = 0.1·win_q/TOL_POS).

Все новые величины попадают в `eval.json` (ключи `win_q_*`, `outlier_frac_*`,
`kurt_pos_*`, `n_win_*`), поэтому оконная диагностика доступна и офлайн по
сохранённым оценкам. Отдельный инструмент отчёта — `13C_tail_report.py`.

- Композитный `J_valid` и позиция расходятся: на `spiral_climb` 13B даёт
