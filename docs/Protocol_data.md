# ITT_Students - Комплексирование видео, навигационной системы и БИНС

## Процесс реализации src/main.cpp
1) Задаём путь базовой директории, а также имена считываемых файлов
2) Склеиваем и получаем пути к файлам
3) Инициализируем углы ориентации (Эйлера-Крылова)
4) Вызываем функцию `get_angle_start` получния начальных углов курса, крена , тангажа. 
на вход:
- Углы (переменные для записи)
- Полученные ранее пути

на выход:
- Значения углов

### Процесс реализации src/navigation/Aligner.cpp
(Реализация функции `get_angle_start`)
1) Инициализируем высоту, широту и открываем файл с навигационными данными `Nav.dat`:
- Пропускаем вспомогательные данные
- Читаем широту и высоту
2) Инициализируем время выставки и открываем конфигурационный файл `StartupNav.ini`:
- Пропускаем вспомогательные данные
- Читаем время выставки
3) Рассчитываем g с поиощью ф-ции `calculate_g`
4) Открываем файл `IMU.dat`:
- Пропускаем вспомогательные данные
5) Инициализируем частоты: измерений IMU, среза фильтра, а также вспомогательные параметры. Создаём файл для записи промежуточных
и отфильтрованных параметров `Aligner.dat` :
- Записываем вспомогательные данные
- Инициализируем время, ускорения, угловые скорости
6) Основной цикл получния начальных углов курса, крена , тангажа.
по блочно:
- Читаем время, ускорения и угловые скорости из файла `IMU.dat`
- Для экспоненциального усреднения рассчитываем коэфф. alpha, с поиощью ф-ции `calculate_alpha`
- Фильтруем с помощию ф-ий `FastMedian` и `EMA_Filter`
- Рассчитываем по формулам углы
- Записываем их и вспомогательные данные в файл `Aligner.dat`
- Рекурсионно расчитываем средние значения углов, с поиощью ф-ции `update_recursive_mean`
7) Записываем накопленные средние значения в выходные параметры

### Описание параметров функции
![alt text](image.png)  
`get_angle_start` Главная функция расчёта начальных углов ориентации (Курс, Тангаж, Крен):
- `Yaw` Указатель на результирующий курс (рыскание).
- `Pitch` Указатель на результирующий тангаж.
- `Roll` Указатель на результирующий крен.
- `IMU_path` Путь к файлу с данными ИМУ (ускорения и угловые скорости).
- `Nav_path` Путь к файлу с навигационными данными (координаты, широта, высота).
- `StartupNav_path` Путь к конфигурационному файлу.
