# Руководство пользователя imitator_gui

## 1. Назначение
Программа imitator_gui предназначена для анализа, моделирования и обработки результатов полётовых экспериментов в составе комплекса «ИТТ-Студенты». Приложение реализует графический интерфейс для работы с фильтром оценивания состояния (ESKF/ИНС-СНС), позволяет загружать исходные данные полёта, выполнять расчёт, визуализировать траектории и ошибки оценивания, проводить сравнение различных прогонов, экспортировать графики и формировать сводный отчёт в PDF.

## 2. Возможности
- Выполнение расчёта оценки состояния по данным ИМУ и СНС (той же моделью, что и консольный `imitator`).
- Генерация синтетических тестовых наборов (ИМУ/СНС/углы/эталон) без внешних данных.
- Визуализация траектории, координат, скоростей, углов ориентации, ошибок оценивания, инноваций СНС и ковариации.
- Анализ качества фильтрации: NIS/NEES (при наличии эталонных данных), RMS и максимальные значения ошибок по компонентам.
- Сравнение прогонов: наложение кривых и режим разности (текущий − второй).
- Подбор коэффициентов фильтра Калмана и применение готовых пресетов.
- Кэширование кадров графиков для плавной навигации при большом объёме данных.
- Экспорт: отдельные графики (PNG/JPG/SVG/PDF), пакетный экспорт всех графиков, анимация (GIF или PNG-кадры), таблицы и ряды в CSV, матрицы фильтра (Q/R/P0/H), лог в файл, сводный PDF-отчёт.
- Сохранение/восстановление параметров расчёта в `settings.ini`.
- История прогонов (SQLite) с возможностью повторного открытия и сравнения.
- Портативный запуск без установки Qt (папка `dist\`).

## 3. Системные требования
- Операционная система Windows 10/11 (x64).
- Достаточно свободного места на диске для сохранения результатов, анимаций и PDF-отчётов.
- Права на чтение входных данных и запись выходных файлов.
- Для режима подбора коэффициентов — установленный Python с пакетами `numpy`/`scipy`.

## 4. Структура поставки
- `imitator_gui.exe` — основное графическое приложение.
- `imitator.exe` — консольная версия для проверки/сверки результатов.
- Папка `dist\` — полностью портативная сборка (содержит все необходимые DLL, плагины Qt и MinGW runtime). Предназначена для запуска двойным щелчком.
- `docs\user_manual\USER_GUIDE.md` — настоящее руководство.
- `USER_GUIDE.md` — копия руководства в корне проекта.
- `docs\user_manual\README.txt` — описание форматов входных/выходных файлов.

## 5. Запуск программы
Способы запуска:
1. **Двойным щелчком (портативный)** — запустить `dist\imitator_gui.exe`. Рекомендуется использовать именно папку `dist\`.
2. **Из папки сборки** — запустить `imitator_gui.exe` из каталога сборки.
3. **Из командной строки** — `imitator_gui.exe` в нужном рабочем каталоге.

При запуске автоматически выполняется самопроверка (создаётся временный PDF-файл с проверкой сигнатуры `%PDF`). При успешном прохождении самопроверки открывается основное окно, иначе в окне/логе выводится информация об ошибке.

**Рабочий каталог.** Рекомендуется запускать приложение в изолированном рабочем каталоге или использовать папку `dist\`. Если одновременно запускать консольный `imitator` и `imitator_gui` из одного рабочего каталога, они будут записывать выходные файлы (`result.txt`, `reference.txt`, `errors.txt`, а также служебные файлы в `tools\`) в один и тот же каталог — это может привести к перезаписи результатов. Для корректной сверки паритета используйте разные рабочие каталоги.

## 6. Сквозной сценарий: загрузить → прогнать → сравнить → PDF
Ниже — типовой полный цикл работы. Детали каждого шага приведены в последующих разделах.

1. **Загрузить данные.** На панели управления слева укажите **каталог данных** (кнопка «Обзор…») — папку, где лежат `imu.dat`, `gps.dat`, `angle.dat` и (при наличии) `StartupNav.ini`. При необходимости укажите **каталог результатов**. Данные можно подготовить самостоятельно (раздел 8) или сгенерировать (раздел 9).
2. **Проверить параметры.** Перейдите на вкладку **«Параметры»** и задайте начальные условия, ковариации шумов и параметры интегрирования/выравнивания. Изменённые параметры можно сохранить в `settings.ini` (раздел 10).
3. **Прогнать.** Нажмите **«Запустить»** (или меню **«Прогон → Запустить»**, `F5`). Ход расчёта отображается в строке состояния и на вкладке **«Лог»**. По завершении на вкладке **«Графики»** появятся результаты, а в истории — новая запись (раздел 12).
4. **Сравнить.** Чтобы сопоставить два прогона, выберите текущий прогон, затем меню **«Сравнение → Второй прогон из истории…»** и укажите второй прогон. При необходимости включите флажок **«Показывать разность (текущий − второй)»**. Наложение кривых доступно также множественным выбором в истории (раздел 13).
5. **Экспортировать и получить PDF.** Экспортируйте нужный график или все графики (PNG/JPG/SVG/PDF), при необходимости сделайте анимацию (GIF/PNG-кадры) и сформируйте сводный отчёт: меню **«Экспорт → Сводный отчёт в PDF…»** (раздел 14).

## 7. Основное окно
Интерфейс разделён на две основные области, разделённые перетаскиваемым сплиттером:

**Левая колонка — управление и состояние:**
- Панель управления: каталог данных, каталог результатов, файл настроек, кнопки «Запустить» / «Пауза» / «Остановить», флажки опций записи (файлы, телеметрия, сохранение в историю), регулятор темпа воспроизведения, прогресс-бар.
- Панель состояния: сводка по текущему/последнему прогону.

**Правая часть — вкладки:**
- **«Графики»** — вложенные вкладки: Траектория, Координаты, Углы, Скорости, Ошибки x, Инновации СНС, Ковариация P, Согласованность.
- **«Данные»** — обзор входных файлов выбранного каталога данных.
- **«Параметры»** — таблица параметров расчёта.
- **«Подбор»** — запуск подбора коэффициентов фильтра (раздел 15).
- **«Лог»** — журнал сообщений приложения.

Строка состояния в нижней части окна отображает текущий прогресс расчёта, сообщения о ходе работы и результаты операций (успех/ошибка).

Меню: **Прогон**, **Сравнение**, **Вид**, **Экспорт**, **Справка**.

> Подробная «карта» интерфейса — какая кнопка/вкладка/пункт меню за что отвечает и
> что нажимать в типовых сценариях — приведена в `docs\user_manual\NAVIGATION.md`.

## 8. Подготовка исходных данных
Для проведения расчёта необходимо подготовить входные файлы в формате, используемом в проекте (подробное описание столбцов и единиц — в `docs\user_manual\README.txt`):
- **Данные ИМУ** (`imu.dat`) — измерения акселерометров и гироскопов.
- **Данные СНС** (`gps.dat`) — навигационные измерения.
- **Углы ориентации** (`angle.dat`, необязательно) — стыкуются с СНС по времени.
- **`StartupNav.ini`** (необязательно) — координаты и время выставки.
- **Эталонные данные** (необязательны) — используются для вычисления ошибок оценивания (NEES/NIS, RMS, максимумы). При их отсутствии часть диагностических графиков/показателей может быть недоступна.

Пути к файлам указываются через панель управления (каталог данных). Рекомендуется размещать данные в логически структурированных папках (например, `data/raw/`, `run_hk/data/raw/` в соответствии с исходным проектом).

## 9. Генерация тестовых данных
Меню **«Прогон → Сгенерировать тестовые данные…»** создаёт синтетический набор входных данных без внешних источников.

В диалоге задаются:
- **Имя набора** (по умолчанию `square_test`).
- **Каталог вывода** (по умолчанию — текущий каталог данных).
- **Частота ИМУ, Гц** (по умолчанию 200).
- **Частота СНС, Гц** (по умолчанию 10).
- **Частота углов, Гц** (по умолчанию 10).
- **Выставка (покой), с** (по умолчанию 120) — длительность начального участка покоя, обязательного для работы выравнивателя.

Профиль движения фиксирован (покой → разгон/движение → поворот → движение → остановка). Если в каталоге вывода уже есть `imu.dat`, программа запросит подтверждение перезаписи.

Генерация выполняется в фоне (показывается неопределённый прогресс). По завершении создаются `imu.dat`, `gps.dat`, `angle.dat`, `truth.txt` (эталон), `StartupNav.ini`; в лог выводится число сгенерированных отсчётов, а дерево входных данных обновляется на новый каталог.

## 10. Настройка параметров
Вкладка **«Параметры»** объединяет следующие группы:
- **Данные** — выбор файлов ИМУ/СНС и (при наличии) эталонных данных.
- **Начальные условия** — начальное положение, скорость, ориентация, начальные смещения акселерометров/гироскопов и их дрейфы.
- **Параметры фильтра Калмана (ESKF)** — ковариации шумов процесса и измерений, параметры фильтра.
- **Параметры интегрирования и выравнивания** — временные параметры, режимы и настройки выравнивания.
- **Прочие параметры** — дополнительные настройки расчёта.

Изменённые параметры можно сохранить, нажав соответствующую кнопку сохранения. При сохранении автоматически создаётся/обновляется файл `settings.ini`.

### Файл settings.ini
`settings.ini` — файл настроек приложения, в котором сохраняются параметры фильтра Калмана и параметры прогона.
- **Местоположение**: по умолчанию рядом с исполняемым файлом; путь можно задать через панель управления.
- **Создание**: автоматически при сохранении параметров.
- **При отсутствии**: используются значения по умолчанию, встроенные в программу.
- **Редактирование**: рекомендуется производить через интерфейс приложения. Ручное редактирование допустимо, если вы уверены в формате параметров.

## 11. Выполнение расчёта
1. Убедитесь, что указаны корректные пути ко всем необходимым входным файлам.
2. Проверьте/скорректируйте параметры расчёта.
3. Нажмите **«Запустить»** (или меню **«Прогон → Запустить»**, `F5`).
4. Дождитесь завершения расчёта — ход выполнения отображается в строке состояния и на вкладке «Лог». Доступны **«Пауза»** и **«Остановить»** (`Shift+F5`).

По завершении расчёта:
- Обновляются все графики.
- В истории добавляется новая запись с отметкой времени, названием и параметрами прогона.
- Результаты доступны для анализа, сравнения и экспорта.

## 12. Работа с графиками
### Основные возможности
- **Отображение рядов** — ряды с пренебрежимо малым уровнем скрываются автоматически (порог отображаемости). Управления видимостью отдельных рядов из интерфейса нет; легенда лишь поясняет цвета и подписи.
- **Масштабирование** — увеличение/уменьшение, произвольный зум, сброс масштаба (Вид → Сбросить масштаб графика).
- **Прокрутка/панорамирование** — перемещение по графику для детального просмотра участков.
- **Синхронизация осей X** — при отображении связанных графиков ось времени синхронизируется.
- **Отображение курсора** — при наведении мыши отображаются значения в выбранной точке. Курсор отрисовывается поверх кэшированного кадра, не влияя на содержимое кэша.
- **Кэширование кадров** — графики используют внутренний кэш отрисовки для ускорения перерисовки. Кэш автоматически инвалидируется при изменении данных, диапазонов осей, состава рядов или размера виджета. Управление — Вид → Кэш кадров графиков.
- **Тёмная тема** — Вид → Тёмная тема.

### Особенности отрисовки
При отключённом кэше отрисовка выполняется напрямую (без промежуточного изображения). Счётчики попаданий/промахов кэша используются только при активном кэшировании.

## 13. История запусков и сравнение
История прогонов хранится в базе SQLite (вкладка **«Параметры» → «История»**), поэтому прогоны можно повторно открыть и сравнить без пересчёта.

Возможности:
- **Открытие прогона** — двойной щелчок по строке загружает результаты выбранного расчёта на графики.
- **Выбор строки** — одиночный (наложения нескольких прогонов выделением строк в таблице нет).
- **Фильтрация** — по имени, дате, пути к каталогу с результатами.
- **Сортировка** — по дате (по умолчанию) и по любому столбцу.
- **Корректная навигация** — при фильтрации/сортировке используется корректное преобразование индексов.

**Сравнение через меню «Сравнение»:**
- **Второй прогон из истории…** — выбрать второй прогон для сопоставления с текущим.
- **Показывать разность (текущий − второй)** — флажок режима разности.
- **Убрать сравнение** — сбросить выбранное сопоставление.

Рекомендуется использовать сравнение при анализе влияния изменений параметров фильтра/начальных условий на качество оценивания.

## 14. Экспорт результатов
### 14.1 Отдельные графики
Через меню **«Экспорт»** (контекстных меню у графиков нет), действует на активную вкладку графика:
- **График в изображение (PNG/JPG)…** — растровый формат (.png, .jpg, .jpeg).
- **График в SVG…** — векторный формат (.svg), удобен для печати и редактирования.
- **График в PDF…** — экспорт текущего графика в PDF.

При экспорте сохраняется именно тот график, для которого вызвано действие, с учётом текущего масштаба, выбранных рядов и видимых элементов.

### 14.2 Пакетный экспорт всех графиков
Меню **«Экспорт → Все графики…»**: выбирается каталог и формат (PNG/JPG/SVG/PDF), затем экспортируются все открытые вкладки графиков с отслеживанием прогресса (экспорт можно прервать). Имена файлов формируются по названиям вкладок.

### 14.3 Таблицы и ряды в CSV
- **Экспорт → Таблица результатов в CSV…** — сводная таблица результатов прогона.
- **Экспорт → Данные активного графика в CSV…** — числовые данные рядов активного графика.

### 14.4 Анимация
Меню **«Экспорт → Анимация…»** для активного графика. В диалоге задаются:
- **Формат** — GIF-файл либо PNG-кадры (последовательность в каталог).
- **Кадров в секунду** (1–60) и **число кадров** (2–500).
- **Ширина/высота** в пикселях.
- **Окно времени** — «Нарастающее (вся траектория)» или «Скользящее окно» (с заданием ширины окна в процентах).

### 14.5 Лог
Меню **«Экспорт → Лог в файл…»** сохраняет журнал приложения в текстовый файл.

### 14.6 Сводный отчёт в PDF
Формируется через меню **«Экспорт → Сводный отчёт в PDF…»**. Поддерживаемое расширение — `.pdf`; по умолчанию предлагается каталог отчётов `reports/<набор>/` и имя `run_<набор>.pdf` (см. `reports/README.md`).

Отчёт включает:
- **Титульный лист** — общая информация о прогоне (набор, пресет, длительность) и строка **«Ошибка считается по»**: `truth.txt` (наземная истина) либо `reference.txt` (эталон СНС).
- **Сводку по NIS/NEES** — число степеней свободы dof = 9 (INS/KF_MEAS), основные статистики.
- **RMS и максимумы ошибок** — по 15 компонентам вектора состояния/ошибок (оценка фильтра по кадрам коррекции).
- **Ошибку относительно истины** (для наборов с корректным `truth.txt`) — P95 и среднее по позиции (м), скорости (м/с) и курсу (°); определения метрик совпадают с тюнером, поэтому числа подбора и прогона сопоставимы. Для наборов без истины раздел не выводится.
- **Таблицу NIS/NEES по времени** — выборка значений во временных точках.
- **Графики** — блоки графиков из текущего представления. При формировании PDF состояние отображаемых рядов и синхронизационных маркеров восстанавливается после экспорта (не влияет на текущее отображение).

### 14.7 Матрицы фильтра (Q/R/P0/H)
Меню **«Экспорт → Матрицы фильтра (Q/R/P0/H)…»** формирует статические матрицы фильтра ESKF 15-го порядка для текущего датасета и сохраняет их сразу в трёх форматах в выбранный каталог:
- `matrices_<датасет>.csv`,
- `matrices_<датасет>.md`,
- `matrices_<датасет>.json`.

Матрицы: **Q** — шум процесса (15×15), **R** — шум измерений (9×9), **P0** — начальная ковариация (15×15), **H** — матрица наблюдения (9×15). Источники:
- коэффициенты σ — из текущей таблицы **«Параметры»**;
- широта начальной точки — из `StartupNav.ini` датасета;
- шаг дискретизации T — медиана интервалов между отсчётами ИМУ (для 200 Гц ≈ 0.005 с).

Особенности: в 9-мерной коррекции по СНС тангаж и крен игнорируются (обрабатываются отдельным tilt-контуром по акселерометру) — соответствующие диагональные элементы R заведомо большие. Динамические матрицы F, K и текущая ковариация P зависят от прогона и в этот экспорт не входят; диагонали P доступны на вкладке «Ковариация» и в сводном PDF-отчёте. Экспорт работает для любого загруженного набора данных и не изменяет настройки фильтра.

## 15. Подбор коэффициентов и пресеты
Вкладка **«Подбор»** запускает подбор коэффициентов шумов фильтра Калмана скриптом `tools/kalman_tuner/tune_kalman.py` как дочерний процесс.

Элементы вкладки:
- **Каталог данных** — набор, по которому выполняется подбор (обычно тот же, что и у прогона).
- **Python** — интерпретатор с `numpy`/`scipy`.
- **Режим** — «Полный подбор», «Быстрый (--quick)», «Глобальная сетка (--global-only)».
- **Сравнивать с истиной (truth.txt)** — считать ошибку по наземной истине набора (`truth.txt`), а не по эталону СНС (`reference.txt`). Доступно только для синтетических наборов с корректным `truth.txt`; рядом показано его состояние (ок / не найден / повреждён). Галочка **включается автоматически** для наборов с корректным `truth.txt` (сравнение по умолчанию — с истиной) и остаётся под управлением пользователя после ручного переключения; при смене набора или конфига «по умолчанию — истина» применяется снова. Для наборов без корректного `truth.txt` сравнение идёт по `reference.txt` (зашумлённый эталон СНС), который создаёт сам `imitator` при каждом прогоне.
- **Конфиг** — набор параметров подбора `tuner_config*.json` рядом со скриптом (у наборов `dataset_shum` — свой конфиг, например `tuner_config.static300.json`).
- Кнопки **«Запустить подбор»**, **«Остановить»**, **«Применить пресет…»**, **«Отчёт о подборе…»**.
- Консоль вывода тюнера.

Параметры поиска берутся из выбранного конфига `tuner_config*.json` рядом со скриптом; готовый пресет записывается в `presets/tuned.ini` (для отдельных наборов — `presets/tuned_<набор>.ini`). Кнопка «Применить пресет…» загружает выбранный INI-файл в параметры фильтра, после чего его можно применить к таблице параметров.

Кнопка «Отчёт о подборе…» собирает PDF-отчёт по итогам выбранного конфига (`best_params.txt` и `eval.json` из его рабочего каталога): метрики подбора, подобранные σ, сходимость J и чувствительность. В шапке отчёта строка **«Ошибка считается по»** показывает, с чем сравнивалась ошибка — `reference.txt` (эталон СНС) или `truth.txt` (наземная истина). Собирайте отчёт сразу после подбора — каталоги `eval.json` перезаписываются следующим запуском тюнера. По умолчанию отчёт предлагается сохранить в `reports/<набор>/tuning_<набор>.pdf`. Тот же отчёт собирается без окна: `imitator_gui --tuning-report=<config.json>` (по умолчанию — `reports/<набор>/tuning_<набор>.pdf`, явный путь — `--tuning-report-out=<file.pdf>`).

Полный режим подбора может занимать десятки минут; быстрый и режим глобальной сетки — заметно меньше.

## 16. Портативная сборка dist
Папка `dist\` содержит самодостаточную сборку для запуска без установки Qt и MinGW.

Состав:
- `imitator_gui.exe`, `imitator.exe`.
- Все необходимые библиотеки Qt (DLL).
- Плагины: `platforms/` (`qwindows.dll`, `qoffscreen.dll`, `qminimal.dll`), `sqldrivers/`, `imageformats/`, `tls/` и др.
- MinGW runtime DLL (`libgcc_s_seh-1.dll`, `libstdc++-6.dll`, `libwinpthread-1.dll`).
- `USER_GUIDE.md` — копия руководства пользователя.

**Особенности:**
- Работает с полностью чистым `PATH`.
- Предназначена для запуска двойным щелчком.
- Может быть скопирована целиком на другой компьютер с Windows 10/11 (x64) и запущена без установки дополнительных компонентов.

## 17. Проверка корректности (паритет с консольной версией)
Приложение спроектировано так, чтобы консольная версия (`imitator`) и GUI-версия (`imitator_gui`) давали идентичные результаты расчёта при одинаковых входных данных и параметрах.

**Рекомендации по сверке:**
- Запускайте `imitator` и `imitator_gui` в **разных рабочих каталогах**, чтобы исключить взаимное перезаписывание выходных файлов (`result.txt`, `reference.txt`, `errors.txt`, служебные файлы в `tools\`).
- При корректном выборе рабочих каталогов выходные файлы консольного прогона должны побайтово совпадать с эталонными.
- Для точного паритета передавайте обоим процессам **один и тот же `settings.ini`**: GUI по умолчанию берёт параметры из сохранённых настроек, консоль — из встроенных значений по умолчанию, из-за чего без явных настроек `result.txt`/`errors.txt` могут различаться.
- Самопроверка GUI (создание PDF при старте) служит быстрой проверкой работоспособности экспорта и окружения.

## 18. Типичные ситуации и рекомендации
- **Не найдены входные файлы** — проверьте корректность путей (каталог данных). Убедитесь, что файлы существуют и к ним есть доступ.
- **Медленная перерисовка при большом объёме данных** — включённый кэш графиков ускоряет навигацию (Вид → Кэш кадров графиков).
- **Ошибки при экспорте PDF** — убедитесь, что каталог доступен для записи, достаточно места на диске и указано расширение `.pdf`.
- **Не видны данные после запуска из другой папки** — запускайте из `dist\` или каталога, где доступны нужные файлы; учитывайте влияние рабочего каталога.
- **Сравнение не отображается** — проверьте выбор прогонов в истории; для наложения используйте множественный выбор или меню «Сравнение».
- **Подбор не запускается** — проверьте путь к Python с `numpy`/`scipy` и наличие каталога `tools/kalman_tuner`.
