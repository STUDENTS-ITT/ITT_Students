# Руководство пользователя imitator_gui

## 1. Назначение
Программа imitator_gui предназначена для анализа, моделирования и обработки результатов полётовых экспериментов в составе комплекса «ИТТ-Студенты». Приложение реализует графический интерфейс для работы с фильтром оценивания состояния (ESKF/ИНС-СНС), позволяет загружать исходные данные полёта, выполнять расчёт, визуализировать траектории и ошибки оценивания, проводить сравнение различных прогонов, экспортировать графики и формировать сводный отчёт в PDF.

## 2. Назначение и возможности
- Выполнение расчёта оценки состояния по данным ИМУ и СНС
- Визуализация траекторий, скоростей, углов, смещений/дрейфов и ошибок оценивания
- Анализ качества фильтрации: NEES/NIS (при наличии эталонных данных), RMS и максимальные значения ошибок по компонентам
- Сравнение нескольких прогонов на одних графиках
- Кэширование кадров графиков для плавной навигации при большом объёме данных
- Экспорт графиков (PNG/JPEG/SVG) и формирование сводного PDF-отчёта
- Сохранение/восстановление параметров расчёта в settings.ini
- Портативный запуск без установки Qt (папка dist\)

## 3. Системные требования
- Операционная система Windows 10/11 (x64)
- Достаточно свободного места на диске для сохранения результатов и PDF-отчётов
- Права на чтение входных данных и запись выходных файлов

## 4. Структура поставки
- imitator_gui.exe – основное графическое приложение
- imitator.exe – консольная версия для проверки/сверки результатов
- Папка dist\ – полностью портативная сборка (содержит все необходимые DLL, плагины Qt и MinGW runtime). Предназначена для запуска двойным щелчком
- docs\user_manual\USER_GUIDE.md – настоящее руководство
- USER_GUIDE.md – копия руководства в корне проекта

## 5. Запуск программы
Способы запуска:
1. **Двойным щелчком (портативный)** – запустить dist\imitator_gui.exe. Рекомендуется использовать именно папку dist\.
2. **Из папки сборки** – запустить imitator_gui.exe из корневого каталога сборки.
3. **Из командной строки** – imitator_gui.exe в нужном рабочем каталоге.

При запуске автоматически выполняется самопроверка (создаётся временный PDF-файл с проверкой сигнатуры %PDF). При успешном прохождении самопроверки открывается основное окно. В противном случае в окне/логах выводится информация об ошибке.

**Рабочий каталог.** Рекомендуется запускать приложение в изолированном рабочем каталоге или использовать папку dist\. Если одновременно запускать консольный imitator и imitator_gui из одного рабочего каталога, они будут записывать выходные файлы (esult.txt, eference.txt, rrors.txt, а также файлы в 	ools/) в один и тот же каталог – это может привести к перезаписи результатов. Для корректной сверки паритета используйте разные рабочие каталоги.

## 6. Основное окно
Интерфейс разделён на три основных области:
- **Панель параметров (верхняя/левая)** – настройка всех параметров расчёта: источники данных, начальные условия, параметры фильтра Калмана, параметры интегрирования/выравнивания.
- **Область графиков (центральная)** – отображение результатов расчёта. Содержит несколько вкладок/графиков с возможностью независимой настройки отображения.
- **Панель истории запусков (правая)** – список выполненных прогонов. Каждый запуск хранит информацию о времени, параметрах и путях к результатам. Позволяет выбирать один или несколько прогонов для сравнения.

Строка состояния в нижней части окна отображает текущий прогресс расчёта, сообщения о ходе работы и результаты операций (успех/ошибка).

## 7. Подготовка исходных данных
Для проведения расчёта необходимо подготовить входные файлы в формате, используемом в проекте:
- **Данные ИМУ** – измерения акселерометров и гироскопов
- **Данные СНС** – навигационные измерения
- **Эталонные данные (необязательны)** – используются для вычисления ошибок оценивания (NEES/NIS, RMS, максимумы). При их отсутствии часть диагностических графиков/показателей может быть недоступна

Пути к файлам указываются во вкладке «Параметры». Рекомендуется размещать данные в логически структурированных папках (например, data/processed/, data/raw/ в соответствии с исходным проектом).

## 8. Настройка параметров
Вкладка «Параметры» объединяет следующие группы:
- **Данные** – выбор файлов IMU/SNS и (при наличии) эталонных данных
- **Начальные условия** – задание начального положения, скорости, ориентации, начальных смещений акселерометров/гироскопов и их дрейфов
- **Параметры фильтра Калмана (ESKF)** – настройка ковариаций шумов процесса и измерений, параметров фильтра
- **Параметры интегрирования и выравнивания** – временные параметры, режимы и настройки выравнивания
- **Прочие параметры** – дополнительные настройки расчёта

Изменённые параметры можно сохранить, нажав соответствующую кнопку сохранения. При сохранении автоматически создаётся/обновляется файл settings.ini.

## 9. Файл settings.ini
settings.ini – файл настроек приложения, в котором сохраняются параметры фильтра Калмана и параметры прогона.
- **Местоположение**: в каталоге, где расположен imitator_gui.exe (рядом с исполняемым файлом)
- **Создание**: автоматически при сохранении параметров во вкладке «Параметры»
- **При отсутствии**: используются значения по умолчанию, встроенные в программу
- **Редактирование**: рекомендуется производить через интерфейс приложения. Ручное редактирование допустимо, если вы уверены в формате параметров

## 10. Выполнение расчёта
1. Убедитесь, что указаны корректные пути ко всем необходимым входным файлам
2. Проверьте/скорректируйте параметры расчёта
3. Нажмите «Запуск» (кнопка запуска расчёта)
4. Дождитесь завершения расчёта – ход выполнения отображается в строке состояния

По завершении расчёта:
- Обновляются все графики в области отображения
- В панели «История запусков» добавляется новая запись с отметкой времени, названием и параметрами прогона
- Результаты расчёта доступны для анализа, сравнения и экспорта

## 11. Работа с графиками
Область графиков предназначена для наглядного анализа результатов.

### Основные возможности
- **Включение/отключение кривых** – управление отображением отдельных рядов (через легенду графика или элементы управления)
- **Масштабирование** – увеличение/уменьшение, произвольный зум, сброс масштаба по осям
- **Прокрутка/панорамирование** – перемещение по графику для детального просмотра участков
- **Синхронизация осей X** – при отображении нескольких связанных графиков ось времени синхронизируется для корректного сопоставления кривых
- **Отображение курсора** – при наведении курсора мыши отображаются значения в выбранной точке. Курсор отрисовывается поверх кэшированного кадра графика, не влияя на содержимое кэша
- **Кэширование кадров** – графики используют внутренний кэш отрисовки (frame cache) для ускорения перерисовки при навигации, масштабировании и перемещении. Кэш автоматически инвалидируется при изменении данных, диапазонов осей, состава отображаемых рядов или размера виджета

### Особенности отрисовки
При отключённом кэше отрисовка выполняется напрямую (без создания промежуточного изображения). Счётчики попаданий/промахов кэша используются только при активном кэшировании и не накапливаются при его отключении.

## 12. История запусков и сравнение
Панель «История» содержит список всех выполненных прогонов.

Возможности:
- **Выбор одного прогона** – отображение результатов выбранного расчёта на графиках
- **Множественный выбор** – выбор двух и более прогонов позволяет наложить их кривые друг на друга для наглядного сравнения (overlay)
- **Фильтрация** – фильтрация записей по имени, дате, пути к каталогу с результатами
- **Сортировка** – сортировка по дате (по умолчанию) и по имени. Порядок сортировки можно изменять
- **Корректная навигация** – при выборе записей в истории для отображения используется корректное преобразование индексов (mapToSource), что гарантирует правильную работу фильтра и сортировки

Рекомендуется использовать сравнение прогонов при анализе влияния изменений параметров фильтра/начальных условий на качество оценивания.

## 13. Экспорт результатов
Приложение поддерживает экспорт графиков и формирование сводного отчёта.

### 13.1 Экспорт графиков (изображения)
Экспорт отдельного графика выполняется через **контекстное меню графика** (правый клик по области графика):
- **Сохранить как изображение... (PNG/JPEG)** – экспорт текущего графика в растровом формате (.png, .jpg, .jpeg)
- **Сохранить как SVG...** – экспорт текущего графика в векторном формате (.svg). Формат SVG удобен для качественной печати, публикаций и последующего редактирования в векторных редакторах

При экспорте сохраняется именно тот график, для которого было вызвано контекстное меню, с учётом текущего масштаба, выбранных рядов и видимых элементов.

### 13.2 Сводный отчёт в PDF
Сводный отчёт формируется через меню **Экспорт → Сводный отчёт в PDF...**.

Отчёт включает:
- **Титульный лист** – общая информация о прогоне
- **Сводку по NIS/NEES** – число степеней свободы dof = 9 (INS/KF_MEAS), основные статистики
- **RMS и максимумы ошибок** – значения среднеквадратической ошибки и максимальной абсолютной ошибки по 15 компонентам вектора состояния/ошибок
- **Таблицу NIS/NEES по времени** – выборка значений во временных точках для детального анализа
- **Графики** – блоки графиков из текущего представления. При формировании PDF состояние отображаемых рядов и синхронизационных маркеров восстанавливается после экспорта (не влияет на текущее отображение в GUI)

Поддерживаемое расширение: .pdf. При сохранении укажите полное имя файла с расширением .pdf.

## 14. Портативная сборка dist
Папка dist\ содержит полностью самодостаточную сборку приложения для запуска без установки Qt и MinGW.

Состав:
- imitator_gui.exe, imitator.exe
- Все необходимые библиотеки Qt (DLL)
- Плагины: platforms/ (qwindows.dll, qoffscreen.dll, qminimal.dll), sqldrivers/, imageformats/, 	ls/ и др.
- MinGW runtime DLL (libgcc_s_seh-1.dll, libstdc++-6.dll, libwinpthread-1.dll)
- USER_GUIDE.md – копия руководства пользователя

**Особенности:**
- Работает с полностью чистым PATH (проверено)
- Предназначена для запуска двойным щелчком мыши
- Может быть скопирована целиком на другой компьютер с Windows 10/11 (x64) и запущена без установки дополнительных компонентов

## 15. Проверка корректности (паритет с консольной версией)
Приложение спроектировано так, чтобы консольная версия (imitator) и GUI-версия (imitator_gui) давали идентичные результаты расчёта при одинаковых входных данных и параметрах.

**Рекомендации по сверке:**
- Запускайте imitator и imitator_gui в **разных рабочих каталогах**, чтобы исключить взаимное перезаписывание выходных файлов (esult.txt, eference.txt, rrors.txt, файлы в 	ools/).
- При корректном выборе рабочих каталогов выходные файлы консольного прогона должны побайтово совпадать с эталонными/verified baseline.
- Самопроверка GUI (создание PDF при старте) служит быстрой проверкой работоспособности экспорта и окружения.

## 16. Типичные ситуации и рекомендации
- **Не найдены входные файлы** – проверьте корректность путей в вкладке «Параметры». Убедитесь, что файлы существуют по указанным путям и к ним есть доступ.
- **Медленная перерисовка при большом объёме данных** – включённый кэш графиков ускоряет навигацию. При изменении состава/диапазонов графиков кэш автоматически инвалидируется.
- **Ошибки при экспорте PDF** – убедитесь, что выбранный каталог доступен для записи, достаточно свободного места на диске и указано расширение .pdf.
- **Не видны данные после запуска из другой папки** – рекомендуется запускать из dist\ или из каталога, где расположены входные данные. Учитывайте влияние рабочего каталога на поиск файлов.
- **Сравнение не отображается** – при использовании фильтра/сортировки в истории убедитесь, что выбраны корректные прогоны. Множественный выбор активирует наложение кривых.

## 17. Завершение работы
Для завершения работы закройте основное окно приложения стандартным способом (крестик). При наличии несохранённых изменений параметров рекомендуется предварительно сохранить их во вкладке «Параметры».
