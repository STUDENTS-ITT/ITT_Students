# Первый прогон с генерацией данных (`imitator_gui`)

Пошаговая инструкция: **ничего скачивать не нужно** — генерируем синтетический
набор ИМУ/СНС/углов прямо в приложении и на нём выполняем первый расчёт фильтра.

Дополняет:
- `FIRST_RUN.md` — общий первый запуск и весь функционал GUI;
- `docs/user_manual/NAVIGATION.md` — карта интерфейса (кнопки, вкладки, меню);
- `USER_GUIDE.md` — руководство пользователя.

> Окружение примеров: проект `C:\ITT_Students_Qt_Version`, портативный запуск из
> `dist\`. Команды даны для PowerShell.

---

## 1. Зачем генерировать данные

Готовых полётных данных под рукой может не быть (они лежат по внешней ссылке из
`README.md`). Генератор создаёт **согласованный с ядром** набор за секунды:

- аналитическая траектория (разгон → разворот → торможение) и по ней — показания ИМУ
  (`imu.dat`), измерения СНС (`gps.dat`, `angle.dat`) и **эталон** (`truth.txt`);
- модель синтеза та же, что в счислении ядра, поэтому «чистые» показания почти точно
  проходят через фильтр (расходятся лишь на ошибку дискретизации интеграторов);
- наличие `truth.txt` включает эталонные ряды, вкладку «Ошибки x» и диагностику.

## 3. Шаг 1. Открыть генератор

Меню **«Прогон → Сгенерировать тестовые данные...»**.

Откроется модальный диалог **«Сгенерировать тестовые данные»** с одной формой:

| Поле | Диапазон | По умолчанию | Комментарий |
|------|----------|--------------|-------------|
| **Имя набора** | текст | `square_test` | только для отчёта/логов; на имена файлов не влияет |
| **Каталог вывода** | путь | текущий «Каталог данных» | **смените на новую папку**, см. ниже |
| **Частота ИМУ, Гц** | 1…1000 | `200` | частота `imu.dat` |
| **Частота СНС, Гц** | 0.1…100 | `10` | частота `gps.dat` |
| **Частота углов, Гц** | 0.1…100 | `10` | частота `angle.dat` |
| **Выставка (покой), с** | 1…1e6 | `120` | длительность первого участка покоя (для выравнивателя) |

Кнопка **«Обзор...»** рядом с каталогом вывода открывает выбор папки.
Подтверждение — **OK**, отмена — **Cancel**.

> **Важно.** По умолчанию «Каталог вывода» = текущий каталог данных. Если не сменить
> его, файлы набора будут записаны прямо туда (при наличии `imu.dat` появится
> запрос на перезапись). Для первого прогона задайте **отдельную пустую папку**,
> например:
> `C:\ITT_Students_Qt_Version\first_run\square_test`
>
> Каталог **создаётся автоматически** — заранее его делать не нужно. Имя набора в
> подкаталог не превращается: все файлы лягут **непосредственно** в «Каталог вывода».

Нажмите **OK**.

## 4. Шаг 2. Что создаётся

| Файл | Формат (первая строка — заголовок) | Частота |
|------|------------------------------------|---------|
| `imu.dat` | `# time_s  timestamp_ns  wx wy wz  ax ay az` | `Частота ИМУ` |
| `gps.dat` | `# time_s  timestamp_ns  latitude longitude altitude  vx vy vz` | `Частота СНС` |
| `angle.dat` | `# time_s  timestamp_ns  roll pitch yaw` | `Частота углов` |
| `truth.txt` | как `reference.txt`: `time lon lat alt heading pitch roll vn vh ve` | `Частота СНС` |
| `StartupNav.ini` | `долгота / широта / высота / время выставки` + комментарии | — |

Начальные условия и шумы **берутся из значений по умолчанию** генератора и из диалога
**не редактируются**:

- точка старта — **Сиэтл**: широта `47.641468°`, долгота `−122.1401651°`, высота `116.975 м`;
- курс/тангаж/крен на старте — `5.0° / −0.33° / 0.0°`;
- шумы: гироскоп σ `0.0016 рад/с` + смещения `[20, −15, 10] °/ч`;
  акселерометр σ `0.043 м/с²` + смещения `[1.5, −2.0, 1.0] mg`;
  СНС: горизонт σ `1.5 м`, высота σ `2.5 м`, скорость σ `0.05 м/с`,
  коррелированная ошибка `0.8 м` (τ `90 с`); углы σ `[0.05, 0.05, 0.2]°`;
- дрожание меток времени, ~0.03 % пропусков отсчётов ИМУ, `seed = 42`.

Всё это (кроме частот и времени выставки) меняется только в коде —
`src/core/data_io/dataset_generator.h`, `struct DatasetConfig` / `struct NoiseConfig`.

## 5. Шаг 3. Профиль траектории (фиксированный)

Профиль задан в `MainWindow::onGenerateDataset` и в диалоге не настраивается.
Он состоит из выставки (из поля «Выставка (покой)») и четырёх сегментов:

| Сегмент | Длительность | Горизонт. скорость | Разворот |
|---------|--------------|--------------------|----------|
| Выставка (покой) | из поля, по умолчанию `120 с` | 0 | 0 |
| Прямой участок | `20 с` | `10 м/с` | 0 |
| Разворот | `40 с` | `10 м/с` | `1.5 °/с` → суммарно ~`60°` |
| Прямой участок | `20 с` | `10 м/с` | 0 |
| Торможение | `20 с` | `0 м/с` | 0 |

Итого при значениях по умолчанию: **120 + 100 = 220 с**. Ожидаемое число строк
(приблизительно, с учётом дрожания и пропусков):

- `imu.dat` ≈ `200 Гц × 220 с` ≈ **44 000** строк;
- `gps.dat`, `angle.dat`, `truth.txt` ≈ `10 Гц × 220 с` ≈ **2 200** строк.

Выставка обязательна: выравниватель использует первый участок покоя и время из
`StartupNav.ini`. Если задать «Выставка (покой)» меньше реально нужного, качество
начальной выставки ухудшится.

## 6. Шаг 4. Процесс генерации

- Появляется модальное окно **«Генерация тестовых данных...»** с неопределённым
  прогрессом (генератор не отдаёт процент) — расчёт идёт в фоновом потоке, окно
  остаётся отзывчивым.
- В **«Лог»** пишется строка `Генерация тестовых данных в <каталог> ...`.
- По завершении:
  - в логе — `Готово: IMU=…, GPS=…, ANGLE=…, TRUTH=…; каталог …`;
  - всплывает сообщение **«Готово»** с числом строк;
  - **«Каталог данных»** переключается на созданный набор автоматически — можно
    сразу считать.
- При ошибке (нет прав на запись и т.п.) — сообщение **«Ошибка»** с текстом причины,
  в логе строка с тем же текстом.

---

## 7. Шаг 5. Проверить набор

Перейдите на вкладку **«Данные»**:

- в дереве входов появятся `imu.dat`, `gps.dat`, `angle.dat`, `StartupNav.ini` с
  размерами и числом строк;
- под деревом — сводка (каталог, число строк ИМУ, оценка длительности).

Числа строк должны быть близки к оценке из §5. Если `imu.dat` пуст или отсутствует —
генерация не прошла, повторите с другим каталогом.

---

## 8. Шаг 6. Первый прогон фильтра

1. В панели управления проверьте:
   - **«Каталог данных»** = папка набора (подставилась автоматически);
   - **«Каталог результатов»** — существующий каталог для `result.txt` /
     `reference.txt` / `errors.txt` (при необходимости задайте явно, напр.
     `out_first_run`);
   - флажки **«Писать файлы»**, **«Телеметрия»**, **«В историю (SQLite)»** включены.
2. Нажмите **«Запустить»** или **F5**.
3. Следите за ходом: прогресс-бар, строка состояния и вкладка **«Лог»**
   (`t = …`, такт, диагностика). Остановить — **«Остановить»** / `Shift+F5`.

По завершении в «Каталоге результатов» появятся `result.txt`, `reference.txt`,
`errors.txt`, а прогон добавится в **«Историю»**.

## 9. Шаг 7. Что посмотреть

Коротко по вкладкам (полный обзор — `FIRST_RUN.md`, §6):

- **«Графики → Траектория»** — путь от старта: сплошная линия БИНС, точки СНС и
  **эталон** из `truth.txt`. Линии должны почти совпадать (расхождение — ошибка фильтра).
- **«Графики → Углы» / «Координаты» / «Скорости»** — курс/тангаж/крен, север-восток-высота,
  компоненты скорости по времени.
- **«Графики → Ошибки x»** — 15 компонент вектора состояния в кадрах коррекции СНС.
- **«Графики → Согласованность (NIS / NEES)»** — диагностика фильтра относительно
  опорной линии `dof = 9`.
- **«Данные»** — таблица результатов (поиск, интервал времени, сортировка).

Навигация по графикам: колесо — зум, левый драг — панорама, двойной щелчок — сброс
масштаба.

## 11. Повторная генерация и варианты

- **Перезапись.** Если в «Каталоге вывода» уже есть `imu.dat`, приложение спросит
  «Перезаписать данные?». Ответ **No** отменяет генерацию.
- **Другая частота/длительность.** Измените «Частота ИМУ/СНС/углов» и «Выставка
  (покой)» — это единственные настраиваемые параметры диалога.
- **Другой профиль/шумы/координаты.** Меняются только через `DatasetConfig`/`NoiseConfig`
  (`dataset_generator.h`) с последующей пересборкой — из интерфейса не доступны.
- **Детерминированность.** Набор воспроизводим: `seed = 42`. Один и тот же ввод даёт
  один и тот же набор.

### Генерация без окна (для CI/скриптов)

```powershell
.\dist\imitator_gui.exe --self-test-generate C:\ITT_Students_Qt_Version\first_run\auto
```

Создаёт набор в указанном каталоге и завершается (код `0` при успехе). Удобно, чтобы
подготовить данные до открытия окна.

## 12. Частые проблемы

| Симптом | Причина / решение |
|---------|-------------------|
| «Не задан каталог вывода» | пустое поле «Каталог вывода» — впишите путь |
| «cannot create output directory» | нет прав/некорректный путь — выберите другую папку |
| Предупреждение о перезаписи | в каталоге уже есть `imu.dat`; выберите новую папку либо подтвердите |
| После генерации графики пусты | включите флажок «Телеметрия» и запустите прогон (F5) |
| «Ошибки x» / эталон пусты | набор без `truth.txt` (сгенерируйте заново генератором) |
| Плохая выставка | малое значение «Выставка (покой)» — увеличьте (по умолчанию 120 с) |
| Файлы легли «не туда» | «Каталог вывода» = текущий каталог данных; задайте отдельную папку |
