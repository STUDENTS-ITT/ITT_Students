# ITT_Students — Комплексирование видео, навигационной системы и БИНС

## Описание проекта
Проект по разработке алгоритма комплексирования видео, навигационной системы и бортовой инерциальной навигационной системы (БИНС) при полёте летательного аппарата. Qt-версия (`imitator_gui`) является графической оболочкой над тем же ядром ESKF, что и консольный `imitator`.

## Формат данных

### Входные данные

Программа принимает четыре файла в каталоге данных (по умолчанию `../data/raw/` относительно рабочего каталога запуска; каталог задаётся в GUI или аргументом консоли):

#### imu.dat — данные инерциального датчика (200 Гц)

Заголовочная строка начинается с `#`. Разделитель — табуляция.

| Столбец | Индекс | Описание | Единицы |
|---------|--------|----------|---------|
| time_s | 0 | Время отсчёта | с |
| timestamp_ns | 1 | Временная метка | нс |
| wx | 2 | Угловая скорость вокруг оси X (вперёд) | рад/с |
| wy | 3 | Угловая скорость вокруг оси Y (вверх) | рад/с |
| wz | 4 | Угловая скорость вокруг оси Z (вправо) | рад/с |
| ax | 5 | Ускорение по оси X (вперёд) | м/с² |
| ay | 6 | Ускорение по оси Y (вверх) | м/с² |
| az | 7 | Ускорение по оси Z (вправо) | м/с² |

**Пример строки:**
```
10.050000	10050000000	1.91692540e-05	2.03542305e-04	1.56184071e-04	9.93428306e-03	9.77088985e+00	1.32800215e-02
```

**СК тела:** X — вперёд, Y — вверх, Z — вправо.
На стоянке: `ax ≈ 0`, `ay ≈ g` (9.81 м/с²), `az ≈ 0`.

#### gps.dat — данные СНС (5 Гц)

| Столбец | Индекс | Описание | Единицы |
|---------|--------|----------|---------|
| time_s | 0 | Время отсчёта | с |
| timestamp_ns | 1 | Временная метка | нс |
| latitude | 2 | Широта | градусы |
| longitude | 3 | Долгота | градусы |
| altitude | 4 | Высота | м |
| vn / vx | 5 | Скорость на север | м/с |
| vh / vy | 6 | Вертикальная скорость (вверх) | м/с |
| ve / vz | 7 | Скорость на восток | м/с |

**Пример строки:**
```
10.000000	10000000000	55.75580000	37.61730000	156.000	0.082953	0.313109	0.001165
```

> Замечание: в исходных полётных файлах заголовок может иметь вид
> `# time_s timestamp_ns latitude_d longitude_d altitude_m vn vh ve`;
> генератор тестовых данных пишет `# time_s timestamp_ns latitude longitude altitude vx vy vz`.
> Порядок и смысл столбцов совпадают.

#### angle.dat — углы ориентации (100 Гц)

| Столбец | Индекс | Описание | Единицы |
|---------|--------|----------|---------|
| time_s | 0 | Время отсчёта | с |
| timestamp_ns | 1 | Временная метка | нс |
| roll | 2 | Крен | рад |
| pitch | 3 | Тангаж | рад |
| yaw | 4 | Курс | рад |

**Пример строки:**
```
10.000000	10000000000	-0.00906004	0.01026417	-0.00202022
```

> **Важно:** частоты `gps.dat` и `angle.dat` различаются (примерно 5 и 100 Гц), поэтому число строк в этих файлах, как правило, не совпадает. `SnsReader` стыкует `angle.dat` с `gps.dat` **по времени** (по ближайшему отсчёту), а не по номеру строки. Синхронное построчное совпадение не требуется и не ожидается.

#### StartupNav.ini — конфигурация выставки

Текстовый файл, 4 строки. Значения через пробел, комментарий через `;`.

| Строка | Описание | Единицы |
|--------|----------|---------|
| 1 | Долгота выставки | град |
| 2 | Широта выставки | град |
| 3 | Высота выставки | м |
| 4 | Время выставки (окончание начальной выставки) | сек |

**Пример:**
```
38.2447222    ; Долгота выставки (град)
55.5641667    ; Широта выставки (град)
116.988716    ; Высота выставки (м)
120.0         ; Время выставки (сек)
```

> Если `StartupNav.ini` отсутствует, координаты берутся из первого отсчёта `gps.dat`, время выставки — 120 с.

### Выходные данные

Программа создаёт три файла в каталоге результатов (в консольной версии — в рабочем каталоге запуска):

#### result.txt — результат БИНС (исправленный Калманом)

10 столбцов, разделённые пробелами/табуляцией. Углы — в градусах, координаты — в градусах, скорости — в м/с.

| Столбец | Описание |
|---------|----------|
| time | Время отсчёта (с) |
| lon | Долгота БИНС (град) |
| lat | Широта БИНС (град) |
| alt | Высота БИНС (м) |
| heading | Курс БИНС (град) |
| pitch | Тангаж БИНС (град) |
| roll | Крен БИНС (град) |
| vn | Скорость на север (м/с) |
| vh | Вертикальная скорость (м/с) |
| ve | Скорость на восток (м/с) |

#### reference.txt — эталон СНС

10 столбцов, аналогичный формат. Используется для сравнения.

#### errors.txt — вектор ошибок фильтра Калмана

16 столбцов: время + 15 компонент вектора ошибок.

| Индекс | Описание |
|--------|----------|
| 0 | Ошибка широты (рад) |
| 1 | Ошибка долготы (рад) |
| 2 | Ошибка высоты (м) |
| 3 | Ошибка скорости на север (м/с) |
| 4 | Ошибка вертикальной скорости (м/с) |
| 5 | Ошибка скорости на восток (м/с) |
| 6 | Ошибка курса (рад) |
| 7 | Ошибка тангажа (рад) |
| 8 | Ошибка крена (рад) |
| 9–11 | Смещение акселерометра (м/с²) |
| 12–14 | Смещение гироскопа (рад/с) |

#### ../data/processed/Aligner.dat — промежуточные данные выставки

Записывается при вычислении начальных углов ориентации. Содержит сырые и сглаженные данные ИМУ, а также рассчитанные углы. На расчёт не влияет (только дамп).

## Сборка и запуск

Ядро (`esfcore`) Qt-независимо; GUI требует Qt 6.12.0 (QtWidgets, QtConcurrent, QSettings, QtSql, QtPdf).

```bash
# Конфигурация (MinGW Makefiles или Ninja), при необходимости укажите путь к Qt:
cmake -S . -B build -G "MinGW Makefiles" -DCMAKE_PREFIX_PATH="C:/QT6.10/6.12.0/mingw_64"
cmake --build build

# Консольный запуск (из каталога build, данные ищутся в ../data/raw/):
cd build
./imitator.exe

# GUI:
./imitator_gui.exe
```

Цели сборки: `esfcore` (ядро), `imitator` (консоль), `imitator_gui` (GUI).
Тесты: `ctest --test-dir build --output-on-failure` (при необходимости `QT_QPA_PLATFORM=offscreen`).

## Используемые библиотеки

- C++17, CMake, MinGW (GCC) или MSVC; Qt 6.12.0 (для GUI).
- numpy, pandas, matplotlib, scipy (для скриптов в `tools/` и подбора).
