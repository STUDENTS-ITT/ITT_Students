# Первый запуск imitator_gui — сквозное руководство

Практическое руководство «с нуля»: как запустить `imitator_gui` сегодня и за один
проход пройти по **всему** функционалу приложения — от загрузки данных до PDF-отчёта,
матриц фильтра и подбора коэффициентов.

Дополняет:
- `USER_GUIDE.md` — общий порядок работы и описание возможностей;
- `docs/user_manual/NAVIGATION.md` — подробная карта интерфейса (кнопки, вкладки, меню);
- `docs/user_manual/README.txt` — форматы входных/выходных файлов.

> Примеры команд даны для PowerShell и текущего окружения проекта:
> - проект: `C:\ITT_Students_Qt_Version`
> - Qt: `C:/QT6.10/6.12.0/mingw_64`
> - MinGW: `C:/Users/anton/.mingw64/mingw64/bin`

---

## 0. Быстрый старт (сокращённо)

Если не хочется читать целиком, минимальный путь такой:

```powershell
# 1. Окружение (Qt + MinGW в PATH)
$env:PATH = "C:/QT6.10/6.12.0/mingw_64/bin;C:/Users/anton/.mingw64/mingw64/bin;" + $env:PATH

# 2. Рабочий каталог и каталог результатов
cd C:\ITT_Students_Qt_Version
New-Item -ItemType Directory -Force out_first_run | Out-Null

# 3. Запуск GUI (свежая сборка из build, не из dist)
.\build\src\gui\imitator_gui.exe -d data/raw -o out_first_run -s settings_first_run.ini
```

Далее в окне: **«Прогон → Сгенерировать тестовые данные...»** → сгенерировать набор →
**F5** (Запустить) → изучить вкладки «Графики»/«Данные» → **«Экспорт → Сводный отчёт
в PDF…»**.

Дальше — подробно по каждому шагу и по всем элементам функционала.

## 1. Что нужно перед запуском

| Что | Проверка | Примечание |
|-----|----------|------------|
| Сборка актуальна | файл `build\src\gui\imitator_gui.exe` существует | если нужен текущий функционал — пересоберите (см. ниже) |
| Qt 6.12.0 (MinGW) | каталог `C:/QT6.10/6.12.0/mingw_64/bin` | нужен в `PATH` при запуске из `build` |
| Runtime MinGW | каталог `C:/Users/anton/.mingw64/mingw64/bin` | тоже в `PATH` |
| Данные для расчёта | есть `data\raw\imu.dat` и т.п. | либо сгенерируем (Шаг 3) |

### 1.1. Пересобрать (если сомневаетесь в свежести)

```powershell
$env:PATH = "C:/Users/anton/.mingw64/mingw64/bin;" + $env:PATH
cmake --build C:\ITT_Students_Qt_Version\build --target imitator_gui -j 8
```

### 1.2. Важно: `dist\` устарел

Каталог `dist\` — **портативная** сборка (все DLL Qt и runtime рядом, запуск двойным
щелчком), но её `imitator_gui.exe` старее текущего кода. Поэтому для «первого запуска
со всем функционалом» используйте сборку из `build\` (вариант ниже). `dist\` пригодится,
когда будет выполнен этап обновления пакета (пересборка `windeployqt`).

## 2. Шаг 1. Запуск приложения

### Вариант A (рекомендуется): из `build` с настройкой `PATH`

```powershell
$env:PATH = "C:/QT6.10/6.12.0/mingw_64/bin;C:/Users/anton/.mingw64/mingw64/bin;" + $env:PATH
cd C:\ITT_Students_Qt_Version
New-Item -ItemType Directory -Force out_first_run | Out-Null
.\build\src\gui\imitator_gui.exe -d data/raw -o out_first_run -s settings_first_run.ini
```

Здесь:
- `-d data/raw` — каталог входных данных (задаём явно; «по умолчанию» рядом с exe в
  `build` его нет);
- `-o out_first_run` — куда писать `result.txt` / `reference.txt` / `errors.txt`;
- `-s settings_first_run.ini` — файл параметров (создастся при сохранении; пока его
  нет — берутся встроенные значения по умолчанию).

> Данные можно указать и позже через панель управления, кнопкой «**…**» у поля
> «Каталог данных».

### Вариант B: портативно из `dist\`

Двойной щелчок по `dist\imitator_gui.exe` (или `-d`/`-o` из командной строки). Все
библиотеки уже рядом, PATH настраивать не нужно. Помните про устаревший exe (п. 1.2).

### Полезные ключи командной строки

| Ключ | Значение |
|------|----------|
| `-d, --data <dir>` | каталог с `imu.dat` / `gps.dat` / `angle.dat` / `StartupNav.ini` |
| `-o, --output <dir>` | каталог для `result.txt` / `reference.txt` / `errors.txt` |
| `-s, --settings <file>` | файл параметров фильтра (`settings.ini`) |
| `-t, --dark` | тёмная тема сразу |
| `--autostart` | сразу запустить расчёт при открытии окна |
| `--self-test` | без окна: расчёт + проверки и выход (для CI) |
| `--export-matrices <dir>` | без окна: выгрузить матрицы Q/R/P0/H (csv/md/json) и выйти |
| `-h, --help`, `-v, --version` | справка и версия |

## 3. Шаг 2. Что вы увидите при старте

- Выполняется **самопроверка**: строится временный PDF и проверяется его сигнатура
  `%PDF`. Результат (успех/ошибка) — в логе.
- Открывается окно ~1400×860: слева — панель управления и состояния, справа — вкладки.
- В логе появляются: версия Qt, каталог данных, путь к `settings.ini`.
- В панели состояния — «ожидание», точность «—» (расчёт ещё не запускался).

**Ориентиры по интерфейсу:** меню **Прогон · Сравнение · Вид · Экспорт · Справка**;
вкладки справа — **Графики · Данные · Параметры · Подбор · Лог**. Подробная карта —
`docs/user_manual/NAVIGATION.md`.

## 4. Шаг 3. Подготовить данные

Есть два пути. Для первого знакомства выберите **A**.

### A. Сгенерировать набор (самодостаточно, рекомендуется)

Меню **«Прогон → Сгенерировать тестовые данные...»**. В диалоге:

| Поле | Значение по умолчанию | Комментарий |
|------|----------------------|-------------|
| Имя набора | `square_test` | произвольное |
| Каталог вывода | текущий каталог данных | задайте **новую** папку, напр. `C:\ITT_Students_Qt_Version\first_run` |
| Частота ИМУ, Гц | 200 | |
| Частота СНС, Гц | 10 | |
| Частота углов, Гц | 10 | |
| Выставка (покой), с | 120 | обязательный начальный участок покоя для выравнивателя |

Нажмите OK. Генерация идёт в фоне (неопределённый прогресс). Создаются `imu.dat`,
`gps.dat`, `angle.dat`, `truth.txt` (эталон), `StartupNav.ini`; «Каталог данных»
переключается на новый набор. Наличие `truth.txt` делает доступными эталонные ряды и
диагностику.

### B. Взять готовый набор

- `data/raw` или `run_hk/data/raw` — «полётный» набор (у `run_hk` есть
  `StartupNav.ini`); если `StartupNav.ini` нет, координаты берутся из `gps.dat`,
  а выставка — `align_fallback_s` = 120 с.
- `ITT_Students-Katya\dataset_shum\<набор>` — синтетические наборы с `params.json`,
  `StartupNav.ini`, `truth.txt` (например `square_650`, `static_300`,
  `high_dynamics`).

В панели управления укажите путь кнопкой «**…**» у поля «Каталог данных».

## 5. Шаг 4. Первый прогон

1. Убедитесь, что в панели управления заданы «Каталог данных» и «Каталог результатов».
2. Проверьте флажки: **«Писать файлы»**, **«Телеметрия»**, **«В историю (SQLite)»**
   (по умолчанию включены). «Телеметрия» наполняет графики/таблицу/панель состояния.
3. Нажмите **«Запустить»** или **F5**.

Во время расчёта:
- строка состояния и **«Лог»** показывают прогресс (`t = …`, %, такт, диагностику);
- прогресс-бар заполняется (если число отсчётов известно);
- темп воспроизведения — ползунок слева (позиция 0 = «максимум», по умолчанию);
- **«Пауза»/«Продолжить»** и **«Стоп»** — управление ходом (пункт меню —
  «Остановить», `Shift+F5`).

По завершении:
- наполняются графики и панель состояния;
- в «Историю» добавляется запись;
- в «Каталоге результатов» появляются `result.txt`, `reference.txt`, `errors.txt`.

> Если запускали с `--autostart`, расчёт стартует сразу при открытии окна.

## 6. Шаг 5. Обзор графиков (все вкладки)

Вкладка **«Графики»** содержит 8 вложенных вкладок. По очереди переключите каждую:

| Вкладка | Заголовок | Что показывает |
|---------|-----------|----------------|
| **Траектория** | — | восток/север от старта; БИНС — сплошная, точки СНС, эталон (при наличии) |
| **Координаты** | «Координаты и высота» | север/восток (или широта/долгота) и высота |
| **Углы** | «Углы ориентации» | курс, тангаж, крен |
| **Скорости** | «Скорости» | Vn, Vh, Ve |
| **Ошибки x** | «Вектор ошибок x (кадры коррекции СНС)» | 15 компонент `x0…x14`; вертикальные линии — моменты коррекции |
| **Инновации СНС** | «Инновации измерений СНС» | `Δ` измерение − прогноз (только ненулевые) |
| **Ковариация P** | «Диагонали ковариации P» | 15 диагоналей `P00…P1414` |
| **Согласованность** | «Согласованность фильтра (NIS / NEES)» | NIS/NEES и опорная линия ожидания `dof = 9` |

Навигация по любому графику:
- **колесо** — зум к курсору; **Ctrl+колесо** — только по X; **Shift+колесо** — только по Y;
- **левый драг** — панорамирование; **двойной щелчок** — сброс к авто-масштабу;
- наведение мыши — перекрестие со значениями.

Ряды с пренебрежимо малым уровнем скрываются автоматически; легенда не кликабельна.

## 7. Шаг 6. Вкладка «Данные»

- Слева — дерево входных файлов: `imu.dat`, `gps.dat`, `angle.dat`, `StartupNav.ini`
  с размером и числом строк; под деревом — сводка (каталог, число строк ИМУ, оценка
  длительности).
- Справа — таблица результатов: поле **«Поиск:»**, спинбоксы **«с»/«по»** (интервал
  времени), кнопка **«Сбросить»**; заголовки колонок сортируемы.

---

## 8. Шаг 7. Вкладка «Параметры» (и пресеты, и история)

Вкладка «Параметры» содержит две вложенные вкладки:

**«Параметры»** — таблица настроек фильтра (данные, начальные условия, ESKF,
интегрирование/выравнивание, прочее):
- **двойной щелчок по значению** применяет параметры к фильтру;
- кнопка **«Пресеты ▾»**: «Сохранить как пресет…», «Загрузить пресет…»,
  «Удалить пресет…», а ниже — список готовых пресетов (в `presets\`) для быстрого
  старта. Для знакомства удобно загрузить один из `presets\tuned_*.ini`.

**«История»** — таблица прогонов (SQLite):
- поле фильтра по названию/каталогу, сортировка по столбцам;
- **двойной щелчок по строке** — открыть прогон из истории без пересчёта.

Про меню **«Прогон»** (для параметров): «Загрузить settings.ini…»,
«Сохранить settings.ini»/«…как…», «Сбросить параметры к умолчаниям»,
«Применить параметры к фильтру».

---

## 9. Шаг 8. Сравнение прогонов

1. Сначала должен быть текущий (открытый) прогон.
2. Меню **«Сравнение → Второй прогон из истории…»** — выберите второй прогон.
3. На графиках появятся пунктирные ряды второго прогона (суффикс `[прогон <id>]`).
4. Флажок **«Показывать разность (текущий − второй)»** включает ряды `Δ …`.
5. **«Убрать сравнение»** — сбросить.

> «История» использует **одиночный** выбор; второй прогон задаётся именно через меню
> «Сравнение», а не выделением строк.

## 10. Шаг 9. Экспорт (весь набор возможностей)

Все пункты — в меню **«Экспорт»** (контекстных меню по правому клику нет). Кроме
«Матрицы фильтра…», действия применяются к **активной** вкладке «Графиков».

| Пункт меню | Что сохраняет |
|-----------|----------------|
| **График в изображение (PNG/JPG)…** | текущий график в `.png/.jpg` |
| **График в SVG…** | текущий график в `.svg` (вектор) |
| **График в PDF…** | текущий график в `.pdf` |
| **Таблица результатов в CSV…** | сводную таблицу прогона в `.csv` |
| **Данные активного графика в CSV…** | числовые ряды активного графика в `.csv` |
| **Матрицы фильтра (Q/R/P0/H)…** | `matrices_<датасет>.csv/.md/.json` (для текущего датасета) |
| **Все графики…** | пакетно все вкладки в каталог (PNG/JPG/SVG/PDF) |
| **Анимация…** | GIF-файл или PNG-кадры активного графика |
| **Лог в файл…** | содержимое вкладки «Лог» в текстовый файл |
| **Сводный отчёт в PDF…** | многоблочный отчёт (титул, NIS/NEES, RMS/максимумы, таблица, графики) |

Для первого знакомства рекомендуется:
1. на вкладке «Траектория» — **«График в PNG…»**;
2. **«Матрицы фильтра (Q/R/P0/H)…»** → убедиться, что создано 3 файла;
3. **«Сводный отчёт в PDF…»** → открыть PDF и проверить разделы.

Пояснение по матрицам: **Q** — шум процесса (15×15), **R** — шум измерений (9×9),
**P0** — начальная ковариация (15×15), **H** — матрица наблюдения (9×15). σ берутся из
таблицы «Параметры», широта — из `StartupNav.ini`, шаг `T` — медиана интервалов ИМУ.

## 11. Шаг 10. Подбор коэффициентов (опционально)

Вкладка **«Подбор»** запускает `tools/kalman_tuner/tune_kalman.py` отдельным процессом.

1. Укажите «Каталог данных» и «Python» (нужен `numpy`/`scipy`).
2. Выберите «Режим»: **Полный**, **Быстрый (--quick)**, **Глобальная сетка (--global-only)**.
3. **«Запустить подбор»** — следите за консолью; **«Остановить»** — прервать.
4. **«Применить пресет…»** — загрузить полученный INI (обычно `presets\tuned.ini`) в
   параметры фильтра; затем можно снова запустить прогон.

Полный режим — десятки минут; быстрый и глобальная сетка — существенно быстрее.

## 12. Шаг 11. Безголовые режимы (быстрая проверка окружения)

Не открывая окно:

```powershell
# Полная самопроверка (расчёт + история + сравнение + PDF + матрицы)
.\build\src\gui\imitator_gui.exe --self-test --self-test-timeout=600 `
    -d data/raw -o out_first_run `
    --self-test-report out_first_run\self_test_report.txt
Get-Content out_first_run\self_test_report.txt -TotalCount 6

# Только выгрузка матриц Q/R/P0/H
.\build\src\gui\imitator_gui.exe --export-matrices=out_first_run\matrices -d data/raw
Get-ChildItem out_first_run\matrices
```

Код возврата `0` — успех.

## 14. Типичные проблемы

| Симптом | Причина / решение |
|---------|-------------------|
| Окно не открывается, ошибка про DLL Qt | не настроен `PATH`: добавьте `C:/QT6.10/6.12.0/mingw_64/bin` и `C:/Users/anton/.mingw64/mingw64/bin` |
| «Каталог данных» пустой/неверный | значение по умолчанию рядом с exe в `build` отсутствует — задайте путь через `-d` или кнопкой «**…**» |
| Данные не видны после запуска из другой папки | используйте явные `-d`/`-o` или запускайте из `dist\` |
| Графики пустые после прогона | снят флажок «Телеметрия» |
| Медленная перерисовка на больших данных | включите «Вид → Кэш кадров графиков» |
| Подбор не запускается | проверьте путь к Python с `numpy`/`scipy` и наличие `tools\kalman_tuner` |
| Экспорт PDF не удался | проверьте права на запись, место на диске и расширение `.pdf` |
