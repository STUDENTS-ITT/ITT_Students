# Векторы, матрицы фильтра Калмана и начальная инициализация

Инвентарь всех векторов и матриц углового фильтра Калмана (15 состояний),
реализованного в `src/ins/ins_filter.h` и `src/navigation/trajectory.h`, и
предлагаемая схема начальной инициализации при выставке по окну 1 с
(см. `docs/fast_alignment_plan.md`).

Все ссылки на строки — для текущего состояния репозитория.

---

## 1. Что вообще инициализируется

Три разных объекта, которые нельзя путать между собой:

| Объект | Где живёт | Что это |
|---|---|---|
| **Номинал** | `NavState`: `lat`, `lon`, `alt`, `V`, `att`, `ba`, `bg` | физическое состояние, которое интегрируется по данным ИМУ |
| **Вектор ошибок** | `NavState.x` (15) | оценка фильтром **ошибок** номинала |
| **Ковариация** | `NavState.P` (15×15) | неопределённость этих ошибок |

Ключевой факт: `x` — **не** состояние навигации. Это вектор поправок к
номиналу. Номинал интегрируется по ИМУ всегда; фильтр вычисляет, насколько
номинал ошибается, и периодически подкручивает номинал на `x` (инъекции
`applyKalmanCorrections` / `applyTiltKalmanCorrections`,
`src/navigation/trajectory.h:110` и `:128`).

Поэтому «инициализация вектора состояния» = инициализация **номинала** +
**x₀** + **P₀**.

### 1.1 Знаковая конвенция (не путать!)

| Компонента | Смысл ошибки | Как применяется к номиналу |
|---|---|---|
| `x[0..2]` (координаты, скорости) | `номинал − истина` | вычитается: `lat -= x[0]` |
| `x[6..8]` (углы) | `номинал − истина` | вычитается: `att.pitch -= x[7]` |
| `x[9..11]` (`ba`) | `истина − номинал` | складывается: `ba += x[9]` |
| `x[12..14]` (`bg`) | `истина − номинал` | складывается: `bg += x[12]` |

Тот же знак используется в матрице измерений `H_accel` (`src/ins/ins_filter.h:402`):
`∂h/∂x[6..8] = −Ĉᵀ·(n_u × f̂)`, `∂h/∂x[9..11] = −I`.

## 2. Предлагаемая начальная инициализация (окно 1 с, `t = T_align`)

### 2.1 Номинал

| Поле `NavState` | Значение | Откуда |
|---|---|---|
| `lat`, `lon`, `alt` | координаты СНС | **последний** отсчёт СНС окна (состояние относится к `T_align`) |
| `V` | `{v_n, v_h, v_e}` последнего отсчёта СНС | **последний** отсчёт СНС окна |
| `att.heading` | последний отсчёт курса в окне | `angle.dat`; иначе gyro-compassing с честным P0 |
| `att.pitch`, `att.roll` | `asin(f̄_X/g)`, `atan2(−f̄_Z, f̄_Y)` | средняя удельная сила за окно |
| `ba` | `f̄ − Cᵀ·[0, g, 0]` | окно усреднения (горизонтальная часть ≈ 0 по построению) |
| `bg` | `{0, 0, 0}` | оценка переносится в `x₀` (см. 2.2) |

### 2.2 Вектор начальных ошибок `x₀`

```
x₀[0..2]   = последний СНС − среднее СНС      (рад, рад, м)
x₀[3..5]   = последний СНС − среднее СНС      (м/с)
x₀[6]      = normalize(ψ_посл − ψ̄_круг)        (рад)
x₀[7..11]  = 0
x₀[12..14] = bg_est = ω̄ − navToBody(C, ω_Земли)
```

Два источника начальной ошибки, и оба — **знаковые**:

1. **Каналы СНС.** Номинал — последний отсчёт окна; на стоянке истинные
   позиция и скорости постоянны, поэтому лучшая доступная оценка истины —
   среднее по окну. Отклонение последнего отсчёта от среднего и есть (с
   точностью до ошибки среднего) ошибка номинала.
2. **Смещение гиро.** `bg_est` — оценка с известным знаком, но в номинал она
   не кладётся: её шум (`σ_ω̄ ≈ 31 °/ч`) сравним с самой величиной смещения
   (на `square_650` истинное `bg = [20, −15, 10] °/ч`). Запечь её в номинал —
   значит заранее ошибиться; положить её в `x₀` — значит дать фильтру взять
   оценку (штатная инъекция `st.bg += x[12+k]`,
   `src/navigation/trajectory.h:117`) и при этом оставить за собой право её
   уточнить, что и обеспечивает честная `P₀(bg)`.

Знаки: `x[0..8] = номинал − истина` ⇒ `x₀[0..6] = номинал − истина ≈
последний − среднее`; `x[12..14] = истина − номинал`, номинал `bg = 0` ⇒
`x₀[12..14] = bg_est`.

`x₀[7..8] = 0`: наклон взят из `f̄`, а его систематическая часть ошибки
(`ba_гор/g`) неизвестна — горизонтальный ba в покое не наблюдаем. Эта часть
описана полом в `P₀` и корреляцией `P[7][9]`, `P[8][11]`.
`x₀[9..11] = 0`: `ba` в номинале, горизонтальная часть оценки ≈ 0 по
построению (уровень по `f̄` «съедает» горизонтальное смещение).

Когда применяется: первый аксель-апдейт (первый отсчёт ИМУ с `t ≥ T_align`,
`src/navigation/trajectory.h:255`): `applyTiltKalmanCorrections` прибавляет
`x[12..14]` к `st.bg` и обнуляет `x[7..14]`. В `H_accel` колонок смещения
гиро нет, поэтому аксель-апдейт величину `x[12..14]` не меняет — только
инъецирует её в номинал.

`x₀[0..6]` применяются первой коррекцией СНС по последнему отсчёту окна
(`applyKalmanCorrections`, `src/navigation/trajectory.h:128`): `st.lat -= x[0]`
и т. д. — знак `x₀` согласован с конвенцией «номинал − истина»
(`src/navigation/trajectory.h:130-138`).

### 2.3 Ковариация `P₀`

Исходные измеренные по окну величины: `f̄`, `ω̄` (средние удельной силы и
угловой скорости), `Δa`, `Δω` (максимумы отклонений от среднего по осям),
`Δp`, `Δh`, `Δv`, `Δψ` (разбросы каналов СНС и курса в окне), `N` (число
отсчётов ИМУ в окне), `M` (число отсчётов СНС в окне).
Паспорт: `σ_ba = 5 мг = 4.905e-2 м/с²`, `σ_bg_паспорт = 5.0e-4 рад/с = 103 °/ч`.

Масштабирование максимума в СКО (коэффициент `k(N) = E[max|N(0,1)|]`:
N = 9 → 1.84, N = 201 → 2.97):

```
σ̂_отсчёта = Δ / k(N)          σ̂_среднего = σ̂_отсчёта / √N
```

Номинал из последнего отсчёта → `σ̂_отсчёта`; номинал из среднего →
`σ̂_среднего`.

```
σ_pos     = max( max(Δlat, Δlon)/R_Земли , sig_pos )         [рад]
σ_h       = max( Δalt , sig_h )                              [м]
σ_v       = max( max|Δv| , sig_v )                           [м/с]
σ_hdg     = max( Δψ , sig_hdg )                              [рад]
σ_наклон  = max( sqrt(σ_ba_гор² + σ_ā_гор²)/g , 2·σ_ba_гор/g )
σ_ba_верт = max( σ_ā_Y , σ_ba/10 )
σ_bg_гор  = max( σ_ω̄_гор , σ_bg_паспорт/5 )
σ_bg_верт = σ_bg_паспорт

P[0][0]  = P[1][1]  = σ_pos²             P[2][2]   = σ_h²
P[3..5]  = σ_v²                           P[6][6]   = σ_hdg²
P[7][7]  = P[8][8]  = σ_наклон²
P[9][9]  = P[11][11] = σ_ba_гор²          P[10][10] = σ_ba_верт²
P[12][12] = P[14][14] = σ_bg_гор²         P[13][13] = σ_bg_верт²
P[7][9]  = P[9][7]  = +σ_ba_гор²/g
P[8][11] = P[11][8] = −σ_ba_гор²/g
```

Остальные элементы нулевые. На `square_650` (окно 1 с, 200 Гц ИМУ, 10 Гц СНС):
`Δω` = (1321, 979, 1105) °/ч ⇒ `σ_ω̄` = (31, 23, 26) °/ч;
`Δa` = (11.46, 12.70, 11.23) мг ⇒ `σ_ā` = (0.27, 0.30, 0.27) мг;
`Δlat`/`Δlon` = 2.05/2.13 м, `Δalt` = 3.74 м, `Δv` ≤ 0.074 м/с, `Δψ` = 0.311°.
Итог: `σ_pos` = 1.5 м (пол), `σ_h` = 5 м (пол), `σ_v` = 0.048 м/с (пол),
`σ_hdg` = 0.169°, `σ_наклон` = 0.573° (пол), `σ_ba_верт` = 0.51 мг (пол),
`σ_bg_гор` = 31 °/ч, `σ_bg_верт` = 103 °/ч.

Смысл корреляций «наклон ↔ `ba`»: выставка по акселю кладёт в тангаж и крен не
истинный наклон, а сумму наклона и `ba_гор/g` (`x[7] = +ba_X/g`,
`x[8] = −ba_Z/g`), поэтому `P[7][9] = +σ_ba_гор²/g`,
`P[8][11] = −σ_ba_гор²/g`. По отдельности угол и смещение аксель-апдейтом
неразличимы (в `H_accel` дают одну и ту же ось тела) — эта связь и позволяет
перенести наблюдение из угла в смещение.

Полы обязательны: в наборе `square_noisefree` все максимумы нулевые, без полов
`P₀ = 0` ⇒ `K = 0` ⇒ фильтр не работает.

### 2.4 Отличия от текущего кода (`src/navigation/aligner.h:50`)

| Компонента | Сейчас | Предлагается |
|---|---|---|
| скорости `P[3..5]` | `2.5 м/с` (свободный масштаб) | `σ_v²` = `max(Δv, sig_v)²` ≈ 0.048 м/с |
| тангаж/крен `P[7][7]`, `P[8][8]` | `1°²` | `σ_наклон²` = 0.573°² (пол `2σ_ba_гор/g`) |
| курс `P[6][6]` | `max(sig_hdg, σ̂)` — шум **одного** отсчёта | `max(sig_hdg, Δψ)` — разброс курсов эталона в окне (0.169°) |
| вертикальный `ba` `P[10][10]` | паспорт 5 мг | `σ_ba_верт²` (наблюдаемо, 0.51 мг) |
| горизонтальный `ba` `P[9][9]`, `P[11][11]` | 5 мг | 5 мг (без изменений — структурно неразделимо от наклона) |
| `bg` `P[12..14]` | паспорт 103 °/ч | `σ_bg_гор²` = 31 °/ч, вертикаль — паспорт |
| `bg` в номинале | 0 | 0 (оценка в `x₀`) |
| скорости в номинале | `{0, 0, 0}` | последний отсчёт СНС окна |
| курс в номинале | первый отсчёт СНС | последний отсчёт курса в окне |
| `ba` в номинале | из выставки (медиана + EMA) | `f̄ − Cᵀ·[0,g,0]` (прямое среднее окна) |
| `x₀[0..6]` | 0 | «последний отсчёт − среднее» по каналам СНС |
| шум среднего | «batch means» (не реализован) | максимум отклонения от среднего, `σ̂ = Δ/k(N)` и `Δ/(k(N)√N)` |

### 2.5 Момент применения

```
t ∈ [0, T_align)   — окно усреднения: фильтр не идёт, читаются ИМУ и СНС
t = T_align        — номинал + x₀ + P₀; номинальному времени присвоено T_align
                     (state.time_prev = T_align)
t ≥ T_align        — первый такт: dt = t_имп − T_align; predict → аксель-апдейт
                     (применяет x₀[12..14])
t = t_снс1         — первая коррекция СНС: по первому кадру СНС за окном
                     (применяет x₀[0..6])
```

Первый такт интегрируется с `dt = t_имп − T_align`, а не с `t_имп`: иначе
первая секунда попала бы в интегрирование вместе с окном.

Первая коррекция выполняется по **первому кадру СНС за окном**, а не по
последнему отсчёту окна: последний отсчёт уже израсходован как номинал
(`lat/lon/alt/V/heading`), его инновация тождественно нулевая, и обновление по
нему только уменьшило бы `P` на `R`, ничего не измерив. Такты между `T_align`
и `t_снс1` (обычно 5–10 мс) идут без коррекции СНС, но с аксель-апдейтом.

Потоки не перематываются: «лишний» отсчёт ИМУ (первый с `t > T_align`)
возвращается в основной цикл (`pending_row`); первый кадр СНС за окном
становится начальным `last_ref`. Поэтому первая запись `errors.txt` появляется
на времени этого кадра (например, 1.0084 с на `square_650`), а первая запись
`result.txt` — на времени первого такта ИМУ за окном.

## 3. Инвентарь векторов

### 3.1 `x` — вектор ошибок состояния (15)

`NavState.x`, `src/navigation/trajectory.h:57`. Хранит оценку ошибок номинала.

| Индекс | Обозначение | Единицы | Смысл |
|---|---|---|---|
| 0 | `δφ` | рад | ошибка широты |
| 1 | `δλ` | рад | ошибка долготы |
| 2 | `δh` | м | ошибка высоты |
| 3 | `δV_n` | м/с | ошибка северной скорости |
| 4 | `δV_h` | м/с | ошибка вертикальной скорости |
| 5 | `δV_e` | м/с | ошибка восточной скорости |
| 6 | `δψ` | рад | ошибка курса |
| 7 | `δθ` | рад | ошибка тангажа |
| 8 | `δγ` | рад | ошибка крена |
| 9 | `ba_X` | м/с² | смещение акселя, ось «вперёд» |
| 10 | `ba_Y` | м/с² | смещение акселя, ось «вверх» |
| 11 | `ba_Z` | м/с² | смещение акселя, ось «вправо» |
| 12 | `bg_X` | рад/с | смещение гиро, ось «вперёд» |
| 13 | `bg_Y` | рад/с | смещение гиро, ось «вверх» |
| 14 | `bg_Z` | рад/с | смещение гиро, ось «вправо» |

Оси тела: X — вперёд, Y — вверх, Z — вправо; навигационная СК: North, Up,
East.

Где используется: `predict` (`x = F·x`), `correct` (`x += K·innov`),
`correctAccel` (`x += K·innov`), инъекции в номинал, вывод `errors.txt`
(время + `x0..x14`) и строки `result.txt` (там `номинал − x`, см.
`makeResult`, `src/navigation/trajectory.h:72`).

### 3.2 `z` — инновация СНС (9)

`zj = vector_diff(bins, sns)`, `src/ins/ins_filter.h:273`. Разность БИНС и
СНС на текущем кадре: `Δφ, Δλ, Δh, ΔV_n, ΔV_h, ΔV_e, Δψ, Δθ, Δγ`. Углы
приводятся к `(-π, π]` через `normalize_angle`.

### 3.3 `innov` — инновация с учётом текущей оценки (9)

`innov = z − H·x`, `src/ins/ins_filter.h:292`. Разность фактического
несоответствия и предсказанного фильтром несоответствия. Именно `innov`
домножается на `K` при коррекции.

### 3.4 `z_accel` (он же `z_body`) — инновация акселерометра (3)

`h(x̂) − y`, `src/navigation/trajectory.h:246`: разность предсказанной
удельной силы и сырого отсчёта акселерометра (включающего истинное смещение).
Модуль `z_accel_mag` используется гейтом аксель-апдейта; в сам фильтр идут
только оси X и Z (`KF_ACCEL_ROW = {0, 2}`).

### 3.5 `P_meas` — ковариация измеряемого подпространства (9×9)

Верхний блок `P`; используется только для диагностики NEES
(`src/ins/ins_filter.h:322`).

### 3.6 `Sinv_innov` — решение `S·y = innov` (9)

Считается методом Холецкого (S симметрична и положительно определена, но её
элементы различаются на порядки — рад² против м²/с², поэтому обращение
Гауссом-Жорданом давало бы ошибку в знаке квадратичной формы). Только для NIS.

### 3.7 Вспомогательные векторы номинала (не фильтр, но нужны для описания)

`V_dot_prev`, `lat_dot_prev`, `lon_dot_prev`, `alt_dot_prev`, `rates_prev` —
предыдущие производные для метода трапеций; `time_prev` — время последнего
такта; `bg_static` — статическое смещение гиро для `hdg_true`;
`tilt_maneuver_time` — время последнего «тихого» гироскопа (для гейта
аксель-апдейта).

## 4. Инвентарь матриц

Все матрицы хранятся построчно (row-major) в одномерном `std::vector<double>`;
число столбцов передаётся явно: `at(A, i, j, cols)`.

### 4.1 `P` — ковариация ошибок (15×15)

`NavState.P`, `src/navigation/trajectory.h:58`. Назначение: неопределённость
оценок `x`; определяет коэффициент усиления `K` и нормировку инновации.

- Начальное значение: `P₀` (см. 2.3).
- `predict`: `P = F·P·Fᵀ + Q`.
- `correct`, `correctAccel`: форма Джозефа
  `P = (I − K·H)·P·(I − K·H)ᵀ + K·R·Kᵀ` — симметрична и сохраняет
  положительную полуопределённость (упрощённая `(I−KH)·P` теряет симметрию и
  может давать отрицательные диагонали).
- После каждой инъекции: `apply_reset_covariance` (`src/ins/ins_filter.h:490`)
  — симметризация `(P + Pᵀ)/2` и страховка отрицательных диагоналей (→ `1e-15`).

### 4.2 `F` — матрица перехода состояния (15×15)

`Fj_matrix`, `src/ins/ins_filter.h:157`. Назначение: перенос ошибок за такт `T`
(дискретная модель, диагональ = 1, невырожденные блоки умножаются на `T`).

| Элемент | Значение | Связь |
|---|---|---|
| `F[0][3]` | `T / R_Земли` | `δφ̇ = δV_n / R` |
| `F[1][5]` | `T / (R_Земли·cos φ)` | `δλ̇ = δV_e / (R·cos φ)` |
| `F[2][4]` | `T` | `δḣ = δV_h` |
| `F[4][2]` | `T·2g/R_Земли` | гравитационный градиент: ошибка высоты → ошибка вертикальной скорости |
| `F[3][5]`, `F[4][5]`, `F[5][3]` | `∓T·2Ω·sin φ`, `T·2Ω·cos φ` | кориолисовы связи ошибок скоростей |
| `F[3..5][6..8]` | `T·(n_u × f_н)` | ошибки ориентации → ошибки скоростей |
| `F[3..5][9..11]` | `T·Ĉ` | смещения акселя → ошибки скоростей |
| `F[6..8][12..14]` | `T·E(ψ, θ, γ)` | смещения гиро → ошибки ориентации (связывающая матрица Эйлера) |

Оси вращения: `n_ψ = (0, −1, 0)` (курс растёт по часовой стрелке), `n_θ =
(−sin ψ, 0, cos ψ)`, `n_γ` — первый столбец `Ĉ_б^н`.

### 4.3 `Q` — шум процесса (15×15, диагональная)

`Qj_matrix`, `src/ins/ins_filter.h:73`. Назначение: рост неопределённости
из-за шумов датчиков и дрейфа смещений за такт `T`.

| Элемент | Значение | Источник |
|---|---|---|
| `Q[0..2][0..2]` | 0 | координаты шума не имеют |
| `Q[3..5][3..5]` | `sig_a²·T` | шум акселерометра |
| `Q[6..8][6..8]` | `sig_g²·T` | шум гироскопа |
| `Q[9..11][9..11]` | `sig_ba²·T` | дрейф смещения акселя |
| `Q[12..14][12..14]` | `sig_bg²·T` | дрейф смещения гиро |

### 4.4 `R` — шум измерений СНС (9×9, диагональная)

`Rj_matrix`, `src/ins/ins_filter.h:117`.

| Элемент | Значение | Примечание |
|---|---|---|
| `R[0][0]` | `sig_pos²` | широта, рад (1.5 м → `sig_pos = 1.5/R_Земли`) |
| `R[1][1]` | `(sig_pos/cos φ)²` | долгота: метровый шум по востоку в радианах = `sig_pos/cos φ`; при `|cos φ| < 0.05` берётся 0.05 (ограничение у полюсов) |
| `R[2][2]` | `sig_h²` | высота, м |
| `R[3..5][3..5]` | `sig_v²` | скорости, м/с |
| `R[6][6]` | `sig_hdg²` | курс; при отсутствии `angle.dat` — `1e6·DEG_TO_RAD`, строка фактически отключена |
| `R[7][7]`, `R[8][8]` | `sig_pitch²`, `sig_roll²` | в текущем коде всегда `1e6·DEG_TO_RAD`: тангаж и крен ведёт аксель-апдейт (200 Гц), СНС-строки отключены |

### 4.5 `R_accel` — шум измерения акселерометра (2×2)

`R_accel_matrix`, `src/ins/ins_filter.h:363`: диагональ
`(sig_a·√dt)²` — шум **одного** отсчёта акселерометра в осях X и Z.

### 4.6 `H` — матрица наблюдения СНС (9×15)

`H_matrix`, `src/math_lib/matrix_ops.h:300`: единицы на главной диагонали,
остальное нули. СНС наблюдает первые 9 компонент состояния (позиция,
скорости, углы); смещения датчиков (9..14) СНС не наблюдает.

### 4.7 `H_accel` — матрица наблюдения акселерометра (2×15)

`H_accel_matrix`, `src/ins/ins_filter.h:402`. Ненулевые блоки только:

| Элемент | Значение |
|---|---|
| `H[0..1][6..8]` | `−Ĉᵀ·(n_u × f_н)` (для `u = ψ, θ, γ`) — знак минус из-за вычитания углов в инъекции |
| `H[0][9]`, `H[1][11]` | `−1` — знак минус, потому что `h` предсказывает *измеренный* аксель (с `+b̂a`), а инъекция смещения — сложение |

Модель измерения: `h(x̂) = Ĉ_б^нᵀ·a_вред̂ + b̂a` при `V̇ ≈ 0`; ось Y
(модуль удельной силы) исключена намеренно — на ней полезного сигнала нет,
а неучтённый `V̇_Y` уходит туда целиком.

### 4.8 `S` — ковариация инновации (9×9 или 2×2)

`S = H·P·Hᵀ + R`. Назначение: нормировка инновации (NIS) и обращение при
расчёте `K`.

### 4.9 `K` — коэффициент усиления Калмана (15×9 или 15×2)

`K = P·Hᵀ·S⁻¹`. Назначение: вес, с которым инновация корректирует оценку.
В `correctAccel` строки `K[0..6]` обнуляются (`src/ins/ins_filter.h:451`) —
аксель-контур развязан от позиции/скорости/курса, чтобы корреляционные члены
`P·Hᵀ` не «протекали» в ошибки, живущие между кадрами СНС.

### 4.10 `E_KH = I − K·H` (15×15) и `E_KHᵀ`

Вспомогательные для формы Джозефа (4.1).

### 4.11 Внешние (не фильтровые, но входящие в `F` и `H_accel`) матрицы и векторы

| Объект | Что это | Где |
|---|---|---|
| `C` (3×3) | матрица направляющих косинусов СК тела → навигационная СК | `bodyToNavMatrix`, `src/navigation/trajectory.h:168` |
| `f_н` (3) | удельная сила в навигационной СК, `C·(f_б − ba)` | `src/navigation/trajectory.h:173` |
| `a_вред` (3) | вредные ускорения (Кориолис, центробежное, гравитация) | `harmfulAccel`, `src/navigation/position_calc.h` |
