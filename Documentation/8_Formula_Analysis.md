# Анализ формул: Теория vs Код

Сопоставление каждого уравнения из теории (Теория_БИНС_с_углами_Эйлера-Крылова.md) с соответствующим участком кода. Для каждого расхождения указывается допущение, следствием которого оно является.

---

## Согласование систем координат

### Теория (ГОСТ 20058-80)
- **OX_g** — на Север (касательная к меридиану)
- **OY_g** — на Восток (касательная к параллели)
- **OZ_g** — вверх (вертикаль места)

### Код (`types.h:14–18`)
- `pos = {Lat, Lon, Alt}`
- `vel = {V_north, V_up, V_east}` — т.е. **{Север, Вверх, Восток}**
- `euler = {Yaw, Pitch, Roll}`

**Несовпадение:** Код использует порядок осей **NUE** (North–Up–East), тогда как теория — **NEU** (North–East–Up). Оси X и Z в географической системе кода совпадают с теорией, а оси Y и Z поменяны местами.

Все формулы ниже записаны в терминах осей кода (NUE), где:
- `V_n = vel.x` (Север), `V_u = vel.y` (Вверх), `V_e = vel.z` (Восток)
- `lat = pos.x`, `lon = pos.y`, `alt = pos.z`

## 1. Переносная угловая скорость (ф-лы 3.6)

### Теория
$$\omega_{Xg} = U\cos\varphi + \frac{V_{Zg}}{R}, \quad \omega_{Yg} = U\sin\varphi + \frac{V_{Zg}}{R}\operatorname{tg}\varphi, \quad \omega_{Zg} = -\frac{V_{Xg}}{R}$$

где $V_{Xg}$ — Север, $V_{Zg}$ — Восток (ось OY_g в теории).

### Код (`sins_algorithm.h:24–35`)
```cpp
omega_xg = U * cos(lat) + V_e / R;
omega_yg = U * sin(lat) + (V_e / R) * tan(lat);
omega_zg = -V_n / R;
```

**Соответствие:** Полное. Код корректно подставляет `V_e` (Восток = OY_g) и `V_n` (Север = OX_g). Формулы теории и кода идентичны.

## 2. Начальная выставка — тангаж и крен (ф-лы для θ₀, γ₀)

### Теория
При покое акселерометры измеряют проекцию $g$ на связанную систему:
$$A_x = g\sin\theta, \quad A_y = g\cos\theta\cos\gamma, \quad A_z = -g\cos\theta\sin\gamma$$

Отсюда:
$$\theta_0 = \arcsin(A_x / g), \quad \gamma_0 = \operatorname{atan2}(-A_z, A_y)$$

### Код (`sins_algorithm.h:54–58`)
```cpp
double g_eff = calc_g_eff(state.pos.x, state.pos.z);
state.euler.y = asin(accel_meas.x / g_eff);       // pitch
state.euler.z = atan2(-accel_meas.z, accel_meas.y); // roll
```

**Соответствие:** Полное. Код реализует теоретические формулы напрямую.

---

## 3. Начальная скорость и рыскание

### Теория
В покое $V_{Xg} = V_{Yg} = V_{Zg} = 0$. Рыскание $\psi$ не определяется по акселерометрам (акселерометры не чувствительны к вращению вокруг вертикали).

### Код (`sins_algorithm.h:59,62`)
```cpp
state.euler.x = 0.0;  // yaw — не определяется
state.vel = {0.0, 0.0, 0.0};
```

**Допущение 1:** Начальная скорость = 0 (объект в покое).
**Допущение 2:** Начальное рыскание = 0 (нет внешнего датчика курса — магнитометр, GPS).

## 4. Кинематические уравнения ориентации (ф-лы 3.30)

### Теория
Относительная угловая скорость определяется в **географической** системе:
$$\omega_r = \omega_{gyro} - \omega_e$$

Уравнения Эйлера–Крылова (3.30):
$$\dot\psi = \frac{\omega_{Yg}^r \cos\gamma - \omega_{Zg}^r \sin\gamma}{\cos\theta}$$
$$\dot\theta = \omega_{Yg}^r \sin\gamma + \omega_{Zg}^r \cos\gamma$$
$$\dot\gamma = \omega_{Xg}^r - \operatorname{tg}\theta\,(\omega_{Yg}^r \cos\gamma - \omega_{Zg}^r \sin\gamma)$$

где $\omega_{Xg}^r, \omega_{Yg}^r, \omega_{Zg}^r$ — компоненты **в географической** системе (Север, Восток, Вверх).

### Код (`sins_algorithm.h:88–103`)
```cpp
// Относительная угловая скорость (В СВЯЗАННОЙ системе)
omega_r.x = gyro_meas.x - omega_e_body.x;
omega_r.y = gyro_meas.y - omega_e_body.y;
omega_r.z = gyro_meas.z - omega_e_body.z;

// Уравнения Эйлера–Крылова
dot_yaw   = (omega_r.y * cos(roll) - omega_r.z * sin(roll)) / cos_p;
dot_pitch = omega_r.y * sin(roll) + omega_r.z * cos(roll);
dot_roll  = omega_r.x - tan(pitch) * (omega_r.y * cos(roll) - omega_r.z * sin(roll));
```

**Расхождение 1 — несовпадение кадров (frames):**

Код вычисляет `omega_r` в **связанной** системе:
```cpp
omega_e_body = C^T · omega_e    // проекция географической ω на связанную
omega_r = gyro - omega_e_body   // разность в связанной системе
```

Затем подставляет `omega_r` (связанная система) в формулы (3.30), которые предназначены для **географической** системы.

В теории:
- $\omega_{Xg}^r$ — компонента по Северу (географическая)
- $\omega_{Yg}^r$ — компонента по Востоку (географическая)
- $\omega_{Zg}^r$ — компонента по Вертикали (географическая)

В коде:
- `omega_r.x` — по оси OX связанной (нос)
- `omega_r.y` — по оси OY связанной (вверх)
- `omega_r.z` — по оси OZ связанной (правый борт)

Формулы (3.30) математически неверны при подстановке компонент связанной системы. Корректный вариант — либо пересчитать `omega_r` в географическую систему (`C · omega_r`), либо использовать кинематические уравнения, записанные для связанной системы.

**Допущение 3:** Используются географические кинематические уравнения (3.30) с компонентами связанной системы. Это упрощение допустимо при малых углах (тангаж и крен ≈ 0), когда связанная и географическая системы почти совпадают. Для наземных объектов с малыми углами наклона погрешность мала.

## 6. Компенсация вредных ускорений (ф-лы 3.15)

### Теория
Полные компенсирующие ускорения (формула 3.15):

**Север (Xg):**
$$a_{Xg}^k = \frac{V_{Zg}^2}{R}\operatorname{tg}\varphi + \frac{V_{Xg}V_{Yg}}{R} + 2UV_{Zg}\sin\varphi$$

**Восток (Yg):**
$$a_{Yg}^k = -\frac{V_{Zg}^2}{R} - \frac{V_{Xg}^2}{R} - 2UV_{Zg}\cos\varphi + g$$

**Вертикаль (Zg):**
$$a_{Zg}^k = \frac{V_{Zg}V_{Yg}}{R} - \frac{V_{Xg}V_{Zg}}{R}\operatorname{tg}\varphi + 2(V_{Yg}U\cos\varphi - UV_{Xg}\sin\varphi)$$

Перевод в термины кода (NUE: $V_{Xg}=V_n$, $V_{Yg}=V_e$, $V_{Zg}=V_u$):

**Север:**
$$a_n^k = \frac{V_u^2}{R}\operatorname{tg}\varphi + \frac{V_n V_e}{R} + 2UV_u\sin\varphi$$

**Восток:**
$$a_e^k = -\frac{V_u^2}{R} - \frac{V_n^2}{R} - 2UV_u\cos\varphi + g$$

**Вертикаль:**
$$a_u^k = \frac{V_u V_e}{R} - \frac{V_n V_u}{R}\operatorname{tg}\varphi + 2(V_e U\cos\varphi - UV_n\sin\varphi)$$

### Код (`sins_algorithm.h:123–124`)
```cpp
double a_k_x = (V_e / R) * (2 * U * sin(lat) + (V_e / R) * tan(lat));
double a_k_z = -(V_n / R) * (2 * U * sin(lat) + (V_e / R) * tan(lat));
```

Разложение кода:
$$a_k^{code\_x} = \frac{2UV_e\sin\varphi}{R} + \frac{V_e^2}{R^2}\operatorname{tg}\varphi$$
$$a_k^{code\_z} = -\frac{2UV_n\sin\varphi}{R} - \frac{V_n V_e}{R^2}\operatorname{tg}\varphi$$

**Расхождения:**

| Компонент | Теория | Код | Статус |
|-----------|--------|-----|--------|
| **Север** | | | |
| $2UV_u\sin\varphi$ | ✓ | ✓ (`2*U*sin(lat)`) | Совпадает |
| $V_u^2/R \cdot \operatorname{tg}\varphi$ | ✓ | ✗ | **Отсутствует** ($V_u = 0$ — допущение 4) |
| $V_n V_e / R$ | ✓ | ✗ | **Отсутствует** (член смешения) |
| **Восток** | | | |
| $-2UV_u\cos\varphi$ | ✓ | ✗ | **Отсутствует** ($V_u = 0$ — допущение 4) |
| $-V_n^2/R$ | ✓ | ✗ | **Отсутствует** ($V_n$ мало) |
| $-V_u^2/R$ | ✓ | ✗ | **Отсутствует** ($V_u = 0$ — допущение 4) |
| $+g$ | ✓ | ✗ | **Вынесено отдельно** (строка 129) |
| Код: $V_e^2/R^2 \cdot \operatorname{tg}\varphi$ | ✗ | ✓ | **Лишний член** (не соответствует теории) |
| Код: $-V_n V_e/R^2 \cdot \operatorname{tg}\varphi$ | ✗ | ✓ | **Лишний член** (не соответствует теории) |

**Допущение 4:** Вертикальная скорость $V_u = V_{Yg} = 0$ (наземный объект, вертикальный канал заблокирован). Вследствие этого:
- Все члены, содержащие $V_u$ (Centripetal, Coriolis vertical), обращаются в нуль
- Член $V_u^2/R \cdot \operatorname{tg}\varphi$ исчезает из северного канала
- Член $-2UV_u\cos\varphi$ исчезает из восточного канала

**Допущение 5:** Члены $V_n V_e / R$ (смешение северной и восточной скоростей) и $-V_n^2/R$ (Centripetal от северной скорости) опущены как малые для наземных объектов ($V_n \ll U \cdot R$).

**Расхождение 6 (возможная ошибка):** Код содержит члены $V_e^2/R^2 \cdot \operatorname{tg}\varphi$ и $-V_n V_e/R^2 \cdot \operatorname{tg}\varphi$, которые **отсутствуют** в формуле (3.15) для горизонтальных каналов. Эти члены не являются следствием какого-либо допущения из теории — они появляются в результате упрощённой записи компенсации.

## 7. Интегрирование скоростей (ф-лы 3.16–3.17)

### Теория
$$\dot{V}_{Xg} = n_{Xg} - a_{Xg}^k, \quad \dot{V}_{Zg} = n_{Zg} - a_{Zg}^k$$

### Код (`sins_algorithm.h:127–133`)
```cpp
double dot_V_n = n_g.x - a_k_x;
double dot_V_e = n_g.z - a_k_z;
state.vel.x += dot_V_n * dt;
state.vel.z += dot_V_e * dt;
```

**Соответствие:** Структурно верно — вычитание компенсации из измерений. Количественное расхождение определено в п. 6.

## 8. Блокировка вертикального канала

### Теория
Формулы (3.17)–(3.18) предполагают интегрирование по всем трём осям, включая высоту:
$$h = h(t_0) + \int V_{Yg}\,dt$$

### Код (`sins_algorithm.h:136–137`)
```cpp
state.vel.y = 0.0;   // V_up = 0
state.pos.z = 0.0;   // Alt = 0
```

**Допущение 4 (продолжение):** Вертикальный канал заблокирован. Объект движется по поверхности Земли, высота постоянна.

## 9. Интегрирование координат (ф-лы 3.18)

### Теория

```cpp

```

**Соответствие:** Полное. Формулы теории и кода идентичны.

## 10. Матрица поворота (ф-лы 3.19–3.26)

### Теория
Последовательность поворотов $A = A_\gamma \cdot A_\theta \cdot A_\psi$ (формула 3.24):

$$A = \begin{pmatrix} \cos\theta\cos\psi & \sin\theta & -\cos\theta\sin\psi \\ -\cos\gamma\cos\psi\sin\theta + \sin\gamma\sin\psi & \cos\gamma\cos\theta & \cos\gamma\sin\psi\sin\theta + \sin\gamma\cos\psi \\ \sin\gamma\cos\psi\sin\theta + \cos\gamma\sin\psi & -\sin\gamma\cos\theta & -\sin\gamma\sin\psi\sin\theta + \cos\gamma\cos\psi \end{pmatrix}$$

### Код (`math_utils.h:40–51`)
```
C[0][0] = c_p*c_y;           C[0][1] = -c_r*c_y*s_p + s_r*s_y;  C[0][2] = s_r*c_y*s_p + c_r*s_y;
C[1][0] = s_p;               C[1][1] = c_r*c_p;                  C[1][2] = -s_r*c_p;
C[2][0] = -c_p*s_y;          C[2][1] = c_r*s_y*s_p + s_r*c_y;   C[2][2] = -s_r*s_y*s_p + c_r*c_y;
```

**Соответствие:** Полное. Матрица кода точно соответствует формуле (3.24) для последовательности поворотов Y→Z→X (ψ围绕 OY_g, θ围绕 OZ', γ围绕 OX'').

## 11. Метод интегрирования

### Теория
Рекомендуется численное интегрирование методами высшего порядка.

### Код (`sins_algorithm.h:105–107, 132–133, 140–141`)
```cpp
state.euler.x += dot_yaw * dt;    // метод Эйлера (1-й порядок)
state.vel.x += dot_V_n * dt;
state.pos.x += (state.vel.x / R) * dt;
```

**Допущение 6:** Используется явный метод Эйлера (первого порядка). При частоте 400 Гц (dt = 0.0025 с) ошибка за шаг мала, но накапливается.

## Классификация допущений

### Следствия физических ограничений (корректны для наземных объектов)
1. **$V_u = 0$** — вертикальный канал заблокирован → все члены с $V_u$ обращаются в нуль
2. **Начальная скорость = 0** — объект в покое при выставке
3. **Высота = 0** — движение по поверхности Земли

### Следствия отсутствия оборудования
4. **$\psi_0 = 0$** — нет магнитометра или GPS для определения начального курса

### Упрощения алгоритма
5. **Опущены члены $V_n V_e/R$, $V_n^2/R$** — малы для наземных объектов ($V \ll U \cdot R \approx 465$ м/с)
6. **Метод Эйлера** вместо Рунге–Кутты — достаточен при частоте 400 Гц
7. **Смешение кадров** в уравнениях ориентации — допустимо при малых углах (тангаж, крен $\approx 0$)

### Возможные ошибки (не являются допущениями)
8. **Члены $V_e^2/R^2 \cdot \operatorname{tg}\varphi$ и $-V_n V_e/R^2 \cdot \operatorname{tg}\varphi$** в коде отсутствуют в формуле (3.15) — не является следствием допущения, вероятно ошибка в записи формулы компенсации
