# Руководство разработчика

## 1. Архитектура проекта

Проект построен по принципу **модульности через заголовочные файлы** — вся логика реализована в `.h` файлах как `inline`-функции. `main.cpp` содержит только оркестрацию.

```
types.h              ← Базовые типы (Vec3, Mat3, NavState, IMU_Record, Nav_Record)
    │
    ├── math_utils.h      ← Векторная алгебра (не зависит от других модулей)
    │
    ├── file_loader.h     ← Файловый ввод (зависит от types.h)
    │
    ├── signal_processing.h ← Обработка сигналов (зависит от types.h, file_loader.h)
    │
    └── sins_algorithm.h  ← Ядро алгоритма (зависит от types.h, math_utils.h)
```

### Порядок включения в `main.cpp`

```cpp
#include "types.h"              // 1. Базовые типы
#include "file_loader.h"        // 2. Загрузка данных
#include "signal_processing.h"  // 3. Обработка сигналов
#include "sins_algorithm.h"     // 4. Навигационный алгоритм
```

## 2. Описание структур данных

### 2.1. `Vec3` — трёхмерный вектор (`types.h:11`)

```cpp
struct Vec3 { double x, y, z; };
```

Используется для хранения координат, скоростей, углов, ускорений. Поле `x, y, z` интерпретируются по контексту:

| Контекст | x | y | z |
|----------|---|---|---|
| `NavState.pos` | Lat (рад) | Lon (рад) | Alt (м) |
| `NavState.vel` | V_north (м/с) | V_up (м/с) | V_east (м/с) |
| `NavState.euler` | Yaw (рад) | Pitch (рад) | Roll (рад) |
| `NavState.accel` | Ax (м/с²) | Ay (м/с²) | Az (м/с²) |
| `NavState.gyro` | Wx (рад/с) | Wy (рад/с) | Wz (рад/с) |

### 2.2. `Mat3` — матрица 3×3 (`types.h:12`)

```cpp
struct Mat3 { double data[3][3]; };
```

Хранит матрицу направляющих косинусов (МНК) `C` и промежуточные матрицы.

### 2.3. `NavState` — состояние навигации (`types.h:14-22`)

Главный контейнер состояния БИНС:

```cpp
struct NavState {
    double T_sys, T_reg, T_rem, T_nav;  // Метки времени фаз
    Vec3 pos;       // {Lat, Lon, Alt} — позиция
    Vec3 vel;       // {V_north, V_up, V_east} — скорости
    Vec3 euler;     // {Yaw, Pitch, Roll} — углы ориентации
    Mat3 C;         // Матрица направляющих косинусов
    Vec3 accel;     // Текущие показания акселерометра
    Vec3 gyro;      // Текущие показания гироскопа
};
```

### 2.4. `IMU_Record` — запись IMU (`types.h:24-28`)

```cpp
struct IMU_Record {
    double Time;
    double Ax, Ay, Az;
    double Wx, Wy, Wz;
};
```

### 2.5. `Nav_Record` — запись навигационных параметров (`types.h:30-34`)

```cpp
struct Nav_Record {
    double T_sys, T_reg, T_rem, T_nav;
    double Lon, Lat, Alt;
    double alignment_end_T;  // T_sys на границе перехода выставка→навигация
};
```

## 3. Описание ключевых функций

### 3.1. `SINS_Algorithm::initializeAlignment()` (`sins_algorithm.h:40-63`)

Метод начальной выставки. Вызывается **один раз** после усреднения данных выставки.

**Входные параметры:**
- `T_sys, T_reg, T_rem, T_nav` — метки времени из `Nav.dat`
- `nav_start_T` — время окончания выставки (= `alignment_end_T`)
- `accel_meas, gyro_meas` — усреднённые показания датчиков за этап выставки
- `init_lat, init_lon, init_alt` — начальные координаты (в рад/м)

**Действия:**
1. Заполняет начальное состояние `NavState`
2. Вычисляет эффективное `g` для текущей широты и высоты
3. Определяет начальные Pitch и Roll по акселерометрам
4. Yaw устанавливается в 0 (не определяется в покое)
5. Вычисляет начальную МНК `C` из углов
6. Обнуляет скорости

### 3.2. `SINS_Algorithm::updateNavigation()` (`sins_algorithm.h:67-141`)

Основной навигационный цикл. Вызывается **для каждого сэмпла** IMU после выставки.

**Входные параметры:**
- `current_T_sys` — текущее время из IMU
- `accel_meas` — текущие показания акселерометра (м/с²)
- `gyro_meas` — текущие показания гироскопа (рад/с)

**Алгоритм (на каждом шаге):**
1. **Проверка фильтра**: пропуск, если `current_T_sys < T_nav`
2. **Вычисление dt**: разность текущего и предыдущего времени
3. **Ориентация**:
   - Расчёт переносной угловой скорости `ω_e`
   - Пересчёт в связанную систему: `ω_e_body = C^T · ω_e`
   - Вычисление относительной скорости: `ω_r = ω_gyro − ω_e_body`
   - Интегрирование углов Эйлера–Крылова
   - Обновление МНК `C`
4. **Навигация**:
   - Пересчёт ускорения в географическую систему: `n_g = C · a_body`
   - Компенсация Кориолиса
   - Интегрирование скоростей (V_north, V_east)
   - Блокировка вертикального канала (V_up = 0, Alt = 0)
   - Интегрирование координат (Lat, Lon)

### 3.3. `calc_g_eff()` (`sins_algorithm.h:16-21`)

Вычисление эффективного ускорения свободного падения:

```
g_eff = GM / R² − Ω² · R · cos²(lat)
```

### 3.4. `calc_omega_e()` (`sins_algorithm.h:24-35`)

Вычисление проекций переносной угловой скорости географического трёхгранника.

## 4. Файловый ввод-вывод

### 4.1. `IMU_Stream` (`file_loader.h:13-43`)

Потоковый загрузчик IMU-данных. Не загружает весь файл в память.

```cpp
IMU_Stream stream;
stream.open("INS_Data/1/IMU.txt");  // Пропускает 2 строки заголовка
IMU_Record rec;
while (stream.readNext(rec)) {
    // Обработка rec
}
// Деструктор автоматически закрывает файл
```

**Особенности:**
- Пропускает строки заголовка и единиц измерения
- Рекурсивно пропускает пустые строки
- Деструктор автоматически закрывает файл

### 4.2. `loadNav()` (`file_loader.h:46-91`)

Загрузчик `Nav.dat`. Читает весь файл для определения границы фаз.

```cpp
Nav_Record nav;
if (!loadNav("INS_Data/1/Nav.dat", nav)) {
    // Ошибка
}
// nav.alignment_end_T = 332 (T_sys последней строки выставки)
```

**Логика:**
1. Пропускает заголовок и единицы
2. Читает все строки, сохраняя параметры первой
3. Находит первую строку с `T_nav > 0`
4. Устанавливает `alignment_end_T` равным `T_sys` предыдущей строки

## 7. Обработка ошибок

| Ситуация | Реакция | Сообщение |
|----------|---------|-----------|
| `Nav.dat` не найден или пуст | `return -1` | `Ошибка: Не удалось загрузить Nav.dat` |
| `IMU.txt` не найден | `return -1` | `Ошибка: Не удалось открыть IMU.txt` |
| Нет данных для выставки | `return -1` | `Ошибка: Недостаточно данных для T_reg` |
| Сингулярность (Pitch ≈ 90°) | Пропуск шага | Нет вывода |
| `dt ≤ 0` | Подстановка `dt = 0.001` | Нет вывода |
