# Спецификация формата вывода данных

## 1. Поля выходных данных

Программа выводит навигационное состояние в консоль. Каждая строка содержит:

| Поле | Описание | Единицы | Формат |
|------|----------|---------|--------|
| T | Системное время | с | десятичное |
| Lat | Широта | ° | десятичное |
| Lon | Долгота | ° | десятичное |
| Yaw | Угол рыскания (от Севера по часовой) | ° | десятичное |
| Pitch | Угол тангажа (подъём носа) | ° | десятичное |
| Roll | Угол крена | ° | десятичное |
| Vn | Скорость на Север | м/с | десятичное |
| Ve | Скорость на Восток | м/с | десятичное |

## 2. Формат строки вывода

```
T=<время>s | Lat=<широта>° Lon=<долгота>° | Yaw=<угол>° Pitch=<угол>° Roll=<угол>° | Vn=<скорость> Ve=<скорость> m/s
```

### Пример

```
T=332.053s | Lat=54.9522° Lon=38.5388° | Yaw=0.0001° Pitch=-1.25° Roll=0.76° | Vn=0.00236 Ve=0.000655 m/s
```

## 3. Сообщения программы

| Сообщение | Описание |
|-----------|----------|
| `Этап выставки: <N> сэмплов усреднено` | Количество IMU-записей, использованных для выставки |
| `БИНС инициализирована. Начало навигации...` | Переход от выставки к навигации |
| `Обработка завершена` | Все данные обработаны |
| `Ошибка: Не удалось загрузить Nav.dat` | Файл Nav.dat не найден или пуст |
| `Ошибка: Не удалось открыть IMU.txt` | Файл IMU.txt не найден |
| `Ошибка: Недостаточно данных для T_reg` | IMU-данные заканчиваются до границы выставки |

## 4. Интервал вывода

По умолчанию выводятся **первые 20 состояний** системы сразу после начала навигации. Это позволяет:
- Убедиться в корректной инициализации
- Оценить начальные углы и скорости
- Проверить, что программа работает

Для получения полного лога необходимо изменить условие в `main.cpp`:

```cpp
// Вывод каждые N сэмплов (вместо первых 20)
if (++counter % 1000 == 0) {
    printNavState(sins.getCurrentState(), rec.Time);
}
```

## 5. Рекомендуемый формат для экспорта

Для визуализации в MATLAB, Python или GIS-системах рекомендуется CSV:

```csv
T,Lat,Lon,Vn,Ve,Yaw,Pitch,Roll
333.0,54.9522,38.5388,0.00236,0.000655,0.0001,-1.25,0.76
333.0025,54.9522,38.5388,0.00237,0.000654,0.0001,-1.25,0.76
...
```

### Пример чтения в Python

```python
import pandas as pd
import matplotlib.pyplot as plt

df = pd.read_csv("output.csv")
plt.plot(df['T'], df['Lat'], label='Lat')
plt.plot(df['T'], df['Lon'], label='Lon')
plt.legend()
plt.show()
```

### Пример чтения в MATLAB

```matlab
data = readtable('output.csv');
plot(data.T, data.Lat, 'b', data.T, data.Lon, 'r');
legend('Lat', 'Lon');
xlabel('Time (s)');
ylabel('Degrees');
```
