# Руководство по данным

## 1. Формат файла `Nav.dat`

### Назначение
Содержит временной ряд навигационных параметров, включая границы фаз (выставка → навигация) и начальные координаты.

### Формат
Текстовый файл, разделённый пробелами. Первая строка — заголовки, вторая — единицы измерения, далее — данные.

### Столбцы

| № | Имя | Описание | Единицы |
|---|-----|----------|---------|
| 1 | T_sys | Системное время | с |
| 2 | T_reg | Время регистрации (выставки). Равен T_sys во время выставки, сбрасывается при переходе к навигации | с |
| 3 | T_rem | Оставшееся время выставки. Убывает от начального значения до 0 | с |
| 4 | T_nav | Время навигации. 0 во время выставки, растёт после перехода | с |
| 5 | Lon.i | Долгота (инерциальная) | град |
| 6 | Lat.i | Широта (инерциальная) | град |
| 7 | Alt.i | Высота (инерциальная) | м |
| 8–10 | Ve.i, Vn.i, Vup.i | Скорости (инерциальные) | м/с |
| 11–13 | Pitch.i, Roll.i, Hdg.i | Углы ориентации (инерциальные) | град |
| 14–26 | ...iso, ...s | Данные от других систем (ISO, спутниковая) | — |
| 27–30 | NGlo, NGPS, NSBas, CertS | Количество спутников и достоверность | — |
| 31–33 | Ax, Ay, Az | Показания акселерометра | м/с² |
| 34–36 | Wx, Wy, Wz | Показания гироскопа | град/с |
| 37 | Td | Температура датчика | — |

### Пример данных

```
Tsys Treg Trem Tnav Lon.i Lat.i Alt.i ...
20 20 700 0 38.538802 54.952222 177.987 ...
21 21 699 0 38.538802 54.952222 177.987 ...
```

### Важные замечания

- **Переход фаз**: В строке, где `T_nav > 0` впервые, начинается навигация. Предыдущая строка — конец выставки.
- **Программа использует**: `T_sys, T_reg, T_rem, T_nav, Lon.i, Lat.i, Alt.i` (первые 7 столбцов данных).
- **Начальные координаты**: Берутся из первой строки данных ( Lon.i, Lat.i, Alt.i ).

## 2. Формат файла `IMU.txt`

### Назначение
Сырые данные инерциальных датчиков (акселерометры и гироскопы) с высокой частотой дискретизации.

### Формат
Текстовый файл, разделённый пробелами. Первая строка — заголовки, вторая — единицы измерения, далее — данные.

### Столбцы

| № | Имя | Описание | Единицы |
|---|-----|----------|---------|
| 1 | Time | Метка времени | с |
| 2 | Ax | Ускорение по оси X (нос) | м/с² |
| 3 | Ay | Ускорение по оси Y (вверх) | м/с² |
| 4 | Az | Ускорение по оси Z (правый борт) | м/с² |
| 5 | Wx | Угловая скорость по оси X | град/с |
| 6 | Wy | Угловая скорость по оси Y | град/с |
| 7 | Wz | Угловая скорость по оси Z | град/с |

### Пример данных

```
Time Ax Ay Az Wx Wy Wz
s m/s^2 m/s^2 m/s^2 deg/s deg/s deg/s
20.0000 -0.376809 9.764421 -0.110576 0.018553 0.017774 -0.001928
20.0025 -0.321258 9.897816 -0.072462 0.006383 0.002539 0.002399
```

### Параметры

- **Шаг дискретизации**: 0.0025 с (400 Гц)
- **Начальное время**: 20.0 с (совпадает с `T_sys` из первой строки `Nav.dat`)
- **Типичный объём**: ~4 миллиона строк (10183 с данных)

## 3. Временная синхронизация

### Определение шага интегрирования

Программа **не использует фиксированный dt**. Шаг вычисляется автоматически:

```cpp
double dt = state.T_sys - last_T_sys;
if (dt <= 0.0) dt = 0.001;  // Защита от вырожденных случаев
```

### Фазы временной шкалы

```
T=20 ──────── T=332 ──────── T=333 ──────────── T=10203
 │              │              │                   │
 ▼              ▼              ▼                   ▼
Начало       Конец         Начало              Конец
выставки     выставки      навигации           данных
```

- **Выставка** (20–332 с): IMU-данные усредняются для определения начальных углов
- **Навигация** (333–10203 с): Полный цикл БИНС (ориентация + счисление пути)

## 4. Директория `INS_Data/`

Содержит наборы тестовых данных в подпапках:

```
INS_Data/
├── 1/    # Набор 1: ~10183 с данных
│   ├── IMU.txt
│   └── Nav.dat
├── 2/    # Набор 2
│   ├── IMU.txt
│   └── Nav.dat
└── 3/    # Набор 3
    ├── IMU.txt
    └── Nav.dat
```

Выбор набора данных осуществляется аргументом командной строки:
```bash
./sins 1   # Набор 1 (по умолчанию)
./sins 2   # Набор 2
```
