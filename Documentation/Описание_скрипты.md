# Описание скриптов (Python)

## Структура

```
Boxcar.py                     - Сглаживание методом Boxcar
Gaussian.py                   - Сглаживание методом Gaussian
Progressive.py                - Сглаживание методом Progressive
Hybrid (Boxcar + Progressive).py - Гибридное сглаживание
Comparison.py                 - Сравнительный анализ методов
plot_angles.py                - Визуализация углов
plot_method.py                - Визуализация методов сглаживания
```

---

## Boxcar.py

Реализация **Boxcar-фильтра** (скользящее среднее).

### Принцип работы
- Берёт окно фиксированного размера
- Вычисляет среднее арифметическое всех точек в окне
- Сдвигает окно на 1 позицию

### Особенности
- Простая реализация
- Одинаковый вес для всех точек в окне
- Быстрое вычисление: O(n)
- Плохо сглаживает выбросы

---

## Gaussian.py

Реализация **Гауссова фильтра** (взвешенное скользящее среднее).

### Принцип работы
- Создаёт гауссово ядро (нормальное распределение)
- Веса убывают от центра окна к краям
- Свёртка сигнала с ядром

### Особенности
- Больший вес центральным точкам
- Лучшее сглаживание шума по сравнению с Boxcar
- Сложность: O(n × window)
- Параметр σ = window/6

---

## Progressive.py

Реализация **Progressive-фильтра** (расширяющееся среднее).

### Принцип работы
- На каждом шаге использует ВСЕ данные от начала до текущей позиции
- Среднее накапливается: mean[i] = sum(data[0..i]) / (i+1)

### Особенности
- Максимальная гладкость для длинных рядов
- Сложность: O(n)
- Медленная сходимость в начале (мало данных)
- Идеально для стационарных процессов

---

## Hybrid (Boxcar + Progressive).py

**Гибридный фильтр** — комбинация Boxcar и Progressive.

### Принцип работы
- **Первые N отсчётов**: Boxcar (стабильное начало)
- **N до 2N отсчётов**: линейная интерполяция между Boxcar и Progressive
- **После 2N отсчётов**: чистый Progressive

### Особенности
- Устраняет начальный артефакт Progressive
- Плавный переход между методами
- Баланс между стабильностью и гладкостью

---

## Comparison.py

**Сравнительный анализ** всех методов сглаживания.

### Функционал
- Сравнивает Boxcar, Gaussian, Progressive, Hybrid
- Вычисляет метрики качества (RMSE, MAE, SNR)
- Строит графики сравнения
- Сохраняет результаты в `comparison.png` и `comparison_errors.png`

---

## plot_angles.py

**Визуализация углов** ориентации (Pitch, Roll, Yaw).

### Функционал
- Строит 6 графиков (3 пары):
  - Pitch vs время + Pitch RMSE
  - Roll vs время + Roll RMSE
  - Yaw vs время + Yaw RMSE
- Показывает сырые данные (голубые) и сглаженные (оранжевые)
- Running RMSE показывает накопительную ошибку

### Использование
```bash
python plot_angles.py [folder]
```
- `folder` — путь к папке с `output.txt` (опционально)

### Выход
- `angles.png` — график с 6 панелями

---

## plot_method.py

**Визуализация результатов** конкретного метода сглаживания.

### Функционал
- Строит графики для одного выбранного метода
- Показывает сырые и сглаженные данные
- Отображает ошибку (разницу между raw и smoothed)

### Использование
```bash
python plot_method.py [method] [folder]
```
- `method` — имя метода (boxcar, gaussian, progressive, hybrid)
- `folder` — путь к папке с данными
