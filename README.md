# Учебные материалы

Ветка `Education` содержит учебные материалы для студентов ИТТ.

## Содержание

- **C++ Primer Lippman.pdf** — учебник по языку C++
- **ALGO_INS.pdf** — материалы по алгоритмам
- **Матвеев Распопов Основы проектирования БИНС.pdf** — основы проектирования бесплатформенных инерциальных навигационных систем
- **Навигация летательных аппаратов в околоземном пространстве.pdf** — навигация летательных аппаратов
