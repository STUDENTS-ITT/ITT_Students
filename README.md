# ITT_Students (NoQT) — комплексирование видео, СНС и БИНС

Консольная версия проекта БИНС/СНС с фильтром Калмана 15-го порядка. Это та же
математика, что и в Qt-версии (`ITT_Students_Qt_Version`), но **без Qt**:
собирается чистым C++17 (STL) и даёт только штатный запуск `imitator`.

Ядро (ESKF, матрицы, интеграторы, чтение/запись `.dat`) лежит плоско в `src/` и
не зависит от Qt. Движок прогона — от выбора файлов и выставки до основного
цикла и записи результатов — целиком в `src/main.cpp`, как в исходной версии.
Нововведённая аналитика (журнал смещений, NIS-выгрузка, отчёт по смещениям) в
коде сохранена, но в штатном запуске не участвует: включается только явными
флагами `--bias-log`, `--consistency`, `--bias-report`.

## Сборка и запуск

```bash
# Из корня NoQT. MinGW (GCC) + CMake, без Qt.
cmake -S . -B build -G "MinGW Makefiles" -DCMAKE_BUILD_TYPE=Release
cmake --build build --target imitator

# Запуск (каталог данных по умолчанию — ../data/raw относительно CWD)
./build/imitator.exe data/raw

# Либо как в исходном проекте, из каталога build:
cd build
./imitator.exe

# С необязательным params.ini (плоский формат исходной версии):
./imitator.exe data/raw params.ini

# Диагностика (в штатном запуске выключена):
./imitator.exe data/raw --bias-log --consistency
./imitator.exe data/raw --bias-report
```

Аргументы:

| Аргумент | Назначение |
|---|---|
| `каталог_данных` | каталог с `imu.dat`/`imu.data`, `gps.dat`/`gps.data`, `angle.dat`/`angle.data`, `StartupNav.ini`; по умолчанию `../data/raw` |
| `params.ini` | необязательный плоский файл шумов фильтра: `sigma_g`, `sigma_a`, `sigma_bg`, `sigma_ba`, `sigma_pos`, `sigma_v`, `sigma_ang`, `outage_start_s`, `outage_end_s` |
| `--bias-log` | писать `tools/bias.txt` — журнал оценок смещений ДУС/акселя |
| `--consistency` | писать `tools/consistency.txt` — согласованность фильтра (NIS) на кадрах коррекции по СНС |
| `--bias-report` | прогнать набор и вывести сводную таблицу по смещениям (истина — из `params.json` набора) |

`settings.ini` не поддерживается: тюнера и пресетов нет, пороги сведения
наклона заданы умолчаниями `TiltManeuverPolicy`.

Результаты (`result.txt`, `reference.txt`, `errors.txt`) пишутся в `tools/`
рядом с рабочим каталогом (`utils::toolsDir`).

Выход `imitator` бит-в-бит совпадает с консольным `imitator` Qt-версии на том же
ядре: проверено сравнением md5 всех файлов результатов.

## Визуализация

```bash
# Интерактивное окно «Калман vs эталон» (по свежим result.txt/reference.txt):
python tools/plot_trajectory.py

# Закрыть окно через 5 с (для автоматических прогонов):
python tools/plot_trajectory.py --auto-close 5

# Только PNG, без окна:
python tools/plot_trajectory.py --save-only

# Графики ошибок (J-метрика, разности, внутренние ошибки КФ) — PNG без окон:
python tools/plot_errors.py
python tools/plot_errors.py --out-dir temp_tune_v2 --skip-first 10
```

`plot_trajectory.py` берёт самые свежие `result.txt` и `reference.txt` из `tools/`,
`build/` и корня проекта, рисует 9 панелей и сохраняет `tools/result_comparison.png`.
Окна закрываются штатно (кнопкой X) либо автоматически по `--auto-close`;
после закрытия процесс завершается с кодом 0 без трассировок Tk.

`plot_errors.py` так же сам находит свежую пару `result.txt`/`reference.txt`,
берёт `errors.txt` рядом с ними и пишет `best_errors.png`, `best_diffs.png`,
`best_kf_errors.png` рядом с `result.txt` (или в `--out-dir`). Явные
`--result`/`--reference`/`--out-dir` по-прежнему поддерживаются — так его
вызывает тюнер.

## Формат данных

### Входные данные

Четыре файла в каталоге данных (по умолчанию `../data/raw/`):

#### imu.dat — данные инерциального датчика (200 Гц)

Заголовочная строка начинается с `#`. Разделитель — табуляция.

| Столбец | Индекс | Описание | Единицы |
|---------|--------|----------|---------|
| time_s | 0 | Время отсчёта | с |
| timestamp_ns | 1 | Временная метка | нс |
| wx | 2 | Угловая скорость вокруг оси X (вперёд) | рад/с |
| wy | 3 | Угловая скорость вокруг оси Y (вверх) | рад/с |
| wz | 4 | Угловая скорость вокруг оси Z (вправо) | рад/с |
| ax | 5 | Ускорение по оси X (вперёд) | м/с² |
| ay | 6 | Ускорение по оси Y (вверх) | м/с² |
| az | 7 | Ускорение по оси Z (вправо) | м/с² |

**СК тела:** X — вперёд, Y — вверх, Z — вправо.
На стоянке: `ax ≈ 0`, `ay ≈ g` (9.81 м/с²), `az ≈ 0`.

#### gps.dat — данные СНС (10 Гц, запись 200 Гц)

Каждый отсчёт обновляется каждые 20 строк, между обновлениями дублируется.

| Столбец | Индекс | Описание | Единицы |
|---------|--------|----------|---------|
| time_s | 0 | Время отсчёта | с |
| timestamp_ns | 1 | Временная метка | нс |
| latitude | 2 | Широта | градусы |
| longitude | 3 | Долгота | градусы |
| altitude | 4 | Высота | м |
| vn | 5 | Скорость на север | м/с |
| vh | 6 | Вертикальная скорость (вверх) | м/с |
| ve | 7 | Скорость на восток | м/с |

#### angle.dat — углы ориентации (200 Гц)

| Столбец | Индекс | Описание | Единицы |
|---------|--------|----------|---------|
| time_s | 0 | Время отсчёта | с |
| timestamp_ns | 1 | Временная метка | нс |
| roll | 2 | Крен | рад |
| pitch | 3 | Тангаж | рад |
| yaw | 4 | Курс | рад |

> **Важно:** `gps.dat` и `angle.dat` читаются синхронно построчно (`SnsReader`);
> число строк должно совпадать.

#### StartupNav.ini — конфигурация выставки

4 строки; значения через пробел, комментарий через `;`:

| Строка | Описание | Единицы |
|--------|----------|---------|
| 1 | Долгота выставки | град |
| 2 | Широта выставки | град |
| 3 | Высота выставки | м |
| 4 | Время выставки (окончание окна усреднения) | сек |

> Если `StartupNav.ini` отсутствует, координаты берутся из первого отсчёта
> `gps.dat`, время выставки — 1 с.

**Окно выставки = 1 с** (4-я строка). Окно — отрезок файла **от его начала до
`T`** (файлы читаются с начала, перемотки нет). За окно считаются средние
и максимумы отклонения ИМУ/СНС; по ним строятся: уровень (`pitch`, `roll`),
курс (последний отсчёт `angle.dat` или гирокомпасирование), оценки смещений
`ba`/`bg`, номинал состояния (координаты, скорости, курс) и ковариация `P₀`
плюс вектор `x₀`. Первая коррекция СНС — по первому кадру за окном.
Диагностика окна пишется в `tools/init.txt` (средние, σ, `x0`, `σ0`, гейт
покоя). Подробно — `docs/fast_alignment_plan.md`, отличия от Qt-версии —
`docs/noqt_deviations.md` (раздел 6).

### Выходные данные (в `tools/`)

- **result.txt** — результат БИНС (исправленный Калманом): time, lon/lat/alt,
  heading/pitch/roll, vn/vh/ve.
- **reference.txt** — эталон СНС, тот же формат.
- **errors.txt** — time + 15 компонент вектора ошибок x.
- **init.txt** — диагностика выставки: средние и σ окна, `ba`/`bg`, уровень,
  курс, пороги гейта покоя, начальные `x0` и `σ0`.
- **gnss_guard.txt** — журнал защиты СНС (уровни 1–2).
- **bias.txt** — журнал оценок смещений ДУС/акселя (только по `--bias-log`).
- **consistency.txt** — согласованность фильтра, NIS (только по `--consistency`).
- `data/processed/Aligner.dat` — промежуточные данные выставки.

## Структура проекта

```
ITT_Students_NoQT/
├── src/
│   ├── main.cpp                    # Движок прогона (аргументы, выставка, цикл, запись)
│   ├── data_io/                    # Чтение imu/gps/angle, запись результатов, синтез наборов
│   ├── ins/                        # Ориентация, разбор ИМУ, фильтр Калмана (15)
│   ├── math_lib/                   # Матрицы, статистика, преобразования
│   ├── navigation/                 # Выставка, комплекс. по СНС, цикл счисления, аналитика
│   └── utils/                      # Константы, типы, пути
├── tools/                          # Скрипты визуализации (plot_trajectory.py и др.)
├── data/
│   ├── raw/                        # Входные данные
│   └── processed/                  # Промежуточные результаты
├── docs/
├── run_hk/                         # Набор данных для прогона
├── test/
├── CMakeLists.txt
└── README.md
```

Отличия от исходного `C:\ITT_Students`: ядро — **текущее** (Этапы 0–6 плана
смещений: согласованное измерение акселя, честные `P0`/`Q`, защита от отказов
СНС, курс из первого отсчёта СНС, комплекс. с гейтом). Сборка — без Qt, только
цель `imitator`. Движок прогона, как и в оригинале, расположен в `main.cpp`:
отдельного модуля `simulation.*` нет.

## Используемые библиотеки

- C++17, CMake, MinGW (GCC) — сама программа.
- numpy, pandas, matplotlib — для скриптов в `tools/` (см. `requirements.txt`).
