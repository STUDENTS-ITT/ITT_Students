# ITT_Students - Комплексирование видео, навигационной системы и БИНС

## 📋 Описание проекта
Проект по разработке алгоритма комплексирования видео, навигационной системы и бортовой инерциальной навигационной системы (БИНС) при полете летательного аппарата.

##  Структура веток Git

### Основная ветка
- **`main` (PROD)** - стабильная рабочая версия кода. Сюда merg'ятся только протестированные функции.

### Ветки разработки
Создавайте отдельные ветки для каждого блока:
```bash
# Обязательно указывайте в названии имя, кто делает например feature/navigation-system-Vasya
git branch feature/navigation-system     # Навигационная система
git branch feature/ins-algorithm         # Алгоритм БИНС
git branch feature/data-reading          # Считывание данных
git branch feature/math-functions        # Математические функции
git branch feature/integration           # Интеграция модулей
```
## Как работать? 🤝 Правила работы в команде
1) Создайте ветку
```bash
# Создать новую ветку и переключиться
git checkout -b feature/your-feature-name
```
2) Переключитесь на другую любую доступную ветку, например main
```bash
# Вернуться в основную ветку
git checkout main
```
3) Добавьте ветку в репозиторий
```bash
# Отправить ветку на сервер
git push origin feature/your-feature-name
```
4) Реализуйте функцию и обязательно протестируйте правильность реализации, выполнения её (в дальнейшем попробуем реализовать автотесты)

5) Commit
- пишите понятные коммиты для всех разработчиков
- чтобы не было проблем используйте русский язык
6) Отправка на сервер
- Перед отправкой на сервер, проверьте актуальность `main` ветки:
```
git pull origin main
```
- Проверьте наличие конфлитков
- Сделайте `push` на сервер:
```
git push origin {название_ветки}
```
7) Создайте pull request на сайте репозитория и ждите комментарий админа
8) Если всё круто, то admin делает merge main и вашей ветки, ваша ветка удаляется автоматически 
### 📞 Контакты
Если вам что-то не нравится в работе общего кода можете написать человеку, который это делал. Либо (что более правильно) создаёте Issue и указываете в чем проблема, так она будет видна всем разработчикам и тот кто свободен объяснит или исправит её
