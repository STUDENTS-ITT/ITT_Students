# Навигация (SINS)

Проект по обработке данных инерциальных навигационных систем (БИНС).

## Данные полётов

- [`INS_Data/`](INS_Data/) — тестовые данные с IMU и навигационные решения (1, 2, 3)
- [`17.07.26/SINS/`](17.07.26/SINS/) — данные за 17.07.26
- [`21.07.2026/INS_Data/`](21.07.2026/INS_Data/) — данные за 21.07.2026
- [`Smoothing/`](Smoothing/) — алгоритмы сглаживания

## Структура

| Папка | Описание |
|---|---|
| `SINS/` | Основной алгоритм БИНС (C++) |
| `Smoothing/` | Методы сглаживания (Boxcar, Gaussian, Hybrid) |
| `21.07.2026/` | Обработка GNSS + SINS (C++) |
| `Documentation/` | Документация |
