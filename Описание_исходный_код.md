## main.cpp

Основная программа обработки данных IMU (инерциального измерительного модуля) и вычисления углов ориентации.

### Функционал

1. **Автоматическое обнаружение файлов**
   - Рекурсивный поиск `IMU.txt` и `Nav.dat` в текущей директории и поддиректориях

2. **Чтение параметров из Nav.dat**
   - Широта местности (для расчёта ускорения свободного падения `g`)
   - Время отсечки `Tnav cutoff` (ограничение временного диапазона данных)

3. **Чтение данных из IMU.txt**
   - Парсинг CSV: время, акселерометр (ax, ay, az), гироскоп (wx, wy, wz)
   - Фильтрация по времени (до `tnavCutoff`)

4. **Сглаживание данных**
   - Выбор метода через `#define USE_GAUSSIAN`:
     - `0` — Boxcar (скользящее среднее)
     - `1` — Gaussian (гауссово взвешенное)
     - `2` — Progressive (расширяющееся среднее)
   - Применение к 6 каналам: ax, ay, az, wx, wy, wz

5. **Расчёт углов**
   - Pitch, Roll, Yaw для сырых и сглаженных данных
   - Конвертация в угловые минуты (arcminutes)

6. **Вывод результатов**
   - Таблица в консоль (первые 20 строк)
   - Сохранение полного набора данных в `output.txt`

### Использование

```bash
# Компиляция
g++ -std=c++17 -O2 -o process.exe main.cpp

# Запуск (из папки с данными)
./process.exe
```

### Формат выходного файла (output.txt)

```

s m/s2 m/s2 m/s2 deg/s deg/s deg/s rad rad rad m/s2 m/s2 m/s2 deg/s deg/s deg/s rad rad rad
```

## imu_data.h

Определяет структуру `ImuData` для хранения данных IMU.

### Структура ImuData

| Поле | Тип | Описание |
|------|-----|----------|
| `time` | double | Временная метка (с) |
| `ax, ay, az` | double | Показания акселерометра (м/с²) |
| `wx, wy, wz` | double | Показания гироскопа (°/с или рад/с) |
| `pitch, roll, yaw` | double | Вычисленные углы (рад) |

### Методы

- `clear()` — обнуление всех полей
- `parseFromString(line)` — парсинг строки CSV в структуру

## calculator.h

Содержит функции сглаживания и расчёта углов.

### Константы

| Константа | Значение | Описание |
|-----------|----------|----------|
| `G_CONST` | 6.67430×10⁻¹¹ | Гравитационная постоянная |
| `EARTH_MASS` | 5.97219×10²⁴ | Масса Земли (кг) |
| `EARTH_RADIUS` | 6371000 | Радиус Земли (м) |
| `EARTH_OMEGA` | 7.292115×10⁻⁵ | Угловая скорость вращения Земли (рад/с) |

### Функции

#### calculateGravity(latitude_rad)
Вычисляет ускорение свободного падения с учётом широты и центробежной силы.

#### movingAverage(in, out, win)
**Boxcar-фильтр** — скользящее среднее с окном `win`.
- Сложность: O(n)
- Граничное условие: отражение (mirror padding)

#### gaussianKernel(win)
Создаёт гауссово ядро для свёртки.
- σ = win/6 (±3σ укладывается в окно)
- Нормализация: сумма весов = 1

#### gaussianFilter(in, out, kernel)
**Гауссово сглаживание** — взвешенная свёртка с гауссовым ядром.
- Сложность: O(n × win)
- Граничное условие: отражение

#### progressiveMean(in, out)
**Progressive-фильтр** — расширяющееся среднее.
- На каждом шаге i используется среднее всех элементов [0..i]
- Сложность: O(n)
- Максимальная гладкость, но медленная сходимость в начале

#### hybridSmooth(in, out, win)
**Гибридный фильтр** — комбинация Boxcar и Progressive.
- Первые `win` отсчётов: Boxcar
- От `win` до `2×win`: линейная интерполяция
- После `2×win`: Progressive

#### calculateAngles(data, g)
Вычисляет углы по данным акселерометра и гироскопа:
- `pitch = asin(ax / g)`
- `roll = atan2(-az, ay)`
- `yaw = atan2(wz, wx)`

## file_utils.h

Утилиты для работы с файловой системой.

### Функции

| Функция | Описание |
|---------|----------|
| `fileExists(path)` | Проверка существования файла |
| `skipLines(file, count)` | Пропуск строк в потоке |
| `readLatitudeFromNav(folder)` | Чтение широты из Nav.dat (6-я колонка, 3-я строка) |
| `readTnavCutoff(folder)` | Чтение времени отсечки Tnav из Nav.dat |
| `findFile(filename)` | Рекурсивный поиск файла в директории |
| `printError(message)` | Вывод сообщения об ошибке |
| `printStatus(message)` | Вывод статусного сообщения |
