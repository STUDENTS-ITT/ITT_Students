# БИНС — Бесплатформенная инерциальная навигационная система

## 1. Название проекта

Бесплатформенная инерциальная навигационная система (БИНС) на углах Эйлера–Крылова.

## 2. Назначение

Обработка данных с инерциальных датчиков (IMU) для вычисления текущих координат, скоростей и углов ориентации движущегося объекта в автономном режиме.

Программа реализует полный цикл работы БИНС:
- Начальная выставка (определение начальных углов ориентации по акселерометрам)
- Интегрирование кинематических уравнений ориентации (Эйлер–Крылов)
- Счисление пути (двойное интегрирование ускорений)

## 3. Краткое описание алгоритма

| Параметр | Значение |
|---|---|
| Метод ориентации | Углы Эйлера–Крылова (Yaw, Pitch, Roll) |
| Метод счисления пути | Двойное интегрирование с компенсацией Кориолиса |
| Модель Земли | WGS-84 (сферическое приближение) |
| Гравитация | Формула с учётом центробежной силы |
| Вертикальный канал | Заблокирован (наземное применение) |

## 4. Системные требования

- Компилятор: C++17 или новее (g++, clang++, MSVC)
- ОС: Windows / Linux / macOS
- Память: > 10 МБ (для обработки файлового лога)

## 6. Запуск

### Компиляция

```bash
g++ -std=c++17 -O2 main.cpp -o sins
```

### Запуск

```bash
# Использовать данные из папки INS_Data/1 (по умолчанию)
./sins

# Использовать данные из папки INS_Data/2
./sins 2
```
