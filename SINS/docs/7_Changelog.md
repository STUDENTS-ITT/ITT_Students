# Журнал изменений

## Версия 1.0 — 16.07.2026

### Реализовано

- Базовая логика БИНС на углах Эйлера–Крылова
- Начальная выставка по акселерометрам (определение Pitch и Roll в покое)
- Прогрессивное усреднение IMU-данных на этапе выставки
- Интегрирование кинематических уравнений ориентации (Эйлер–Крылов)
- Счисление пути с компенсацией ускорений Кориолиса
- Модель гравитации WGS-84 с учётом центробежной силы
- Блокировка вертикального канала для наземного применения
- Потоковый загрузчик IMU.txt (без загрузки всего файла в память)
- Автоматическое определение границы фаз выставка→навигация из Nav.dat
- Вывод первых 20 состояний системы в консоль

### Исправлены ошибки

- **Критическая**: Буфер выставки пуст из-за сравнения `T < T_reg` вместо `T <= alignment_end_T`
- **Критическая**: Долгота интегрировалась в `pos.z` вместо `pos.y` (поле Alt)
- **Критическая**: `last_T_sys` инициализировался временем начала выставки вместо её окончания (первый `dt` = 313 с вместо ~1 с)
- **Средняя**: `printNavState` выводил высоту вместо долготы
- **Средняя**: `loadNav` читала только первую строку Nav.dat, не находя границу фаз
