# Коррекция углов ориентации: angle.dat и фильтр Калмана

## Что сделано

1. **Разделено чтение `gps.dat` и `angle.dat`** — ранее файлы читались синхронно в одном классе `SnsReader`. Теперь `angle.dat` стал опциональным: если файл отсутствует, программа работает без него.

2. **Коррекция по крену и тангажу отключена** — фильтр Калмана корректирует только координаты, скорости и курс. Крен и тангаж определяются только по акселерометру (через БИНС).

3. **Коррекция по курсу сохранена** — если `angle.dat` есть, курс корректируется по данным из файла.

## Как работает коррекция углов

Фильтр Калмана 15-го порядка использует 9-компонентный вектор измерений:

```
z = {lat, lon, alt, vn, vh, ve, heading, pitch, roll}
```

На каждом шаге коррекции (раз в 200 отсчётов ИМУ = 1 Гц) вычисляется инновация:

```
инновация = БИНС − эталон
```

### Если `angle.dat` есть

| Компонента | Источник эталона | Коррекция |
|------------|------------------|-----------|
| Широта | `gps.dat` | Да |
| Долгота | `gps.dat` | Да |
| Высота | `gps.dat` | Да |
| Скорость на север | `gps.dat` | Да |
| Вертикальная скорость | `gps.dat` | Да |
| Скорость на восток | `gps.dat` | Да |
| Курс | `angle.dat` | **Да** |
| Тангаж | Текущее состояние БИНС | **Нет** (инновация = 0) |
| Крен | Текущее состояние БИНС | **Нет** (инновация = 0) |

### Если `angle.dat` нет

| Компонента | Источник эталона | Коррекция |
|------------|------------------|-----------|
| Широта | `gps.dat` | Да |
| Долгота | `gps.dat` | Да |
| Высота | `gps.dat` | Да |
| Скорость на север | `gps.dat` | Да |
| Вертикальная скорость | `gps.dat` | Да |
| Скорость на восток | `gps.dat` | Да |
| Курс | Нет эталона | **Нет** |
| Тангаж | Нет эталона | **Нет** |
| Крен | Нет эталона | **Нет** |

## Роль `angle.dat`

- **Содержит:** эталонные углы ориентации (курс, тангаж, крен) от внешнего датчика.
- **Используется для:** коррекции курса в фильтре Калмана.
- **Не используется для:** коррекции крена и тангажа (они определяются по акселерометру).
- **На аппарате:** файла не будет. Коррекция курса будет отключена до появления альтернативного источника (магнитометр, визуальная навигация и т.д.).

## Реализация

Изменения в `trajectory.h`, функция `step()`:

```cpp
// Эталон СНС: из ref берем только координаты, скорости и курс.
// Тангаж и крен берём из текущего состояния БИНС (инновация = 0 → коррекции нет).
const Vector sns = {ref.lat, ref.lon, ref.alt,
                    ref.vn, ref.vh, ref.ve,
                    ref.heading, st.att.pitch, st.att.roll};
```

Вместо `ref.measurement()` (который возвращает `ref.heading/pitch/roll`) подставляются текущие значения БИНС для тангажа и крена. В результате инновация для этих компонент равна нулю, и фильтр не применяет к ним коррекцию.
