# AGENTS.md — контекст для ИИ по проекту ITT_Students_Qt_Version

## Цель проекта
Создание Qt 6.12.0 GUI-обвязки поверх существующего ESKF/БИНС-СНС комплекса.

Ядро (ESKF, матрицы, интеграторы, чтение/запись .dat) должно остаться Qt-независимым. Распространения бинарника не планируется — можно использовать любые модули Qt, включая GPLv3 при желании, но предпочтительно использовать только LGPL-модули.

## Текущая структура
Актуально скопировано из C:\ITT_Students (консольный `imitator` + Python-визуализация `tools/plot_trajectory.py`).

## Архитектура Qt-версии

По `docs/qt_integration_proposal.md` проект разделяется на два логических слоя:

- **`src/core/` (Qt-независимое ядро)** — содержит `ins/`, `nav/`, `math_lib/`, `utils/`, `data_io/`. Собирается как статическая библиотека `esfcore` (C++17, STL). **Запрещено** добавлять какие-либо зависимости Qt в `core/`.
- **`src/console/`** — консольный запуск (`main.cpp`), остаётся для обратной совместимости. Собирается как цель `imitator`, линкуется с `esfcore`.
- **`src/gui/` (Qt)** — GUI-приложение `imitator_gui` на Qt 6.12.0 (QtWidgets). Графики — **только на `QPainter`** (без QtCharts/QtGraphs/QtQuick3D). Использует `QtConcurrent/QThread`, `QSettings`, `QtSql` (SQLite).

Правило: в `src/core` не должно быть ни одного `#include <Q...>` (проверяется при рефакторинге).

## Сборка (предварительная)

Планируется использовать CMake с несколькими целями:
- `esfcore` — статическая библиотека (core)
- `imitator` — консольная цель (console + core)
- `imitator_gui` — Qt GUI-приложение (gui + core)

Для Qt 6.12.0 под Windows предпочтительнее MSVC + Ninja (оф. бинарники Qt не поставляются в сборке MinGW Makefiles). При сборке нужно проверять окружение (текущий проект собран MinGW Makefiles, core можно собирать тем же тулчейном).

## Ключевые правила работы с кодом

- **Не добавлять зависимости Qt в `core/`**. Весь Qt-код — только в `src/console`? Нет, консольный main без Qt. Весь Qt-код только в `src/gui/`.
- **Сохранять текущие алгоритмы ESKF** (15 состояний). Не менять матричные умножения/транспонирования без проверки конвенции: матрица хранится построчно (row-major), кол-во столбцов `cols` передаётся явно: `multiply_matrix(A,B,cols_A,cols_B)`, `transpose_m(A,cols)`, `multiply_m(A,v,cols_A)`, `at(A,i,j,cols)`.
- **Углы внутри — радианы, на выход — градусы** (`RAD_TO_DEG`).
- Комментарии — на русском, без лишних восклицательных знаков (стиль исходного кода).
- После правок собирать: `cmake --build build --target imitator_gui` или `imitator` (в зависимости от задачи).
- Соблюдать минимальные изменения: рефакторинг под слои, не переписывать фильтр без необходимости.
- При выделении `core/` консольный `imitator` должен давать **идентичные** выходные файлы (`result.txt`, `reference.txt`, `errors.txt`) по сравнению с текущей версией (бит-в-бит по содержимому).

## Лицензия/распространение

Распространения бинарника не планируется. Предпочтение отдаётся **только LGPL-модулям** Qt (`QtCore`, `QtGui`, `QtWidgets`, `QtConcurrent`, `QtSql`, `QtSerialPort`, `QtNetwork`, `QtTest`). Графики реализуются на `QPainter` (не QtCharts/QtGraphs/QtQuick3D).
