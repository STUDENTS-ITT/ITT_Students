# reports — готовые PDF-отчёты по наборам

Здесь лежат отчёты, которые **само приложение `imitator_gui`** собирает по наборам
данных (`ITT_Students-Katya/dataset_shum/*`). Ручных скриптов нет: верстку делает
GUI-код (`src/gui/export/`).

## Структура

```
reports/
  <набор>/                     например static_300
    tuning_<набор>.pdf         отчёт о подборе коэффициентов фильтра
    run_<набор>.pdf            отчёт о прогоне (с подобранным пресетом)
```

Имя `<набор>` — это имя каталога данных (последний компонент `data_dir`), например
`static_300`, `square_650`, `figure8_8ms`.

## Как получить

Диалоги сохранения по умолчанию подставляют каталог `reports/<набор>/`.

### Отчёт о подборе (только метрики подбора)

- GUI: вкладка **«Подбор»** → выбрать конфиг (`tuner_config.<набор>.json`) →
  кнопка **«Отчёт о подборе…»**.
- CLI:
  ```
  dist\imitator_gui.exe --tuning-report tools\kalman_tuner\tuner_config.static300.json
  ```
  По умолчанию пишет в `reports/<набор>/tuning_<набор>.pdf`; явный путь —
  `--tuning-report-out <file.pdf>`.
- В шапке отчёта строка **«Ошибка считается по»** указывает, с чем сравнивалась
  ошибка: `reference.txt` (эталон СНС) или `truth.txt` (наземная истина). Режим
  истины задаётся чекбоксом «Сравнивать с истиной (truth.txt)» на вкладке
  «Подбор»: галочка автоматически включается для наборов с корректным
  `truth.txt` и сбрасывается, если файл повреждён или отсутствует.

### Отчёт о прогоне

- GUI: выбрать набор данных и пресет `presets/tuned_<набор>.ini`, нажать
  **«Запустить»** (F5), затем меню **«Экспорт» → «Сводный отчёт в PDF…»**.
- Самотест/CI: `dist\imitator_gui.exe --self-test -d <набор> -s presets\tuned_<набор>.ini`.
- Если в наборе есть корректный `truth.txt`, отчёт **по умолчанию считает ошибку
  по истине**: в шапке стоит строка «Ошибка считается по — truth.txt (наземная
  истина)», а после раздела «Ошибки фильтра (кадры коррекции)» печатается раздел
  **«Ошибка относительно истины»** (P95/среднее по позиции, скорости, курсу — те
  же определения, что у тюнера). Наборы без истины считаются по `reference.txt`,
  и раздел не выводится.

## Примечание

Артефакты тюнера `best_params.txt` и `eval.json` лежат в рабочем каталоге подбора
(`work_root` из конфига) и **перезаписываются** при следующем запуске подбора.
Отчёт о подборе нужно собирать сразу после успешного подбора, пока артефакты на месте.
